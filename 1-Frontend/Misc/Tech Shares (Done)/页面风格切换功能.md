# 页面风格切换功能

## 一、页面样式切换

- 实现方式：通过根容器类名切换明暗风格。
- 样式组成：共用样式、明专属样式、暗专属样式。
- 组合关系：共用样式 + 明专属样式 = 明风格；共用样式 + 暗专属样式 = 暗风格。
- 实践建议：明专属样式与暗专属样式尽量一一对应，便于维护和扩展。

### 1. 全局样式及变量

```css
:root {
  --g-font-family:
    "PingFang SC", "Microsoft YaHei", "微软雅黑", helvetica, arial, sans-serif;
  --g-text-color: #142c65;
}

:root.dark {
  --g-text-color: #eceff8;
}

body {
  font-family: var(--g-font-family);
  color: var(--g-text-color);
}
```

### 2. 页面内样式变量

```css
.layout {
  color: var(--title-color);
}

:root .layout {
  --title-color: #006aff;
}

:root.dark .layout {
  --title-color: #eceff8;
}
```

## 二、图片、文字等非样式元素切换

### 1. 使用状态管理中的标志位

```vue
export const useSystemStore = defineStore<string, IState, IGetters, IActions>(
  "system",
  {
    state: () => ({
      dark: false,
    }),
    getters: {},
    actions: {},
  },
)

<div class="bottom" @click="toggleDark">
  <img
    :src="getImgSrc(imgPath, systemStore.dark ? 'apperance-dark' : 'apperance')"
  />
  <span>{{ systemStore.dark ? "浅色" : "深色" }}模式</span>
</div>
```

## 三、完成过程

### 1. 初始化并存储用户的风格偏好

- 首次进入页面时，优先读取本地存储中的主题偏好。
- 如果本地还没有记录，则读取系统主题偏好并写入本地存储。

```ts
window.addEventListener("DOMContentLoaded", () => {
  initialDark()
  setDark()
})

function initialDark() {
  if (typeof getStorage(darkKey) !== "boolean") {
    setStorage(
      darkKey,
      window.matchMedia("(prefers-color-scheme: dark)").matches,
    )
  }
}
```

### 2. 根据本地存储同步根节点与状态管理

```ts
function setDark() {
  const dark = getStorage(darkKey)

  if (typeof dark === "boolean") {
    const systemStore = useSystemStore()

    if (dark) {
      document.documentElement.classList.add(darkClassName)
      systemStore.dark = true
    } else {
      document.documentElement.classList.remove(darkClassName)
      systemStore.dark = false
    }
  }
}
```

### 3. 提供手动切换能力

```ts
export const toggleDark = () => {
  const dark = getStorage(darkKey)

  if (typeof dark === "boolean") {
    setStorage(darkKey, !dark)
    setDark()
  }
}
```

### 4. 侦听本地存储变化，保持多标签页一致

- 当其他标签页修改了主题偏好时，当前标签页会通过 `storage` 事件同步更新。

```ts
window.addEventListener("storage", event => {
  if (event.key === darkKey || event.key === null) {
    if (typeof getStorage(darkKey) !== "boolean") {
      initialDark()
    }
    setDark()
  }
})
```

## 四、小结

- 根容器类名负责整体主题样式切换。
- 状态管理标志位负责图片、文案等非样式元素切换。
- `localStorage` 与 `storage` 事件配合，可以保证主题偏好在多个标签页之间保持一致。
