# 动画

## 一、一句话理解

CSS 动画的核心不是“让东西动起来”，而是用可控的节奏、阶段和状态变化，表达页面反馈、层级和流程。

---

## 二、动画和过渡先分清

动画和过渡经常一起出现，但它们适合的场景不同。

| 对比项               | `transition` 过渡 | `animation` 动画             |
| -------------------- | ----------------- | ---------------------------- |
| **是否需要触发条件** | 通常需要          | 可以主动播放                 |
| **能否定义多个阶段** | 不方便            | 可以                         |
| **适合什么场景**     | hover、点击态变化 | 入场、加载、循环、多阶段效果 |

一个简单判断：

- 只是状态切换，用过渡。
- 需要完整播放过程，用动画。

---

## 三、动画的基本结构

CSS 动画通常分两步：

1. 用 `@keyframes` 定义关键帧。
2. 用 `animation-*` 属性把动画应用到元素上。

### 1. 定义关键帧

```css
@keyframes moveBox {
  0% {
    transform: translateX(0);
  }

  50% {
    transform: translateX(100px);
  }

  100% {
    transform: translateX(200px);
  }
}
```

### 2. 应用动画

```css
.box {
  animation-name: moveBox;
  animation-duration: 1s;
}
```

只定义关键帧不会自动生效，必须把它绑定到元素上。

## 四、常见动画属性

| 属性                        | 作用                        |
| --------------------------- | --------------------------- |
| `animation-name`            | 动画名称，对应 `@keyframes` |
| `animation-duration`        | 动画持续时间                |
| `animation-timing-function` | 速度曲线                    |
| `animation-delay`           | 延迟多久开始                |
| `animation-iteration-count` | 播放次数                    |
| `animation-direction`       | 播放方向                    |
| `animation-fill-mode`       | 播放前后样式如何保留        |
| `animation-play-state`      | 播放或暂停                  |

### 1. `animation-duration`

```css
.box {
  animation-duration: 2s;
}
```

持续时间必须写单位，常见是 `s` 和 `ms`。

### 2. `animation-timing-function`

```css
.box {
  animation-timing-function: ease-in-out;
}
```

常见值：

| 值            | 含义           |
| ------------- | -------------- |
| `linear`      | 匀速           |
| `ease`        | 默认，慢快慢   |
| `ease-in`     | 慢开始         |
| `ease-out`    | 慢结束         |
| `ease-in-out` | 两头慢，中间快 |

### 3. `animation-iteration-count`

```css
.box {
  animation-iteration-count: 3;
}

.loading {
  animation-iteration-count: infinite;
}
```

`infinite` 表示无限循环，但不要滥用。

### 4. `animation-fill-mode`

```css
.box {
  animation-fill-mode: forwards;
}
```

| 值          | 含义                 |
| ----------- | -------------------- |
| `none`      | 默认，不保留         |
| `forwards`  | 停在最后一帧         |
| `backwards` | 延迟期间先套用第一帧 |
| `both`      | 同时具备前两者效果   |

### 5. `animation-play-state`

```css
.box:hover {
  animation-play-state: paused;
}
```

常用于 hover 暂停、点击暂停、轮播暂停等场景。

---

## 五、动画简写

```css
.box {
  animation: moveBox 1s ease 0s 2 alternate forwards;
}
```

常见记忆顺序：

```text
名称 持续时间 速度曲线 延迟 次数 方向 填充模式
```

如果动画较复杂，拆开写会更易读、更好维护。

---

## 六、一个完整示例

```html
<div class="box"></div>
```

```css
.box {
  width: 100px;
  height: 100px;
  background-color: tomato;
  animation: moveBox 2s ease-in-out infinite alternate;
}

@keyframes moveBox {
  0% {
    transform: translateX(0) rotate(0deg);
    border-radius: 0;
  }

  100% {
    transform: translateX(200px) rotate(180deg);
    border-radius: 50%;
  }
}
```

这里元素发生了三类变化：

1. 位移。
2. 旋转。
3. 形状变化。

说明一个动画并不只对应一个属性，它可以同时描述多个视觉维度。

## 七、常见应用场景

| 场景                   | 为什么适合用动画           |
| ---------------------- | -------------------------- |
| **加载中效果**         | 需要自动重复播放           |
| **页面元素入场**       | 需要完整播放一段过程       |
| **引导提示或强调**     | 需要反复提醒用户关注       |
| **骨架屏、轮播、波纹** | 需要连续、多阶段或循环效果 |

### 1. 入场动画

页面内容从透明到出现、从下方轻微上浮，是最常见的入场方式。

### 2. Loading 动画

通常会设置 `infinite`，但要控制节奏，不要让用户产生烦躁感。

---

## 八、动画写得自然的关键

### 1. 节奏要符合场景

| 场景         | 常见建议           |
| ------------ | ------------------ |
| **悬停反馈** | 短、轻、快         |
| **入场动画** | 稍慢，但不要拖沓   |
| **加载动画** | 平稳、可循环       |
| **强调提醒** | 适度，不要不停闪烁 |

### 2. 动画不该喧宾夺主

动画是为了说明状态，不是为了抢内容本身的注意力。

如果用户看完动画，反而没看清内容，那动画就是失败的。

---

## 九、性能相关的注意点

高频动画优先用 `transform` 和 `opacity`，因为它们通常更不容易触发昂贵的布局和重绘。

更推荐动画的属性：

- `transform`
- `opacity`

相对要谨慎的属性：

- `width`
- `height`
- `top`
- `left`
- `margin`

不是说这些属性完全不能动，而是频繁变化时性能成本通常更高。

## 十、实战中的常见问题

| 问题                   | 常见原因                                                |
| ---------------------- | ------------------------------------------------------- |
| **动画不生效**         | 只写了 `@keyframes`，没给元素加 `animation-name` 或简写 |
| **结束后样式又跳回去** | 没设置 `animation-fill-mode: forwards`                  |
| **循环动画看着生硬**   | 曲线和阶段设计不合理                                    |
| **页面变卡**           | 动画属性选得不好，或者同屏动画太多                      |

如果一个动画需要精确跟随用户输入或实时计算状态，CSS 动画不一定是最佳方案，这时可能要交给 JavaScript 或动画库。

---

## 十一、小结

| 知识点             | 结论                                          |
| ------------------ | --------------------------------------------- |
| **动画和过渡区别** | 过渡用于状态变化，动画用于完整播放过程        |
| **动画核心结构**   | `@keyframes` 定义过程，`animation-*` 控制播放 |
| **常见场景**       | 入场、加载、强调、连续反馈                    |
| **性能重点**       | 高频动画优先用 `transform`、`opacity`         |
| **真正难点**       | 不是语法，而是节奏、场景和性能判断            |
