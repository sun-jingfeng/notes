# 边框图片

## 一、一句话理解

`border-image` 的核心不是“会写一个冷门属性”，而是知道什么时候值得用图片切边框，什么时候应该换成更简单的视觉方案。

---

## 二、什么是边框图片

`border-image` 可以把一张图片切成几块，并映射到元素边框上，从而实现普通边框做不到的视觉效果。

它适合：

1. 特殊装饰边框。
2. 游戏风、复古风、海报风格界面。
3. 对边框视觉要求比较强的展示页面。

不过在日常业务系统中，它的使用频率并不高。

---

## 三、使用边框图片的前提

边框图片不是直接“覆盖边框”，而是基于边框区域来绘制，所以通常要先有边框宽度。

```css
.box {
  border: 20px solid transparent;
}
```

如果没有边框宽度，边框图片通常看不出来。

---

## 四、核心属性

### 1. `border-image-source`

指定边框图片资源。

```css
border-image-source: url("./images/border.png");
```

### 2. `border-image-slice`

指定把图片从上、右、下、左切开多少。

```css
border-image-slice: 30;
border-image-slice: 30 40 30 40;
```

### 3. `border-image-width`

指定边框图片的显示宽度。

```css
border-image-width: 20px;
```

### 4. `border-image-repeat`

指定边框图片在边缘区域如何铺展。

```css
border-image-repeat: stretch;
border-image-repeat: repeat;
border-image-repeat: round;
```

常见值：

| 值        | 含义                           |
| --------- | ------------------------------ |
| `stretch` | 拉伸填充                       |
| `repeat`  | 平铺，可能出现裁切不整齐       |
| `round`   | 自动调整后完整平铺             |
| `space`   | 留空隙平铺，兼容性和使用率较低 |

---

## 五、简写方式

边框图片也支持简写。

```css
.box {
  border: 20px solid transparent;
  border-image: url("./images/border.png") 30 / 20px round;
}
```

可以大致理解为：

```text
图片地址 裁切值 / 宽度 / 外扩 重复方式
```

如果刚开始不熟，建议先拆开写，排错更方便。

---

## 六、完整示例

```html
<div class="panel">边框图片示例</div>
```

```css
.panel {
  width: 320px;
  padding: 24px;
  border: 24px solid transparent;
  border-image-source: url("./images/border.png");
  border-image-slice: 48;
  border-image-width: 24px;
  border-image-repeat: round;
  background-color: #fff;
}
```

### 1. 这个例子里发生了什么

1. 先预留了 24px 边框空间。
2. 再把图片按 `48` 的裁切值切开。
3. 最后把切出来的边缘区域贴到四条边上。

---

## 七、切图理解

`border-image` 的核心难点不是属性名，而是理解图片如何被切分。

可以把一张图理解成九宫格：

```text
左上 | 上边 | 右上
左边 | 中间 | 右边
左下 | 下边 | 右下
```

其中：

1. 四个角通常保持原样。
2. 四条边根据设置进行拉伸或平铺。
3. 中间区域默认不会直接作为元素内容背景使用。

---

## 八、常见问题

### 1. 为什么设置了没显示

通常排查这几项：

1. 是否先设置了 `border`。
2. 图片路径是否正确。
3. `slice` 是否合理。
4. 图片本身是否适合切分。

排查时最关键的意识是：问题往往出在“切分逻辑不对”，而不是属性名记错。

### 2. 为什么边角变形

可能原因：

1. 切割值不合理。
2. 使用了 `stretch` 导致边缘被强拉伸。
3. 原图本身不适合做边框图。

### 3. 为什么真实项目里不常用

因为：

1. 切图成本较高。
2. 调整起来不如普通边框灵活。
3. 现代页面很多效果可以用圆角、阴影、渐变、伪元素替代。

---

## 九、适用与替代方案

### 1. 适合使用 `border-image` 的场景

1. 视觉装饰性很强的边框。
2. 需要保留独特纹理或花边效果。
3. 传统边框无法满足设计要求。

### 2. 常见替代方式

1. `border-radius`
2. `box-shadow`
3. `outline`
4. 渐变背景
5. `::before` / `::after` 伪元素装饰

---

## 十、真实项目里怎么判断是否要用

| 场景                                 | 是否建议使用 `border-image` |
| ------------------------------------ | --------------------------- |
| **装饰性非常强、纹理不能丢**         | 可以考虑                    |
| **普通后台卡片或表单边框**           | 通常没必要                  |
| **需要高频调整样式和主题色**         | 不太适合                    |
| **可用渐变、阴影、伪元素实现的效果** | 优先考虑替代方案            |

---

## 十一、总结

1. `border-image` 的本质是用图片来绘制边框。
2. 使用前通常要先预留边框空间。
3. 最关键的属性是 `source`、`slice`、`width`、`repeat`。
4. 它更偏展示型技巧，在常规业务页面里不是高频方案。
5. 学这部分时，重点是理解“九宫格切分”和“边框区域映射”两个核心概念。
