# CSS样式生效机制

## 一、一句话理解

这三个概念本质上都在回答同一个问题：当多个样式同时出现时，浏览器最后到底让谁生效。

---

## 二、层叠性

**层叠性（Cascade）** 指的是：当多个 CSS 规则同时作用于同一个元素，并且设置了同一个属性时，浏览器需要决定最终使用哪一条。

### 1. 基本规则

| 情况                     | 结果             |
| ------------------------ | ---------------- |
| **样式不冲突**           | 会共同生效       |
| **样式冲突，优先级相同** | 后写的覆盖先写的 |

```css
p {
  color: red;
}

p {
  color: blue;
}
```

最终 `p` 会显示为蓝色，因为后面的规则覆盖了前面的规则。

### 2. 简写属性的覆盖问题

有些简写属性会连带覆盖相关子属性。

```css
span {
  line-height: 100px;
  font: 16px "Microsoft YaHei";
}
```

这里 `font` 是简写属性，它会把字体相关的多个子属性一起重设，可能把之前单独写的 `line-height` 覆盖掉。

同理：

```css
div {
  background-color: #f40;
  background: url("./1.jpg") no-repeat;
}
```

后面的 `background` 也可能把前面单独设置的背景色相关配置一并覆盖。

> **注意**：使用简写属性时，要意识到它可能不是“补充”，而是“整体重置”。

---

## 三、继承性

**继承性（Inheritance）** 指的是：某些 CSS 属性会从父元素自动传给子元素。

### 1. 常见可继承属性

| 类型         | 常见属性                                                         |
| ------------ | ---------------------------------------------------------------- |
| **文字相关** | `color`、`font-size`、`font-family`、`font-style`、`font-weight` |
| **行高相关** | `line-height`                                                    |
| **文本排版** | `text-align`、`text-indent`、`letter-spacing`                    |

### 2. 常见不可继承属性

| 类型       | 常见属性                                         |
| ---------- | ------------------------------------------------ |
| **盒模型** | `width`、`height`、`margin`、`padding`、`border` |
| **背景**   | `background`、`background-color`                 |
| **定位**   | `position`、`top`、`left`                        |

### 3. 示例

```css
body {
  color: #333;
  font-size: 16px;
}
```

如果子元素没有单独设置这些属性，通常会继承父元素对应的文字样式。

### 4. 行高继承的特殊点

```css
body {
  font: 12px/1.5 "Microsoft YaHei";
}
```

这里的 `1.5` 没有单位，表示**倍数**。子元素继承时，会根据自己的字体大小重新计算行高：

子元素行高 = 子元素字体大小 × 1.5

这也是实际开发里常见的推荐写法。

---

## 四、优先级

当不同选择器同时命中同一个元素，并且设置了同一个属性时，浏览器会按**优先级（Specificity）** 决定谁生效。

### 1. 常见优先级大小规律

| 选择器 / 写法                    | 大致权重 |
| -------------------------------- | -------- |
| **继承 / 通配符 `*`**            | 0        |
| **标签选择器**                   | 1        |
| **类选择器 / 属性选择器 / 伪类** | 10       |
| **id 选择器**                    | 100      |
| **行内样式**                     | 1000     |
| **`!important`**                 | 强制最高 |

### 2. 一个简单例子

```css
p {
  color: red;
}

.text {
  color: blue;
}
```

```html
<p class="text">测试文字</p>
```

最终结果是蓝色，因为类选择器优先级高于标签选择器。

---

## 五、优先级判断规则

### 1. 先比是否直接命中

直接命中的规则，优先级通常高于继承来的样式。

### 2. 再比选择器权重

如果是不同选择器命中同一个元素，就按权重比较。

### 3. 权重相同则看书写顺序

后写的覆盖先写的。

---

## 六、复合选择器的权重计算

复合选择器会发生权重叠加，但**不会进位**。

例如：

| 选择器           | 权重理解            |
| ---------------- | ------------------- |
| **`div ul li`**  | 3 个标签选择器      |
| **`.nav ul li`** | 1 个类 + 2 个标签   |
| **`a:hover`**    | 1 个标签 + 1 个伪类 |
| **`.nav a`**     | 1 个类 + 1 个标签   |

可以理解为：

- 类选择器永远高于标签选择器
- id 选择器永远高于类选择器
- 继承来的样式权重最低

---

## 七、`!important`

`!important` 会强行提高当前声明的优先级。

```css
.text {
  color: red !important;
}
```

### 1. 使用建议

| 建议                                   | 说明               |
| -------------------------------------- | ------------------ |
| **能不用就不用**                       | 容易让样式系统失控 |
| **仅在覆盖第三方样式或紧急兜底时使用** | 避免大范围滥用     |

---

## 八、真实开发里怎么排查样式冲突

可以按这条顺序判断：

1. 这个样式是直接命中的，还是继承来的。
2. 是否被简写属性整体重置了。
3. 多条规则里谁的优先级更高。
4. 如果优先级相同，是不是后写的覆盖了前写的。
5. 有没有 `!important` 或特殊层叠上下文干扰。

这条排查链比死记权重表更实用。

---

## 九、三个概念如何区分

| 概念       | 解决什么问题                       |
| ---------- | ---------------------------------- |
| **层叠性** | 同一个属性冲突时，后者是否覆盖前者 |
| **继承性** | 父元素某些样式是否自动传给子元素   |
| **优先级** | 多个不同选择器同时命中时谁生效     |

---

## 十、小结

| 知识点           | 结论                                     |
| ---------------- | ---------------------------------------- |
| **层叠性**       | 同优先级下，后写覆盖先写                 |
| **继承性**       | 文字相关属性常可继承，盒模型通常不可继承 |
| **优先级**       | id > 类/伪类 > 标签 > 继承/通配符        |
| **简写属性**     | 常会整体覆盖相关子属性                   |
| **`!important`** | 慎用，只在必要时使用                     |
