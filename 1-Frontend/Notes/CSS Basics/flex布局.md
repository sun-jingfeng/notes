# flex 布局

## 一、一句话理解

Flex 的核心价值不是“让元素横着排”，而是让父容器统一决定子项怎么分布、怎么对齐、怎么分剩余空间。

---

## 二、什么是 flex 布局

## 一、什么是 flex 布局

**Flex 布局（Flexible Box Layout）** 是一种一维布局模型，用来高效地控制子元素在主轴方向上的排列、分配空间和对齐方式。

**核心特点：** 适合处理“父子关系明确”的横向或纵向布局，例如导航栏、卡片列表、按钮组、居中容器。

| 对比项       | 传统布局               | flex 布局                |
| ------------ | ---------------------- | ------------------------ |
| **布局方式** | 浮动、定位、行内块组合 | 父容器统一控制子项       |
| **对齐能力** | 居中、等分较麻烦       | 对齐和分配空间更直接     |
| **适用场景** | 老项目兼容性要求高     | 现代 PC / 移动端布局首选 |

---

## 三、基础概念

当父元素设置 `display: flex` 后：

- 父元素称为**容器（container）**
- 子元素称为**项目（item）**

### 1. 主轴和交叉轴

flex 是一维布局，所有项目默认沿着**主轴**排列，另一条垂直方向的轴叫**交叉轴**。

默认情况下：

- 主轴：水平方向，从左到右
- 交叉轴：垂直方向，从上到下

```text
主轴：left  →  right
交叉轴：top ↓ bottom
```

---

## 四、使用步骤

### 1. 第一步：给父元素设置 flex

```css
.container {
  display: flex;
}
```

### 2. 第二步：设置容器和项目属性

通常需要根据布局目标补充：

- 主轴方向
- 主轴对齐方式
- 交叉轴对齐方式
- 项目是否换行
- 项目宽度分配方式

---

## 五、容器常用属性

### 1. `flex-direction`

设置主轴方向。

| 值                   | 含义                 |
| -------------------- | -------------------- |
| **`row`**            | 默认值，主轴从左到右 |
| **`row-reverse`**    | 主轴从右到左         |
| **`column`**         | 主轴从上到下         |
| **`column-reverse`** | 主轴从下到上         |

```css
.container {
  display: flex;
  flex-direction: row;
}
```

### 2. `justify-content`

设置项目在**主轴**上的对齐方式。

| 值                  | 含义                   |
| ------------------- | ---------------------- |
| **`flex-start`**    | 从主轴起点开始排列     |
| **`flex-end`**      | 从主轴终点开始排列     |
| **`center`**        | 主轴居中               |
| **`space-between`** | 两端贴边，中间均分空隙 |
| **`space-around`**  | 每项两侧都有空隙       |
| **`space-evenly`**  | 所有空隙完全相等       |

### 3. `align-items`

设置项目在**交叉轴**上的对齐方式。

| 值               | 含义                       |
| ---------------- | -------------------------- |
| **`stretch`**    | 默认值，项目拉伸填满交叉轴 |
| **`flex-start`** | 交叉轴起点对齐             |
| **`flex-end`**   | 交叉轴终点对齐             |
| **`center`**     | 交叉轴居中                 |
| **`baseline`**   | 基线对齐                   |

### 4. `flex-wrap`

控制项目是否换行。

| 值                 | 含义           |
| ------------------ | -------------- |
| **`nowrap`**       | 默认值，不换行 |
| **`wrap`**         | 超出后换行     |
| **`wrap-reverse`** | 反向换行       |

```css
.container {
  display: flex;
  flex-wrap: wrap;
}
```

> **注意**：换行生效需要两个条件同时满足：容器允许换行，且项目总宽度超过容器宽度。

### 5. `align-content`

当项目发生多行排列时，用于控制**多行整体**在交叉轴上的分布。单行布局时通常不会生效。

---

## 六、项目常用属性

### 1. `flex`

`flex` 是最常用的项目属性，用来控制项目如何分配剩余空间。

```css
.item {
  flex: 1;
}
```

它是以下三个属性的简写：

| 属性              | 作用                       |
| ----------------- | -------------------------- |
| **`flex-grow`**   | 放大比例，剩余空间如何分   |
| **`flex-shrink`** | 缩小比例，空间不够时如何缩 |
| **`flex-basis`**  | 分配空间前的基础尺寸       |

常见写法：

| 写法             | 含义                       |
| ---------------- | -------------------------- |
| **`flex: 1`**    | 平均分配剩余空间           |
| **`flex: 2`**    | 占用比 `flex: 1` 更多空间  |
| **`flex: none`** | 不放大、不缩小，保持原尺寸 |

### 2. `order`

控制项目显示顺序，值越小越靠前。

```css
.item-1 {
  order: 2;
}

.item-2 {
  order: 1;
}
```

### 3. `align-self`

允许单个项目覆盖容器的 `align-items` 设置。

```css
.item-special {
  align-self: flex-end;
}
```

## 七、常见布局案例

### 1. 水平居中 + 垂直居中

```css
.box {
  display: flex;
  justify-content: center;
  align-items: center;
}
```

### 2. 两端对齐导航栏

```css
.nav {
  display: flex;
  justify-content: space-between;
  align-items: center;
}
```

### 3. 等分布局

```html
<div class="list">
  <div class="item">1</div>
  <div class="item">2</div>
  <div class="item">3</div>
</div>
```

```css
.list {
  display: flex;
  gap: 12px;
}

.item {
  flex: 1;
}
```

### 4. 左侧固定，右侧自适应

```html
<div class="layout">
  <aside class="sidebar">菜单</aside>
  <main class="content">内容区</main>
</div>
```

```css
.layout {
  display: flex;
}

.sidebar {
  width: 220px;
}

.content {
  flex: 1;
  min-width: 0;
}
```

> **注意**：在 flex 布局中，如果右侧文本内容把容器撑开，常见做法是给自适应区域加 `min-width: 0`，而不是单纯写 `width: 0`。

## 八、书写 flex 布局的思路

推荐按下面的顺序思考：

1. 找到父子关系，把父元素设为 `display: flex`
2. 确定主轴方向是否需要改成纵向
3. 决定项目在主轴上如何分布：靠左、居中、两端、等分
4. 决定项目在交叉轴上如何对齐
5. 如果项目要自适应宽度，再设置 `flex`
6. 如果要换行，再设置 `flex-wrap`

---

## 九、什么时候用 flex，什么时候别硬上

| 场景               | 是否适合 flex             |
| ------------------ | ------------------------- |
| **导航栏**         | ✅ 非常适合               |
| **按钮组**         | ✅ 非常适合               |
| **卡片横向排列**   | ✅ 非常适合               |
| **单行或单列居中** | ✅ 非常适合               |
| **复杂二维网格**   | 可用，但通常更适合 `grid` |

总结：

- **移动端**：优先使用 flex
- **现代 PC 项目**：大多数场景也优先使用 flex
- **强兼容旧版 IE 的项目**：需要根据兼容要求谨慎选择

## 十、小结

| 知识点              | 结论              |
| ------------------- | ----------------- |
| **父元素开启 flex** | `display: flex`   |
| **主轴方向**        | `flex-direction`  |
| **主轴对齐**        | `justify-content` |
| **交叉轴对齐**      | `align-items`     |
| **项目分配空间**    | `flex`            |
| **项目顺序**        | `order`           |
