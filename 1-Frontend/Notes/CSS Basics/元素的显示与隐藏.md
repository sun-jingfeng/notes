# 元素的显示与隐藏

## 一、一句话理解

元素“显示与隐藏”的关键不只是看得见或看不见，而是同时判断它还占不占位置、还能不能交互、超出区域的内容要不要继续展示。

---

## 二、先分清三类控制目标

前端里常把这几个概念混在一起，但它们控制的其实不是同一件事：

| 控制目标                   | 常用属性     | 核心问题                     |
| -------------------------- | ------------ | ---------------------------- |
| **元素是否参与布局**       | `display`    | 元素还在不在页面流里         |
| **元素是否可见**           | `visibility` | 元素是否能被看到             |
| **超出盒子的内容怎么处理** | `overflow`   | 盒子外面的内容是否显示或滚动 |

所以 `display`、`visibility`、`overflow` 虽然都常出现在“隐藏”场景里，但它们并不是互相完全替代的关系。

---

## 三、`display` 控制元素是否参与布局

### 1. 常见写法

```css
display: none;
display: block;
display: inline;
display: inline-block;
```

### 2. `display: none` 的效果

```css
.box {
  display: none;
}
```

结果：

- 元素不可见。
- 元素不再占据原来的布局空间。
- 页面布局会像这个元素不存在一样重新计算。

这就是为什么很多切换面板、弹窗、折叠内容会使用 `display: none`。

### 3. `display` 不只是隐藏

很多时候 `display` 的作用不是隐藏，而是改变元素参与布局的方式，例如：

- `inline` 改成 `block`
- `block` 改成 `inline-block`
- 在 Flex 或 Grid 布局中改变子项表现

所以要记住：`display` 首先是布局属性，其次才经常被拿来做隐藏。

---

## 四、`visibility` 控制是否可见

### 1. 常见写法

```css
visibility: visible;
visibility: hidden;
```

### 2. `visibility: hidden` 的效果

- 元素看不见。
- 元素仍然保留原来的位置。
- 页面布局不会像 `display: none` 那样回收空间。

### 3. 和 `display: none` 的区别

| 属性                     | 是否可见 | 是否占位 | 典型用途                     |
| ------------------------ | -------- | -------- | ---------------------------- |
| **`display: none`**      | 否       | 否       | 折叠区域、切页、彻底移出布局 |
| **`visibility: hidden`** | 否       | 是       | 占位不变但暂时不显示         |

典型场景：

- 想隐藏按钮图标，但不希望按钮尺寸跳动。
- 想让表格某个单元格暂时不可见，但整体对齐不能乱。

---

## 五、`overflow` 处理溢出内容

`overflow` 不是让元素本身隐藏，而是决定盒子之外的内容怎么处理。

### 1. 常见取值

| 值            | 说明                     |
| ------------- | ------------------------ |
| **`visible`** | 默认值，溢出内容继续显示 |
| **`hidden`**  | 超出部分被裁掉           |
| **`scroll`**  | 总是显示滚动条           |
| **`auto`**    | 有需要时自动显示滚动条   |

```css
.box {
  width: 240px;
  height: 120px;
  overflow: auto;
}
```

### 2. 使用场景

| 场景                           | 推荐值    | 原因                 |
| ------------------------------ | --------- | -------------------- |
| **不想让内容撑坏布局**         | `hidden`  | 直接裁切超出部分     |
| **内容很多，需要用户滚动查看** | `auto`    | 只在必要时出现滚动条 |
| **固定需要滚动条布局**         | `scroll`  | 保持滚动区域稳定     |
| **调试溢出问题**               | `visible` | 方便观察真实溢出范围 |

### 3. 一个高频坑

如果容器上写了 `overflow: hidden`，内部的下拉菜单、阴影、绝对定位弹层、提示气泡可能会被直接裁掉。

这类问题本质上不是弹层没渲染，而是被父容器裁切了。

---

## 六、真实开发里怎么选

| 需求                         | 推荐方案             | 原因                 |
| ---------------------------- | -------------------- | -------------------- |
| **彻底隐藏，且不占位置**     | `display: none`      | 布局会回收空间       |
| **隐藏但保留原来的位置**     | `visibility: hidden` | 防止页面跳动         |
| **内容超出容器时裁切或滚动** | `overflow`           | 控制盒子外的显示方式 |

### 1. tab 切换

不同面板只显示当前项，其他面板通常用 `display: none`，因为它们不应该继续占据布局空间。

### 2. 占位骨架或按钮图标

如果隐藏后不希望尺寸变化，可以考虑 `visibility: hidden`。

### 3. 卡片内容截断

如果容器高度固定，可以通过 `overflow: hidden` 控制超出的内容不要撑开布局。

---

## 七、一个简单对比例子

```html
<div class="box box-a">A</div>
<div class="box box-b">B</div>
<div class="box box-c">C</div>
```

```css
.box {
  width: 120px;
  height: 40px;
  margin-bottom: 8px;
  background-color: #f5f5f5;
}

.box-b {
  display: none;
}

.box-c {
  visibility: hidden;
}
```

结果：

- `box-b` 完全不占位置，后面的元素会上移。
- `box-c` 虽然看不见，但空间还在。

这个区别在列表、表单、表格、导航切换里非常常见。

---

## 八、常见误区

| 误区                                          | 正确认识                                         |
| --------------------------------------------- | ------------------------------------------------ |
| **隐藏只有一种写法**                          | 其实要先分清是隐藏元素、隐藏可见性，还是处理溢出 |
| **`overflow: hidden` 只是裁边**               | 它还会影响弹层、阴影、滚动等行为                 |
| **`visibility: hidden` 很少用，所以可以不管** | 在需要保留占位的场景里很有用                     |
| **`display: none` 一定最好**                  | 它适合彻底移出布局，不适合所有场景               |

---

## 九、小结

| 知识点                   | 结论                                   |
| ------------------------ | -------------------------------------- |
| **`display: none`**      | 隐藏且不占位，适合彻底移出布局         |
| **`visibility: hidden`** | 隐藏但占位，适合避免布局跳动           |
| **`overflow`**           | 控制溢出内容显示、裁切或滚动           |
| **选择原则**             | 先判断是否保留布局位置，再决定用哪一种 |
