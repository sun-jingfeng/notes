# 定位

## 一、一句话理解

定位最适合解决的是“脱离常规排布后，元素该相对谁移动、该压在谁上面”这两个问题。

---

## 二、什么是定位

**定位（position）** 是 CSS 中用来精确控制元素位置的一组能力，适合处理“自由摆放”“覆盖叠层”“悬浮吸附”等场景。

**定位 = 定位模式 + 边偏移**。

| 组成         | 作用                                             |
| ------------ | ------------------------------------------------ |
| **定位模式** | 决定元素采用哪种定位方式                         |
| **边偏移**   | 用 `top`、`right`、`bottom`、`left` 指定最终位置 |

---

## 三、定位模式总览

`position` 常见取值如下：

| 值             | 含义             | 是否脱离文档流                   |
| -------------- | ---------------- | -------------------------------- |
| **`static`**   | 静态定位，默认值 | 否                               |
| **`relative`** | 相对定位         | 否                               |
| **`absolute`** | 绝对定位         | 是                               |
| **`fixed`**    | 固定定位         | 是                               |
| **`sticky`**   | 粘性定位         | 否，滚动到阈值后表现类似固定定位 |

边偏移属性：

```css
top
right
bottom
left
```

---

## 四、`static` 静态定位

静态定位是元素的默认定位方式，表示按照标准流正常排列。

```css
.box {
  position: static;
}
```

### 1. 特点

| 特点                     | 说明                        |
| ------------------------ | --------------------------- |
| **默认值**               | 大多数元素默认就是 `static` |
| **不支持边偏移定位效果** | 写 `top`、`left` 基本无意义 |
| **一般不主动写**         | 主要在覆盖其他定位时使用    |

---

## 五、`relative` 相对定位

相对定位表示：元素**相对于自己原来的位置**进行偏移。

```css
.box {
  position: relative;
  left: 20px;
  top: 10px;
}
```

### 1. 特点

| 特点                           | 说明                                 |
| ------------------------------ | ------------------------------------ |
| **不脱离文档流**               | 原来占的位置仍然保留                 |
| **参考自己原位置移动**         | 偏移后视觉位置变化，但文档流位置还在 |
| **常给绝对定位子元素当参照物** | 最典型用途是“子绝父相”               |

---

## 六、`absolute` 绝对定位

绝对定位表示：元素会脱离文档流，并相对于最近的“已定位祖先元素”进行定位。

```css
.child {
  position: absolute;
  top: 0;
  right: 0;
}
```

### 1. 参照物规则

绝对定位会优先寻找最近的、`position` 不为 `static` 的祖先元素作为定位参考。

如果祖先都没有定位，则默认相对于**初始包含块**（通常可理解为视口或页面根容器）定位。

### 2. 特点

| 特点                 | 说明                           |
| -------------------- | ------------------------------ |
| **脱离文档流**       | 不再占据原来的位置             |
| **参考最近定位祖先** | 常配合父元素的 `relative` 使用 |
| **适合局部自由摆放** | 角标、弹层、按钮浮层等         |

### 3. 子绝父相

“**子绝父相**”是最常见的定位组合：

- 子元素：`position: absolute`
- 父元素：`position: relative`

```html
<div class="card">
  <span class="badge">NEW</span>
</div>
```

```css
.card {
  position: relative;
}

.badge {
  position: absolute;
  top: 8px;
  right: 8px;
}
```

> **注意**：父元素用 `relative` 的核心目的，通常不是为了让自己移动，而是为了给绝对定位的子元素提供参考系。

---

## 七、`fixed` 固定定位

固定定位表示：元素相对于**浏览器可视区域**定位，页面滚动时位置通常保持不变。

```css
.back-top {
  position: fixed;
  right: 20px;
  bottom: 20px;
}
```

### 1. 特点

| 特点               | 说明                           |
| ------------------ | ------------------------------ |
| **脱离文档流**     | 不占原来的位置                 |
| **参考浏览器视口** | 通常不跟随页面滚动             |
| **常用于悬浮元素** | 返回顶部、悬浮客服、侧边工具栏 |

### 2. 固定在版心两侧的常见写法

右侧悬浮：

```css
.right-nav {
  position: fixed;
  left: 50%;
  margin-left: 620px;
}
```

左侧悬浮：

```css
.left-nav {
  position: fixed;
  right: 50%;
  margin-right: 620px;
}
```

其中 `620px` 一般表示“版心半宽 + 间距”。

---

## 八、`sticky` 粘性定位

粘性定位可以理解为“相对定位和固定定位的混合体”。

```css
.header {
  position: sticky;
  top: 0;
}
```

### 1. 特点

| 特点                     | 说明                      |
| ------------------------ | ------------------------- |
| **开始阶段像相对定位**   | 正常占位                  |
| **达到阈值后像固定定位** | 会吸附在指定位置          |
| **必须配合边偏移使用**   | 如 `top: 0`，否则不会生效 |

常见场景：

- 吸顶导航
- 表头吸附
- 分组标题吸附

---

## 九、定位与 z-index

当定位元素发生重叠时，可以通过 `z-index` 控制层叠顺序。

```css
.modal {
  position: fixed;
  z-index: 1000;
}
```

### 1. 规则

| 规则                    | 说明                            |
| ----------------------- | ------------------------------- |
| **值越大越靠上**        | 同一层叠上下文中成立            |
| **可以是负数、0、正数** | 默认是 `auto`                   |
| **不能带单位**          | 例如不能写 `100px`              |
| **通常作用于定位元素**  | `position` 非 `static` 时最常见 |

### 2. 层叠上下文（Stacking Context）

也叫堆叠上下文。当一个元素创建了新的层叠上下文后，它的子元素 `z-index` 只在这个上下文**内部**比较，不会直接和外部元素比较；对外则是整棵子树作为“一个整体”参与父级的层叠。

> **注意**：这也是很多“明明 `z-index` 很大却没盖住别的元素”的根本原因。

### 3. 哪些情况会创建层叠上下文

| 条件                                                        | 说明                          |
| ----------------------------------------------------------- | ----------------------------- |
| 根元素 `<html>`                                             | 页面的根层叠上下文            |
| **`position: fixed` / `sticky`**                            | **无条件创建，与 `z-index` 无关** |
| `position: relative` / `absolute` + `z-index` 不为 `auto`   | 最常被记住的那一条            |
| flex / grid 容器的子项 + `z-index` 不为 `auto`              | 子项自己不必是定位元素        |
| `opacity` 小于 `1`                                          |                               |
| `transform` / `filter` / `perspective` / `clip-path` / `mask` 不为 `none` |                  |
| `will-change` 声明了上面任意一个属性                        | 即使该属性当前并没有真的变化  |
| `isolation: isolate`                                        | 专门用来主动隔离层级          |
| `contain: layout` / `paint` / `strict` / `content`          |                               |
| `mix-blend-mode` 不为 `normal`                              |                               |

### 4. ⚠️ 纠正：`fixed` 不需要数字 `z-index`

**之前的错误理解**：只有“定位元素 + 数字 `z-index`”才创建层叠上下文，所以 `position: fixed` 且 `z-index: auto` 不创建。

那是 **CSS 2.1** 的规则。**CSS Positioned Layout Level 3** 之后，`fixed`（以及 `sticky`）改为**无条件**创建层叠上下文，Chrome / Safari / Firefox 都是这个行为。

实测（代码见下一节）：容器内放一个 `z-index: 10000` 的子元素，容器外放一个 `z-index: 1000` 的兄弟，其余条件全部不变，只切换容器的 `position`：

| 容器 `position` | 容器 `z-index` | 重叠处谁在上面   | 是否创建层叠上下文 |
| --------------- | -------------- | ---------------- | ------------------ |
| `static`        | `auto`         | 子元素（10000）  | 否                 |
| `relative`      | `auto`         | 子元素（10000）  | 否                 |
| `absolute`      | `auto`         | 子元素（10000）  | 否                 |
| **`fixed`**     | **`auto`**     | **兄弟（1000）** | **是**             |
| `sticky`        | `auto`         | 兄弟（1000）     | 是                 |
| `relative`      | `0`            | 兄弟（1000）     | 是                 |

关键对比：`absolute` 和 `fixed` 在同样的 `z-index: auto` 下结论相反。所以判断的第一步是看 `position` 取值，而不是看有没有写数字 `z-index`。

### 5. 最小复现

```html
<div class="host">
  <div class="inner">z-index: 10000</div>
</div>
<div class="sibling">z-index: 1000</div>
```

```css
/* 只改这一行的 position，其余都不动 */
.host {
  position: fixed;
}

.inner {
  position: fixed;
  inset: 100px auto auto 100px;
  z-index: 10000;
  width: 200px;
  height: 120px;
  background: green;
}

.sibling {
  position: fixed;
  inset: 160px auto auto 160px;
  z-index: 1000;
  width: 200px;
  height: 120px;
  background: red;
}
```

`.host` 为 `fixed` 时，红色（1000）盖住绿色（10000）；改成 `relative` 或 `absolute`（`z-index` 依然是 `auto`）时，绿色盖住红色。

### 6. 实践影响

| 场景                          | 说明                                                                     |
| ----------------------------- | ------------------------------------------------------------------------ |
| **弹层被外层导航 / tabbar 盖住** | 弹层的 `z-index` 被祖先的层叠上下文关住了，继续调大没有任何用           |
| **正确解法**                  | 把弹层传送到 `body`：Vue `<Teleport>`、React `createPortal`、小程序 `root-portal` |
| **排查顺序**                  | 从弹层往上找**第一个**创建层叠上下文的祖先，真正参与比较的是那个祖先的层级 |

> 常见的“隐形元凶”是祖先身上的 `transform`、`opacity: 0.99`、`filter`、`will-change` —— 看着人畜无害，却会静默地把整棵子树的 `z-index` 关起来。

## 十、常见定位技巧

### 1. 绝对定位实现盒子居中

```css
.dialog {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
}
```

> 💡 现代项目更推荐使用 `transform: translate(-50%, -50%)`，比负边距更灵活。
>
> ⚠️ 但要记得：`transform` 会创建层叠上下文（见第九节第 3 小节）。用它做居中的弹窗，内部子元素的 `z-index` 就被关在这个弹窗里了。

### 2. 绝对定位拉伸填充

当元素使用绝对定位时，可以通过同时指定两侧边偏移来拉伸：

```css
.overlay {
  position: absolute;
  top: 0;
  right: 0;
  bottom: 0;
  left: 0;
}
```

### 3. 行内元素变成可设宽高的盒子

行内元素在绝对定位或固定定位后，通常可以直接设置宽高。

## 十一、定位的常见注意事项

| 问题                   | 说明                                         |
| ---------------------- | -------------------------------------------- |
| **绝对定位元素不占位** | 可能导致父容器高度塌陷                       |
| **定位覆盖其他内容**   | 要结合 `z-index` 和层级结构分析              |
| **忘记给父元素加定位** | 子元素会相对错误的祖先或视口定位             |
| **`sticky` 不生效**    | 常见原因是没写 `top`，或祖先容器滚动环境特殊 |
| **堆叠层级混乱**       | 检查祖先是否创建了层叠上下文，注意 `fixed` / `sticky` 无条件创建 |

---

## 十二、什么时候优先用定位

| 布局方式   | 主要用途                     |
| ---------- | ---------------------------- |
| **标准流** | 常规上下/左右排列            |
| **浮动**   | 早期横向布局、文字环绕       |
| **定位**   | 精准摆放、覆盖层、吸附、悬浮 |

总结：定位最适合做“**自由移动和叠层展示**”，而不是所有布局都依赖定位。

---

## 十三、小结

| 知识点       | 结论                             |
| ------------ | -------------------------------- |
| **相对定位** | 不脱离文档流，相对自己移动       |
| **绝对定位** | 脱离文档流，相对最近定位祖先移动 |
| **固定定位** | 脱离文档流，相对视口定位         |
| **粘性定位** | 正常占位，到阈值后吸附           |
| **层叠控制** | 用 `z-index` 管理前后顺序，但只在同一层叠上下文内可比 |
