# 居中问题总结

## 一、一句话理解

居中从来不是一个固定写法问题，而是先判断“谁要居中、沿哪条轴、处在什么布局环境里”。

---

## 二、先建立一个正确心智

所谓“居中”，至少要先说清楚三个问题：

1. 是**水平居中**还是**垂直居中**。
2. 居中对象是**文本**、**行内元素**、**块级元素**，还是**绝对定位元素**。
3. 是只居中一个方向，还是做**水平垂直同时居中**。

很多“居中失效”，本质都是场景没分清。

---

## 三、最常见的居中场景总表

| 场景                     | 推荐做法                    | 说明               |
| ------------------------ | --------------------------- | ------------------ |
| **行内内容水平居中**     | `text-align: center`        | 给父元素设置       |
| **定宽块级元素水平居中** | `margin: 0 auto`            | 元素本身需要有宽度 |
| **单行文字垂直居中**     | `line-height = height`      | 只适合单行文本     |
| **多个元素水平垂直居中** | `flex`                      | 现代布局首选       |
| **二维完全居中**         | `grid` 或 `flex`            | 最稳妥             |
| **绝对定位元素居中**     | `left/top: 50% + transform` | 适合浮层、弹窗     |

---

## 四、水平居中

### 3.1 行内元素或行内块元素水平居中

如果目标元素本身处于行内排版环境中，最常用的是给父元素设置：

```css
.parent {
  text-align: center;
}
```

适用对象：

1. 文本
2. `span`
3. `a`
4. `img`
5. `inline-block` 标签

### 3.2 块级元素水平居中

如果目标是一个块级元素，并且宽度不是撑满整行，可以这样写：

```css
.box {
  width: 300px;
  margin: 0 auto;
}
```

### 3.3 `margin: 0 auto` 生效条件

1. 元素必须是块级格式化上下文中可居中的块。
2. 元素要有明确宽度，或者宽度不是自动撑满父元素。
3. 它不是浮动元素。

### 3.4 一个常见误区：浮动元素不能靠 `margin: 0 auto` 居中

原理上，元素一旦 `float`，就脱离普通块级居中那套规则了，所以“浮动元素水平居中”不是推荐场景。

更合理的做法通常是：

1. 不再用浮动，改成 `flex`。
2. 如果必须并排，优先用 `inline-block` 或 `flex` 替代浮动。

```css
.parent {
  display: flex;
  justify-content: center;
}
```

---

## 五、垂直居中

### 4.1 单行文字垂直居中

这是最经典也最局限的一种方式：

```css
.title {
  height: 40px;
  line-height: 40px;
}
```

它的原理是让行高等于盒子高度。

### 4.2 这种方式的限制

1. 只适合**单行文字**。
2. 文本一旦换行，效果就不对了。
3. 不适合复杂内容或多个子元素。

### 4.3 行内块元素和文字对齐

比如图标和文字并排时，经常使用：

```css
.icon {
  vertical-align: middle;
}

.text {
  vertical-align: middle;
}
```

这里的 `vertical-align` 不是“让元素在父容器里真正垂直居中”，而是**让同一行里的行内级元素彼此对齐**。

### 4.4 一个常见误解

`vertical-align: middle` 只对：

1. 行内元素
2. 行内块元素
3. 表格单元格

有意义。

它对普通块级元素通常不生效。

---

## 六、水平垂直同时居中

### 5.1 `flex` 是现代首选

```css
.parent {
  display: flex;
  justify-content: center;
  align-items: center;
}
```

| 属性                          | 作用       |
| ----------------------------- | ---------- |
| **`justify-content: center`** | 主轴居中   |
| **`align-items: center`**     | 交叉轴居中 |

适合场景：

1. 按钮内部内容居中
2. 卡片中的图文块居中
3. 页面局部区域居中
4. 弹窗主体居中

### 5.2 `grid` 也很适合做二维居中

```css
.parent {
  display: grid;
  place-items: center;
}
```

这是一种非常简洁的二维居中写法。

---

## 七、绝对定位元素居中

如果元素是绝对定位，比如浮层、弹窗、提示框，常见公式是：

```css
.modal {
  position: absolute;
  left: 50%;
  top: 50%;
  transform: translate(-50%, -50%);
}
```

### 6.1 为什么推荐 `transform`

旧写法经常是：

```css
left: 50%;
margin-left: -150px;
```

但它要求你提前知道元素宽度的一半，不够灵活。

而 `transform: translate(-50%, -50%)` 直接按元素自身尺寸偏移，更适合响应式和动态尺寸。

---

## 八、快速判断路径

可以直接按下面这条线选方案：

1. 先看是不是文本或行内内容。
2. 再看是不是定宽块级元素。
3. 如果要做双轴居中，优先想 `flex` / `grid`。
4. 如果目标元素已经脱离普通流，比如弹窗、浮层，再考虑定位 + `transform`。

这比死记“居中写法大全”更稳定。

---

## 九、不同场景下的推荐顺序

### 7.1 能用 `flex` 时优先用 `flex`

因为它：

1. 语义清晰。
2. 适应性强。
3. 同时适合单个元素和多个元素。

### 7.2 能用 `grid` 时可用 `grid`

特别适合单元素的二维居中。

### 7.3 `line-height` 只当作特定技巧

不要把它当万能垂直居中方案。

### 7.4 `vertical-align` 只解决“同行对齐”

它不是块级布局里的万能垂直居中属性。

---

## 十、常见错误总结

1. 给块级元素写 `text-align: center` 期待它本身居中。
2. 给没宽度的块级元素写 `margin: 0 auto`。
3. 给浮动元素写 `margin: 0 auto` 期待居中。
4. 给普通块级元素写 `vertical-align: middle`。
5. 用 `line-height` 处理多行内容垂直居中。

---

## 十一、小结

1. 居中问题要先区分方向和元素类型，再选方案。
2. 水平居中里，`text-align` 适合行内内容，`margin: 0 auto` 适合定宽块级元素。
3. 垂直居中里，`line-height` 只适合单行文本，`vertical-align` 只适合同一行的对齐。
4. 水平垂直同时居中时，现代项目优先使用 `flex` 或 `grid`。
5. 绝对定位元素居中时，优先用 `left/top: 50% + transform`，不要依赖写死的负边距。
