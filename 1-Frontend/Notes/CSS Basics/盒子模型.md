# 盒子模型

## 一、一句话理解

盒子模型真正解决的是：元素实际会占多大空间、内容和边框隔多远、盒子和盒子之间留多大距离。

---

## 二、什么是盒子模型

在 CSS 中，大多数元素都可以看成一个矩形盒子。网页布局的本质，很多时候就是在摆放这些盒子。

**盒子模型（Box Model）** 由四部分组成：

| 组成        | 说明                         |
| ----------- | ---------------------------- |
| **content** | 内容区域                     |
| **padding** | 内边距，内容到边框的距离     |
| **border**  | 边框                         |
| **margin**  | 外边距，盒子和盒子之间的距离 |

```text
margin
   border
      padding
         content
```

---

## 三、边框 `border`

边框由三部分组成：宽度、样式、颜色。

```css
border: 1px solid red;
```

### 1. 常见边框样式

| 值           | 说明   |
| ------------ | ------ |
| **`none`**   | 无边框 |
| **`solid`**  | 实线   |
| **`dashed`** | 虚线   |
| **`dotted`** | 点线   |

### 2. 常见写法

```css
border: 1px solid #333;
border-top: 2px solid red;
border-width: 4px;
border-color: skyblue;
```

### 3. 边框会影响盒子大小

如果元素已经设置了宽高，再加边框，视觉总尺寸会变大。

---

## 四、表格细线边框

表格常见需求之一是把相邻单元格边框合并。

```css
table {
  border-collapse: collapse;
}
```

| 属性                            | 作用               |
| ------------------------------- | ------------------ |
| **`border-collapse: collapse`** | 相邻边框合并成单线 |

---

## 五、内边距 `padding`

`padding` 表示内容和边框之间的距离。

```css
.box {
  padding: 20px;
}
```

### 1. 简写规则

| 写法                               | 含义                  |
| ---------------------------------- | --------------------- |
| **`padding: 20px`**                | 四边都是 20px         |
| **`padding: 10px 20px`**           | 上下 10px，左右 20px  |
| **`padding: 10px 20px 30px`**      | 上 10，左右 20，下 30 |
| **`padding: 10px 20px 30px 40px`** | 上右下左              |

### 2. padding 对尺寸的影响

当元素使用默认盒模型时，设置 `padding` 会把盒子撑大。

---

## 六、外边距 `margin`

`margin` 表示盒子与盒子之间的距离。

```css
.box {
  margin: 20px;
}
```

### 1. 简写规则

`margin` 的 1 到 4 值写法，和 `padding` 完全一致。

### 2. 让块级元素水平居中

前提：

1. 元素必须是块级元素
2. 必须指定宽度
3. 左右外边距设为 `auto`

```css
.container {
  width: 960px;
  margin: 0 auto;
}
```

> **注意**：行内元素或行内块元素想水平居中，通常是给父元素设置 `text-align: center`。

`margin` 的重点不是“加空白”，而是控制盒子与盒子之间的外部关系。

---

## 七、标准盒模型与 `box-sizing`

### 1. 默认盒模型：`content-box`

默认情况下，`width` 和 `height` 只计算内容区，不包含 `padding` 和 `border`。

### 2. 更常用的盒模型：`border-box`

```css
.box {
  box-sizing: border-box;
}
```

此时 `width` 和 `height` 包含内容、内边距和边框，更适合实际开发。

### 3. 对比

| 模式              | `width` / `height` 代表什么 |
| ----------------- | --------------------------- |
| **`content-box`** | 只算内容区                  |
| **`border-box`**  | 包含内容 + padding + border |

现代项目里更常见的思路是尽早统一为 `border-box`，这样尺寸心智更稳定。

### 4. 示例

```css
.c2 {
  width: 200px;
  height: 200px;
  padding: 20px;
  border: 10px solid #000;
}

.c3 {
  width: 200px;
  height: 200px;
  padding: 20px;
  border: 10px solid #000;
  box-sizing: border-box;
}
```

## 八、外边距合并

### 1. 相邻块元素垂直外边距合并

上下相邻的两个块级元素，如果一个有 `margin-bottom`，另一个有 `margin-top`，它们之间的实际距离通常不会相加，而是取较大值。

```css
.box1 {
  margin-bottom: 30px;
}

.box2 {
  margin-top: 50px;
}
```

最终两者间距通常是 `50px`，不是 `80px`。

### 2. 解决思路

| 方案                         | 说明             |
| ---------------------------- | ---------------- |
| **只给其中一个元素加外边距** | 最简单直接       |
| **引入新的 BFC**             | 适合某些复杂布局 |

---

## 九、外边距塌陷

### 1. 什么是父子外边距塌陷

当父元素和第一个子元素是嵌套块级关系，且子元素设置了 `margin-top`，父元素可能会一起被“带下来”。

```css
.parent {
  width: 400px;
  height: 400px;
  background-color: red;
}

.child {
  width: 100px;
  height: 100px;
  margin-top: 100px;
  background-color: green;
}
```

### 2. 常见解决方案

| 方案                                | 说明               |
| ----------------------------------- | ------------------ |
| **给父元素加上边框**                | 让父子不再直接贴合 |
| **给父元素加上内边距**              | 同样能打断塌陷     |
| **给父元素设置 `overflow: hidden`** | 常见且简单         |
| **让父元素形成 BFC**                | 更通用的解决思路   |

```css
.parent {
  overflow: hidden;
}
```

很多初学阶段觉得“margin 怎么不听话”，本质上都是还没分清外边距合并和外边距塌陷这两个问题。

---

## 十、真实开发里怎么排查尺寸问题

可以优先按这几个问题判断：

1. 这个元素的 `width/height` 算的是内容区，还是整个盒子。
2. 是 `padding` / `border` 把盒子撑大了，还是 `margin` 把外部间距拉开了。
3. 父子之间是不是发生了外边距塌陷。
4. 是否应该改成 `box-sizing: border-box` 统一计算方式。

---

## 十一、清除默认内外边距

浏览器默认会给很多元素添加内外边距，实际布局前常会先做初始化。

```css
* {
  margin: 0;
  padding: 0;
}
```

### 1. 注意事项

| 元素类型                  | 内外边距表现                                       |
| ------------------------- | -------------------------------------------------- |
| **行内元素**              | 左右内外边距通常有效，上下通常不按普通块级盒子表现 |
| **块级元素 / 行内块元素** | 上下左右内外边距都更容易体现                       |

---

## 十二、小结

| 知识点               | 结论                                   |
| -------------------- | -------------------------------------- |
| **盒子四部分**       | content、padding、border、margin       |
| **padding / border** | 默认会撑大盒子                         |
| **水平居中**         | 块级元素 + 指定宽度 + `margin: 0 auto` |
| **推荐盒模型**       | `box-sizing: border-box`               |
| **外边距问题**       | 需要理解合并与塌陷                     |
