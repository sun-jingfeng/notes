# HTML 表格

## 一、一句话理解

表格真正适合的是行列关系明确的数据展示，而不是拿来凑页面布局。

---

## 二、什么是表格

**表格（table）** 用于展示具有行列关系的数据，例如成绩单、商品列表、排班表、财务报表等。

它适合表达“结构化数据”，不适合拿来做整页布局。

---

## 三、表格的基本结构

```html
<table>
  <tr>
    <td>张三</td>
    <td>18</td>
  </tr>
</table>
```

| 标签        | 作用         |
| ----------- | ------------ |
| **`table`** | 表格容器     |
| **`tr`**    | 表格中的一行 |
| **`td`**    | 普通单元格   |

### 1. 最基础示例

```html
<table>
  <tr>
    <td>姓名</td>
    <td>年龄</td>
  </tr>
  <tr>
    <td>张三</td>
    <td>20</td>
  </tr>
</table>
```

---

## 四、表头单元格 `th`

`<th>` 表示表头单元格，常出现在第一行或第一列。

```html
<table>
  <tr>
    <th>姓名</th>
    <th>年龄</th>
  </tr>
  <tr>
    <td>张三</td>
    <td>20</td>
  </tr>
</table>
```

### 1. 特点

| 特点               | 说明                   |
| ------------------ | ---------------------- |
| **语义更明确**     | 表示标题或字段名       |
| **默认加粗并居中** | 浏览器通常自带默认样式 |

---

## 五、表格的结构化标签

为了让表格结构更清晰，HTML 还提供了分区标签。

| 标签        | 作用         |
| ----------- | ------------ |
| **`thead`** | 表头区域     |
| **`tbody`** | 主体数据区域 |
| **`tfoot`** | 表尾区域     |

```html
<table>
  <thead>
    <tr>
      <th>姓名</th>
      <th>年龄</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>张三</td>
      <td>20</td>
    </tr>
  </tbody>
</table>
```

### 1. 使用价值

| 价值             | 说明                   |
| ---------------- | ---------------------- |
| **结构清晰**     | 头部、主体、尾部分离   |
| **样式更好控制** | 可以按区域分别设置样式 |
| **可读性更强**   | 对复杂表格尤其重要     |

如果表格规模稍大，分区标签会明显提升结构可读性和后续样式维护效率。

---

## 六、表格属性

早期 HTML 会直接在标签上写表格样式属性，例如 `border`、`width`、`cellpadding`、`cellspacing`。现代开发中一般不推荐这样做，更推荐交给 CSS。

### 1. 旧写法示例

```html
<table border="1" width="500">
  ...
</table>
```

### 2. 现代推荐写法

```html
<table class="table-demo">
  ...
</table>
```

```css
.table-demo {
  width: 500px;
  border-collapse: collapse;
}

.table-demo td,
.table-demo th {
  border: 1px solid #ccc;
}
```

这体现的是一个基本原则：结构归 HTML，表现归 CSS。

## 七、合并单元格

表格支持跨行和跨列合并。

| 属性          | 作用     |
| ------------- | -------- |
| **`rowspan`** | 跨行合并 |
| **`colspan`** | 跨列合并 |

### 1. 跨列合并

```html
<table border="1">
  <tr>
    <th colspan="2">基本信息</th>
  </tr>
  <tr>
    <td>姓名</td>
    <td>张三</td>
  </tr>
</table>
```

### 2. 跨行合并

```html
<table border="1">
  <tr>
    <th>类别</th>
    <th>项目</th>
  </tr>
  <tr>
    <td rowspan="2">前端</td>
    <td>HTML</td>
  </tr>
  <tr>
    <td>CSS</td>
  </tr>
</table>
```

### 3. 合并单元格三步法

1. 确定是跨行还是跨列
2. 找到目标单元格，在目标单元格上写 `rowspan` 或 `colspan`
3. 删除被合并掉的多余单元格

> **注意**：目标单元格通常是“跨行时最上面的单元格”或“跨列时最左边的单元格”。

合并单元格最容易出错的地方，不是属性名写错，而是没有先画清楚最终表格结构。

---

## 八、表格的常见使用建议

| 建议                                   | 说明               |
| -------------------------------------- | ------------------ |
| **用于数据展示，不用于整体布局**       | 布局更适合使用 CSS |
| **复杂表格建议使用 `thead` / `tbody`** | 提升可维护性       |
| **样式尽量交给 CSS**                   | 避免结构和表现耦合 |

还可以补充两个常见意识：

1. 数据表格尽量让列语义明确。
2. 复杂表格要优先保证可读性，再考虑花哨效果。

---

## 九、什么时候该用表格，什么时候不该用

| 场景                           | 是否适合用表格 |
| ------------------------------ | -------------- |
| **成绩单、财务报表、排班信息** | 适合           |
| **整页栅格布局、导航栏布局**   | 不适合         |
| **后台列表页的结构化数据**     | 适合           |
| **普通内容排版**               | 不适合         |

---

## 十、小结

| 知识点         | 结论                         |
| -------------- | ---------------------------- |
| **基础结构**   | `table` + `tr` + `td`        |
| **表头单元格** | 用 `th` 表示                 |
| **结构分区**   | 用 `thead`、`tbody`、`tfoot` |
| **合并单元格** | 用 `rowspan` 和 `colspan`    |
| **现代实践**   | 表格负责语义，样式交给 CSS   |
