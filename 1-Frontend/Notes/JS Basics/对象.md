# 对象

## 一、一句话理解

对象最适合表达的是“一个具体事物有哪些数据、又能做哪些动作”，也就是把相关状态和行为组织到一起。

---

## 二、什么是对象

对象是 JavaScript 中最常见的引用类型，本质上是一组键值对，用来描述某个事物的属性和行为。

```js
const user = {
  name: "张三",
  age: 20,
  sayHi() {
    console.log("你好")
  },
}
```

| 组成 | 说明                           | 示例                   |
| ---- | ------------------------------ | ---------------------- |
| 属性 | 描述对象状态的数据             | `name`、`age`、`price` |
| 方法 | 挂在对象上的函数，用于描述行为 | `sayHi()`、`play()`    |

---

## 三、对象的创建方式

### 字面量方式

日常开发中最常用的是对象字面量。

```js
const phone = {
  brand: "Apple",
  color: "black",
  price: 6999,
}
```

### 构造函数方式

```js
const person = new Object()
person.name = "李四"
person.age = 22
```

通常优先使用字面量，因为语法更直观、代码更短。

---

## 四、对象的语法规则

```js
const 对象名 = {
  属性名: 属性值,
  方法名() {},
}
```

| 规则                           | 说明                               |
| ------------------------------ | ---------------------------------- |
| 键和值成对出现                 | 中间使用 `:` 分隔                  |
| 多个成员之间用 `,` 分隔        | 最后一个成员后一般不写逗号         |
| 属性名是合法标识符时可省略引号 | 例如 `name`、`age`                 |
| 特殊属性名需要加引号           | 例如 `'user-name'`、`'first name'` |

---

## 五、属性与方法

### 属性

属性一般表示对象的特征，通常是名词。

```js
const person = {
  name: "李四",
  height: 180,
  gender: "男",
}
```

### 方法

方法本质上是对象中的函数，用于描述行为。

```js
const person = {
  name: "李四",
  run() {
    console.log("正在跑步")
  },
}
```

---

## 六、对象属性的访问方式

### 点语法

属性名是普通标识符时，优先使用点语法。

```js
const goods = {
  name: "小米 14",
  price: 3999,
}

console.log(goods.name)
console.log(goods.price)
```

### 中括号语法

以下场景需要使用中括号：

| 场景               | 示例               |
| ------------------ | ------------------ |
| 属性名是变量       | `obj[key]`         |
| 属性名包含特殊字符 | `obj['user-name']` |
| 属性名是数字字符串 | `obj['0']`         |

```js
const key = "price"
const goods = {
  name: "小米 14",
  "user-name": "admin",
  price: 3999,
}

console.log(goods[key])
console.log(goods["user-name"])
```

注意：`obj['key']` 访问的是名为 `key` 的属性，`obj[key]` 访问的是变量 `key` 对应的属性名。

这个区别在遍历对象、动态取值和配置项读取里非常常见。

## 七、对象的增删改查

### 新增属性

```js
const user = {}
user.name = "王五"
user["age"] = 22
```

### 修改属性

```js
const user = {
  name: "王五",
  age: 22,
}

user.age = 23
```

### 删除属性

```js
const user = {
  name: "王五",
  age: 23,
}

delete user.age
```

### 查询属性是否存在

```js
const user = { name: "王五" }

console.log("name" in user) // true
console.log("age" in user) // false
```

## 八、遍历对象

### for...in

`for...in` 用于遍历对象中可枚举的属性名。

```js
const goods = {
  name: "小米 10",
  num: 100012816024,
  weight: "0.55kg",
  address: "中国大陆",
}

for (const key in goods) {
  console.log(key)
  console.log(goods[key])
}
```

| 写法           | 是否正确 | 说明                       |
| -------------- | -------- | -------------------------- |
| `goods[key]`   | 是       | `key` 是变量，应该用中括号 |
| `goods['key']` | 否       | 访问的是名为 `key` 的属性  |
| `goods.key`    | 否       | 访问的是固定属性 `key`     |

### Object.keys 和 Object.values

```js
const user = { name: "张三", age: 20 }

console.log(Object.keys(user))
console.log(Object.values(user))
```

如果你的目标是拿到数组再做遍历加工，`Object.keys()`、`Object.values()`、`Object.entries()` 往往比直接 `for...in` 更顺手。

## 九、对象中的方法与 this

```js
const user = {
  name: "张三",
  sayHi() {
    console.log("你好，我是" + this.name)
  },
}

user.sayHi()
```

在对象方法中，`this` 通常指向“点前面”的对象，也就是调用该方法的对象。

```js
const user = {}
user.login = function () {
  console.log("开始登录")
}

user.login()
```

## 十、对象与数组的区别

| 对比项   | 对象                   | 数组                    |
| -------- | ---------------------- | ----------------------- |
| 作用     | 描述事物的属性和行为   | 按顺序存储一组数据      |
| 键名     | 通常自定义             | 默认是从 `0` 开始的索引 |
| 访问方式 | `obj.name`、`obj[key]` | `arr[0]`、`arr[1]`      |

---

## 十一、真实开发里什么时候用对象

| 需求                                 | 更适合的结构    |
| ------------------------------------ | --------------- |
| **描述一个用户、一件商品、一条订单** | 对象            |
| **保存一组同类数据列表**             | 数组            |
| **既有列表又有每项详细字段**         | 数组 + 对象组合 |

很多初学阶段的问题，本质不是语法不会，而是没有先分清数据到底更像“一个事物”还是“一组事物”。

## 十二、常见注意点

### 属性名重复时，后面的值会覆盖前面的值

```js
const obj = {
  name: "张三",
  name: "李四",
}

console.log(obj.name) // 李四
```

### 对象是引用类型

```js
const obj1 = { count: 1 }
const obj2 = obj1

obj2.count = 2
console.log(obj1.count) // 2
```

这说明 `obj1` 和 `obj2` 指向的是同一块对象数据。

## 十三、内置对象 `Math`

`Math` 是 JavaScript 提供的内置对象，不需要 `new`，可以直接调用它的方法。

### 1. 常用方法

| 方法                 | 作用                   |
| -------------------- | ---------------------- |
| **`Math.random()`**  | 生成 $[0, 1)$ 的随机数 |
| **`Math.ceil()`**    | 向上取整               |
| **`Math.floor()`**   | 向下取整               |
| **`Math.max()`**     | 求最大值               |
| **`Math.min()`**     | 求最小值               |
| **`Math.pow(a, b)`** | 幂运算                 |
| **`Math.abs()`**     | 绝对值                 |

### 2. 生成任意范围随机数

```js
// 0 ~ 10 的整数
const num1 = Math.floor(Math.random() * 11)

// 5 ~ 10 的整数
const num2 = Math.floor(Math.random() * 6) + 5

// n ~ m 的整数（包含 n 和 m）
function getRandom(n, m) {
  return Math.floor(Math.random() * (m - n + 1)) + n
}
```

## 十四、对象 key 的遍历顺序

在现代 JavaScript 中，对象属性的遍历顺序是可预测的，但不建议业务逻辑强依赖它。

### 1. 整数字符串 key

会按数值从小到大排序：

```js
const data = {
  3: 1,
  2: 1,
  1: 1,
}

console.log(Object.keys(data)) // ['1', '2', '3']
```

### 2. 普通字符串 key

按插入顺序排列：

```js
const data = {
  name: "张三",
  age: 20,
  gender: "男",
}

console.log(Object.keys(data)) // ['name', 'age', 'gender']
```

### 3. 数字 key 和字符串 key 混用

先排整数字符串 key，再排普通字符串 key：

```js
const data = {
  gender: "男",
  2: "b",
  age: 20,
  3: "c",
  name: "张三",
  1: "a",
}

console.log(Object.keys(data)) // ['1', '2', '3', 'gender', 'age', 'name']
```

## 十五、小结

1. 对象是一组键值对，用来描述某个事物。
2. 对象由属性和方法组成，属性描述特征，方法描述行为。
3. 常用访问方式有点语法和中括号语法。
4. 可以对对象进行增删改查，也可以通过 `for...in`、`Object.keys()` 等方式遍历。
5. 对象方法里的 `this` 一般指向当前调用该方法的对象。

| 知识点       | 结论                             |
| ------------ | -------------------------------- |
| **对象本质** | 键值对集合                       |
| **属性访问** | 优先用 `.`，变量属性名用 `[]`    |
| **遍历对象** | 常用 `for...in`、`Object.keys()` |
| **方法**     | 本质是挂在对象上的函数           |
| **内置对象** | `Math` 等对象可直接调用          |
