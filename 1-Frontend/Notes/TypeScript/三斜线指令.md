# 三斜线指令

## 一、一句话理解

三斜线指令本质上是一种“当前文件级”的显式类型引入手段，用来补充编译器在这个文件里该额外认识哪些类型信息。

---

## 二、什么是三斜线指令

三斜线指令是 TypeScript 中一种特殊注释语法，用来显式告诉编译器去加载额外的类型信息。

常见写法有 3 类：

```ts
/// <reference path="./file-name.d.ts" />
/// <reference types="vite/client" />
/// <reference lib="DOM" />
```

### 1. 它的本质

不是普通注释，而是编译器能识别的指令。

### 2. 使用位置

通常需要放在文件顶部，才能按预期生效。

---

## 三、三种常见类型

### 1. `path`

```ts
/// <reference path="./global.d.ts" />
```

作用：引入某个具体声明文件。

适合：

1. 老项目。
2. 手动组织多个声明文件。
3. 某些不依赖模块解析的声明整合场景。

### 2. `types`

```ts
/// <reference types="vite/client" />
```

作用：引入某个第三方包提供的类型声明。

常见于：

1. Vite 项目。
2. 需要显式加载某类全局类型的工具库。

### 3. `lib`

```ts
/// <reference lib="DOM" />
```

作用：引入 TypeScript 内置标准库类型。

例如：

1. `DOM`
2. `ES2022`
3. `WebWorker`

---

## 四、现代项目里它还常用吗

大多数现代项目中，三斜线指令不是日常主力。

更常见的方式通常是：

1. `tsconfig.json` 配置。
2. 正常模块导入导出。
3. 在 `.d.ts` 文件中声明模块。

所以三斜线指令更多出现在：

1. 类型声明入口文件。
2. 某些需要强制引入全局类型的场景。
3. 兼容旧写法或特殊库声明。

也就是说，它现在更偏“特殊入口或声明场景工具”，而不是日常业务代码主力手段。

---

## 五、典型场景：声明文件之间建立关联

### 1. 示例

```ts
/// <reference path="./mitt.d.ts" />

declare module "mitt" {
  const a: number
}
```

另一份声明文件里再继续扩展：

```ts
declare module "mitt" {
  const b: string
}
```

这样在使用时就能拿到完整提示。

```ts
import mitt from "mitt"

mitt.a
mitt.b
```

---

## 六、和命名空间导出结合的场景

在某些旧式声明里，模块本身可能导出的是命名空间形式。

```ts
/// <reference path="./mitt.d.ts" />

declare namespace mitt {
  const a: number
}

export = mitt
```

然后再扩展：

```ts
declare module "./index" {
  const b: string
}
```

这类写法现在已经不算主流，但看旧库声明时仍然会遇到。

---

## 七、三斜线指令和 `tsconfig` 的关系

很多人会把两者混在一起，其实它们解决的问题层级不同：

| 手段            | 作用层级           |
| --------------- | ------------------ |
| 三斜线指令      | 当前文件级显式引入 |
| `tsconfig.json` | 项目级统一配置     |

如果能通过项目配置解决，通常优先用项目配置；只有在某些特殊入口或声明聚合场景下，才需要三斜线指令。

---

## 八、真实开发里怎么快速判断

| 场景                            | 更推荐的方式                    |
| ------------------------------- | ------------------------------- |
| **项目级统一类型配置**          | `tsconfig.json`                 |
| **普通模块间依赖**              | 正常 import / export            |
| **声明入口文件需要显式补类型**  | 三斜线指令                      |
| **Vite / 特定工具全局类型注入** | `/// <reference types="..." />` |

---

## 九、总结

1. 三斜线指令是 TypeScript 的特殊注释语法，用来显式引入额外类型信息。
2. 最常见的 3 种形式是 `path`、`types`、`lib`。
3. 它通常要写在文件顶部。
4. 现代项目里它不是高频主力，但在声明文件和兼容场景里依然有用。
5. 学这篇时，重点是知道它什么时候该用，什么时候不该滥用。
