# TypeScript组合类型基础

## 一、一句话理解

联合类型解决“可能是这几种之一”，交叉类型解决“必须同时满足这几种要求”，两者是 TypeScript 组合类型表达的基础。

---

## 二、联合类型

联合类型表示“一个值可以是多种类型中的某一种”，可以把它理解成“或”。

```ts
let strOrNum: string | number

strOrNum = "abc"
strOrNum = 123
```

### 1. 核心特征

在没有进一步缩小类型前，你只能使用这些类型**共同拥有**的成员。

```ts
let value: string | number
value = Math.random() > 0.5 ? "abc" : 123

value.toString() // 允许
// value.toFixed(2) // 不一定允许
// value.charAt(0) // 不一定允许
```

### 2. 类型缩小

当你通过判断把类型范围缩小后，就可以使用对应类型的方法。

```ts
if (typeof value === "string") {
  value.charAt(0)
} else {
  value.toFixed(2)
}
```

这就是 TypeScript 中非常重要的**类型缩小（narrowing）**。

---

## 三、联合类型的常见场景

### 1. 有限状态值

```ts
type Status = "idle" | "loading" | "success" | "error"
```

### 2. 参数可能有多种输入

```ts
function format(input: string | number) {
  return String(input)
}
```

### 3. 接口返回多种结果

```ts
type Result =
  | { success: true; data: string }
  | { success: false; message: string }
```

这种写法也叫**可辨识联合类型**，在实际业务里很常见。

---

## 四、联合类型中的函数

函数联合类型是 TypeScript 里稍微绕一点的内容。

### 1. 返回值通常会形成联合

```ts
type Fn = (() => string) | (() => number) | (() => boolean)

type R = ReturnType<Fn> // string | number | boolean
```

### 2. 参数提取要注意分发

```ts
type Fn =
  | ((p: { a: string }) => void)
  | ((p: { b: number }) => void)
  | ((p: { c: boolean }) => void)

type MyParameters<T> = T extends (p: infer P) => any ? P : never
type P = MyParameters<Fn>
```

此时 `P` 会是：

```ts
{ a: string } | { b: number } | { c: boolean }
```

这个知识点本质上和条件类型的分发行为有关。

---

## 五、交叉类型

交叉类型表示“同时满足多个类型要求”，可以把它理解成“且”。

```ts
type Person1 = {
  handsome: boolean
}

type Person2 = {
  tall: boolean
}

type Person = Person1 & Person2
```

此时 `Person` 必须同时拥有 `handsome` 和 `tall`。

### 1. 对象结构合并

```ts
const person: Person = {
  handsome: true,
  tall: true,
}
```

### 2. 深层对象也会继续合并

```ts
type UserInfo1 = {
  address: {
    province: string
  }
}

type UserInfo2 = {
  address: {
    city: string
  }
}

type UserInfo = UserInfo1 & UserInfo2
```

结果要求 `address` 同时具备 `province` 和 `city`。

---

## 六、交叉类型的冲突

如果相同属性的类型彼此冲突，结果可能会变成 `never`。

```ts
type T1 = {
  name: number
}

type T2 = {
  name: string
}

type T3 = T1 & T2
```

这里 `T3["name"]` 实际上会变成 `never`，因为一个值不可能既是 `number` 又是 `string`。

这也是为什么交叉类型不是“无脑合并”，而是“取两边都满足的结果”。

所以一旦交叉结果看起来很怪，优先检查是不是同名属性之间本来就冲突。

---

## 七、联合与交叉的对比

| 对比项   | 联合类型 `\|`      | 交叉类型 `&` |
| -------- | ------------------ | ------------ |
| 含义     | 满足其中一种       | 同时满足多种 |
| 理解方式 | 或                 | 且           |
| 常见场景 | 多种输入、多种状态 | 组合对象能力 |

### 1. 一个直观例子

```ts
type A = { name: string }
type B = { age: number }

type U = A | B
type I = A & B
```

1. `U` 表示要么只有 `name`，要么只有 `age`。
2. `I` 表示必须同时有 `name` 和 `age`。

---

## 八、联合类型之间的交叉

两个联合类型做交叉时，结果可以理解为“取可同时成立的交集”。

```ts
type T1 = 1 | 2 | 3
type T2 = 2 | 3 | 4
type T3 = T1 & T2 // 2 | 3
```

再例如：

```ts
type T4 = "name" | "age" | true | 2
type T5 = string
type T6 = T4 & T5 // "name" | "age"
```

如果完全没有交集，就会得到 `never`。

---

## 九、函数类型的交叉

函数交叉类型常常表现为“重载效果”。

```ts
type Fn = ((p: number) => number) &
  ((p: string) => string) &
  ((p: boolean) => boolean)

declare const fn: Fn

fn(123)
fn("abc")
fn(true)
```

这类写法在高级类型设计里会出现，但日常业务开发中不算高频。

---

## 十、真实开发里怎么快速判断

| 需求                       | 更适合的类型表达    |
| -------------------------- | ------------------- |
| **值可能是多种输入之一**   | 联合类型            |
| **对象要同时具备多组能力** | 交叉类型            |
| **多种状态分支处理**       | 联合类型 + 判别字段 |
| **结构组合后成员冲突明显** | 先检查交叉是否合理  |

---

## 十一、总结

1. 联合类型表示“多选一”，交叉类型表示“全部满足”。
2. 联合类型最关键的是类型缩小，交叉类型最关键的是理解合并后的约束结果。
3. 交叉类型遇到冲突属性时，可能得到 `never`。
4. 这两者是 TypeScript 复杂类型表达的基础能力。
5. 学这篇时，不要只背 `|` 和 `&`，要重点理解它们背后的值域关系。
