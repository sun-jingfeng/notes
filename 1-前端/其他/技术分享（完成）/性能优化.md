## 函数切片

参考： 生成器函数

示例代码

> 1 // 复杂代码

> 2 function* complexCalculate() {

> 3 let count = 0

> 4 const start = performance.now()

> 5 while (performance.now() - start <= 5000) {

> 6 yield count++

> 7 }

> 8 return count

> 9 }

10

> 11 // 将复杂代码切片为异步函数

> 12 function timeSlice(): Promise<number> {

> 13 return new Promise(resolve => {

> 14 const iteratorFn = complexCalculate()

> 15 const recursion = () => {

> 16 const start = performance.now()

> 17 let result: IteratorResult<unknown, number>

> 18 do {

> 19 result = iteratorFn.next()

> 20 } while (!result.done && performance.now() - start < 16) // 切片为 16ms 长度的任务

> 21 if (result.done) {

> 22 resolve(result.value)

> 23 } else {

> 24 requestAnimationFrame(recursion)

> 25 }

> 26 }

> 27 recursion()

> 28 })

> 29 }

## 说明

- 将原本的长任务切片成多个短任务

- 会降低执行效率，切片越小效率越低

## 其他性能优化点

## 避免不必要的响应式数据转换

## 数据整体无需响应

- 不使用响应式api，直接声明

## 数据部分无需响应

   - markRaw()

   - shallowRef()

   - shallowReactive()

- 使用css或requestAnimationFrame绘制动画

中断已经不需要了的请求

   - AbortController

- 减少排列、绘制：使用transform实现移动效果、合并dom操作

- 避免强制排列

   - 避免大型、复杂的布局和布局抖动

- 页面缓存后关闭侦听器

- 按需加载、页面缓存

- 高频操作节流处理，例如滚动、移动事件

- 让传给子组件的 props 尽量保持稳定，参考Props 稳定性

- 使用v-once、v-memo
