# 权限控制

## 概念：基于角色的权限控制

- RBAC 的核心是先将权限分配给角色，再将角色分配给用户，用户访问资源时再根据角色校验权限。

---

## 基本思路

- 将所有权限存储到后端
- 将权限分配给角色，再将角色分配给用户
- 页面初始化时，先获取用户的权限，然后根据用户的权限确定其可以访问的页面

---

## 实现

### 页面权限控制

- 初始路由
  - 步骤
    - 将页面路由分成两部分：权限页面路由、非权限页面路由
    - 路由对象初始化时，只注册非权限路由
  - 示例代码

### userStore

步骤

声明用户权限信息

---

## 声明根据用户权限信息递归过滤后的权限页面路由

## 示例代码

```ts
type IState = {
  userinfo: IPickResponse<typeof getUserinfoApi> | null
}

type IGetters = {}

type IActions = {
  getAuthorityRoutesList(
    dynamicRoutes?: RouteRecordRaw[],
    basePath?: string,
  ): RouteRecordRaw[]
}

export const useUserStore = defineStore<string, IState, IGetters, IActions>(
  "user",
  {
    state: () => ({
      userinfo: null,
    }),
    getters: {},
    actions: {
      getAuthorityRoutesList(
        dynamicRoutes: RouteRecordRaw[] = getDynamicRoutes(),
        basePath = "/",
      ) {
        const result: RouteRecordRaw[] = []

        dynamicRoutes.forEach(route => {
          const routePath = path.resolve(basePath, route.path)

          if (route.children) {
            route.children = this.getAuthorityRoutesList(
              route.children,
              routePath,
            )
            if (route.children?.length) {
              route.redirect = path.resolve(basePath, route.children[0].path)
            }
          }

          if (
            !CONFIG.authorityRoute ||
            route.children?.length ||
            this.userinfo?.authorityPathsList?.includes?.(routePath)
          ) {
            result.push(route)
          }
        })

        return result
      },
    },
  },
)
```

### 路由守卫

- 步骤
  - 判断是否获取了用户的权限信息，未获取则同步获取
  - 将过滤后的权限页面路由注册到路由对象
  - 跳转到登录页时，清除用户权限信息、清除已注册的权限页面路由
- 示例代码

```ts
let removeRouteList: ReturnType<typeof router.addRoute>[] = []

router.beforeEach(async to => {
  const userStore = useUserStore()

  if (getToken()) {
    if (!userStore.userinfo) {
      try {
        const { data: res } = await getUserinfoApi()
        userStore.userinfo = res
        userStore
          .getAuthorityRoutesList()
          .forEach(route => removeRouteList.push(router.addRoute(route)))
        return to.path
      } catch (error: any) {
        console.error(error)
        removeToken()
        return `/login${to.path === "/" ? "" : `?redirect=${to.path}`}`
      }
    }

    if (to.path === "/login") {
      return "/"
    } else {
      return true
    }
  } else {
    if (to.path === "/login") {
      userStore.userinfo = null
      removeRouteList.forEach(item => item())
      removeRouteList = []
      return true
    } else {
      return `/login${to.path === "/" ? "" : `?redirect=${to.path}`}`
    }
  }
})
```

### 动态导航

## 在过滤后的权限页面路由中，找到目标路由数组，循环生成导航

```ts
export const getRoutesList = (): {
  label: string
  routeName: string
}[] =>
  useUserStore()
    .getAuthorityRoutesList()
    .find(route => route.path === "/")
    ?.children?.map(route2 => ({
      label: route2.meta?.pageName ?? "",
      routeName: (route2.name ?? "") as string,
    })) ?? []
```

### 一键同步权限

## 说明

- 需要将全部权限存储到后端，以用来在其他页面编辑角色权限
- 存储的权限至少包含以下信息：权限名称、权限层级关系、相同层级权限的顺序
- 步骤
  - 获取后端存储的权限
  - 获取前端全部权限
  - 删掉后端多出的权限
  - 新增前端多出的权限

---

## 示例代码

```ts
const syncAuthority = async () => {
  try {
    const authorityList = (await getAuthorityListApi()).data
    const wholeAuthorityList = getWholeAuthorityList()
    const discardAuthorityList = authorityList
      .filter(
        item =>
          !wholeAuthorityList.find(
            item2 =>
              item2.path === item.path &&
              item2.pageName === item.pageName &&
              item2.order === item.order,
          ),
      )
      .map(item => item.id)

    const newAuthorityList = wholeAuthorityList.filter(
      item =>
        !authorityList.find(
          item2 =>
            item2.path === item.path &&
            item2.pageName === item.pageName &&
            item2.order === item.order,
        ),
    )

    await deleteAuthority(discardAuthorityList)
    await addAuthority(newAuthorityList)
    ElMessage.success("同步成功！")
  } catch (error: any) {
    ElMessage.error(error.msg || "同步失败！")
    console.error(error)
  }
}

const getWholeAuthorityList = (
  dynamicRoutes: RouteRecordRaw[] = getDynamicRoutes(),
  basePath: string = "",
): Parameters<typeof addAuthorityApi>[0][] => {
  const result: Parameters<typeof addAuthorityApi>[0][] = []

  dynamicRoutes.forEach((route, index) => {
    const routePath = path.resolve(basePath, route.path)
    result.push({
      path: routePath,
      pageName: route.meta?.pageName ?? `未命名：${routePath}`,
      order: index + 1,
    })

    if (route.children?.length) {
      result.push(...getWholeAuthorityList(route.children, routePath))
    }
  })

  return result
}

const deleteAuthority = async (idList: string[]) => {
  idList.length && (await deleteAuthorityApi(idList))
}

const addAuthority = async (
  dataList: Parameters<typeof addAuthorityApi>[0][],
) => {
  const proList: Promise<unknown>[] = []
  dataList.length &&
    dataList.forEach(item => proList.push(addAuthorityApi(item)))
  await Promise.all(proList)
}
```
