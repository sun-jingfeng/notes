# CSS 基础选择器

## 一、一句话理解

选择器解决的不是“能不能选到元素”，而是“用什么方式选元素更稳、更易维护、更不容易误伤别的结构”。

---

## 二、什么是选择器

**选择器（Selector）** 用来告诉浏览器：“我要给哪些 HTML 元素应用样式”。

CSS 规则的基本结构如下：

```css
选择器 {
  属性: 值;
}
```

例如：

```css
p {
  color: red;
}
```

这段代码的意思是：把所有 `p` 标签文字设置为红色。

---

## 三、基础选择器分类

基础选择器是最常用的一组选择器，主要包括以下几种：

| 选择器           | 写法   | 作用               |
| ---------------- | ------ | ------------------ |
| **标签选择器**   | `div`  | 选择所有同名标签   |
| **类选择器**     | `.box` | 选择指定类名的元素 |
| **id 选择器**    | `#app` | 选择指定 id 的元素 |
| **通配符选择器** | `*`    | 选择所有元素       |

---

## 四、标签选择器

标签选择器，也叫元素选择器，直接使用 HTML 标签名作为选择器。

```css
div {
  color: blue;
}
```

### 1. 特点

| 特点                 | 说明                                 |
| -------------------- | ------------------------------------ |
| **书写简单**         | 直接写标签名即可                     |
| **影响范围大**       | 会选中页面中所有同类标签             |
| **适合统一基础样式** | 如统一设置 `p`、`a`、`li` 的基础表现 |

### 2. 优缺点

| 维度     | 说明                     |
| -------- | ------------------------ |
| **优点** | 快速给同类元素统一加样式 |
| **缺点** | 不适合做差异化样式       |

---

## 五、类选择器

类选择器是前端开发中使用最频繁的选择器之一，用 `.` 开头。

```css
.red {
  color: red;
}
```

```html
<div class="red">这段文字会变红</div>
```

### 1. 特点

| 特点                     | 说明                         |
| ------------------------ | ---------------------------- |
| **复用性强**             | 多个元素可共用同一个类       |
| **适合差异化样式**       | 比标签选择器更灵活           |
| **是工程中最常见的写法** | 页面样式通常主要依赖类名组织 |

### 2. 命名建议

| 建议                       | 说明                                 |
| -------------------------- | ------------------------------------ |
| **见名知意**               | 如 `card`、`nav-item`、`btn-primary` |
| **使用英文或英文组合**     | 避免中文、纯数字                     |
| **多个单词可用中横线连接** | 如 `user-avatar`                     |

### 3. 一个更重要的认知

现代样式组织的主力通常是类选择器，而不是标签选择器和 id 选择器，因为它最适合做组件化和可复用样式。

---

## 六、多类名

一个元素可以同时拥有多个类名，各类样式会共同生效。

```html
<div class="red font20 bold">这段文字有多个类名</div>
```

### 1. 使用规则

| 规则                     | 说明         |
| ------------------------ | ------------ |
| **多个类名用空格分隔**   | 不能用逗号   |
| **一个元素可以有多个类** | 便于组合样式 |

### 2. 常见场景

把“公共样式”和“个性样式”拆开：

```html
<div class="font20 primary">标题</div>
<div class="font20 danger">警告</div>
```

```css
.font20 {
  font-size: 20px;
}

.primary {
  color: #409eff;
}

.danger {
  color: #f56c6c;
}
```

这种方式能减少重复 CSS，提高复用性。

多类名的核心价值是组合，而不是把所有样式都塞进一个超长类名里。

---

## 七、id 选择器

id 选择器用 `#` 开头，用来选择拥有特定 id 的元素。

```css
#header {
  background-color: #f5f5f5;
}
```

```html
<div id="header">头部区域</div>
```

### 1. 特点

| 特点                   | 说明                                   |
| ---------------------- | -------------------------------------- |
| **唯一性强**           | 一个页面中同一个 id 理论上只应出现一次 |
| **权重较高**           | 高于类选择器                           |
| **常用于页面唯一节点** | 如根节点、锚点、某些脚本定位节点       |

### 2. 和类选择器的区别

| 对比项       | 类选择器     | id 选择器                   |
| ------------ | ------------ | --------------------------- |
| **写法**     | `.className` | `#idName`                   |
| **复用性**   | 可重复使用   | 通常只使用一次              |
| **应用场景** | 样式组织主力 | 页面唯一元素、锚点、JS 定位 |

> **注意**：现代工程化开发里，样式通常优先用类选择器，id 更常用于唯一标识和脚本操作。

---

## 八、通配符选择器

通配符选择器使用 `*`，表示选择页面中的所有元素。

```css
* {
  margin: 0;
  padding: 0;
}
```

### 1. 常见用途

| 用途             | 说明                  |
| ---------------- | --------------------- |
| **初始化样式**   | 批量清除默认内外边距  |
| **统一基础规则** | 例如统一 `box-sizing` |

### 2. 注意事项

通配符选择器影响范围极大，虽然写法方便，但不应滥用。

---

## 九、基础选择器如何选择

| 需求                       | 推荐选择器   |
| -------------------------- | ------------ |
| **给所有同类标签统一样式** | 标签选择器   |
| **给部分元素设置复用样式** | 类选择器     |
| **选择页面唯一元素**       | id 选择器    |
| **批量做初始化**           | 通配符选择器 |

实际开发中，**类选择器通常使用最多**。

---

## 十、常见误区

| 误区                               | 正确认识                           |
| ---------------------------------- | ---------------------------------- |
| **id 选择器更强，所以更好用**      | 权重高不等于更适合作为主力样式方案 |
| **标签选择器更简单，所以可以多写** | 范围太大，后期容易误伤             |
| **类名越长越安全**                 | 更重要的是语义清晰和可组合         |
| **通配符方便，所以到处都能用**     | 只适合初始化这类全局场景           |

## 十一、小结

| 知识点           | 结论                       |
| ---------------- | -------------------------- |
| **标签选择器**   | 适合统一设置某类标签样式   |
| **类选择器**     | 最灵活、最常用             |
| **多类名**       | 便于组合公共样式和个性样式 |
| **id 选择器**    | 适合唯一元素，权重较高     |
| **通配符选择器** | 常用于初始化，不宜滥用     |
