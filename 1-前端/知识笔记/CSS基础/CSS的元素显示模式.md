# CSS 的元素显示模式

## 一、一句话理解

元素显示模式决定了元素默认怎么排、能不能并排、宽高是否可控，以及很多“看起来像样式没生效”的问题为什么会发生。

---

## 二、什么是元素显示模式

**元素显示模式** 指元素在页面中的基本排布方式，也就是它默认如何参与文档流、是否独占一行、宽高是否可直接设置。

传统入门里通常把元素分成三类：

1. 块级元素
2. 行内元素
3. 行内块元素

虽然现代布局更多依赖 `flex`、`grid`，但理解这三类基础模式仍然很重要，因为很多默认行为、间距问题和布局异常都和它们有关。

---

## 三、三种基础显示模式对比

| 模式           | 是否独占一行 | 能否直接设置宽高 | 默认宽度           | 典型元素                 |
| -------------- | ------------ | ---------------- | ------------------ | ------------------------ |
| **块级元素**   | 是           | 可以             | 撑满父容器可用宽度 | `div`、`p`、`ul`、`li`   |
| **行内元素**   | 否           | 一般不可以       | 由内容撑开         | `span`、`a`、`strong`    |
| **行内块元素** | 否           | 可以             | 由内容撑开         | `img`、`input`、`button` |

---

## 四、块级元素

### 3.1 一句话理解

**块级元素** 默认会从新的一行开始排列，并尽可能占满父容器的可用宽度。

### 3.2 常见元素

1. `div`
2. `p`
3. `h1` 到 `h6`
4. `ul`、`ol`、`li`
5. `section`、`article`、`header`、`footer`

### 3.3 核心特点

1. 默认独占一行。
2. 可以直接设置 `width`、`height`。
3. `margin`、`padding` 都能正常生效。
4. 在未设置宽度时，通常会占满父元素的可用宽度。

### 3.4 典型例子

```html
<div class="box">内容</div>
```

```css
.box {
  width: 300px;
  height: 100px;
  margin: 20px auto;
  background: #f5f5f5;
}
```

### 3.5 注意事项

像 `p`、`h1` 这类偏文本语义的元素，虽然是块级元素，但不应该在里面随意嵌套其他块级结构，尤其不要写出语义和结构都混乱的嵌套。

---

## 五、行内元素

### 4.1 一句话理解

**行内元素** 默认和文本一起在同一行内排布，更适合承载文字、强调、链接这类“行内语义”。

### 4.2 常见元素

1. `span`
2. `a`
3. `strong`
4. `em`
5. `i`
6. `b`
7. `u`

### 4.3 核心特点

1. 默认不会独占一行。
2. 多个行内元素会从左到右排列。
3. 宽高通常不能直接按预期生效。
4. 宽度默认由内容决定。

### 4.4 典型问题

```html
<span class="label">标签</span>
```

```css
.label {
  width: 200px;
  height: 40px;
  background: pink;
}
```

这时背景能看到，但 `width`、`height` 通常不会像块级元素那样真正控制盒子。

### 4.5 注意事项

1. `a` 标签里不要再嵌套另一个 `a`。
2. 行内元素更适合包裹文字或少量短内容，不适合直接承担复杂布局。
3. 如果行内元素需要可控宽高或更大的点击区域，通常要改成 `inline-block` 或 `block`。

---

## 六、行内块元素

### 5.1 一句话理解

**行内块元素** 同时具备“可以和别的元素并排显示”和“宽高可控”两个特征。

### 5.2 常见元素

1. `img`
2. `input`
3. `button`
4. `textarea`
5. `select`

### 5.3 核心特点

1. 可以和其他行内或行内块元素处于同一行。
2. 宽高可以直接设置。
3. 默认宽度通常由内容或自身属性决定。
4. 元素之间常出现“空白缝隙”。

### 5.4 为什么会有缝隙

因为行内块元素仍然参与行内排版，HTML 中的换行、空格会被当作字符间距处理。

```html
<img src="a.png" alt="" /> <img src="b.png" alt="" />
```

这两个标签之间的换行或空格，可能就会形成视觉缝隙。

### 5.5 常见解决办法

1. 去掉标签之间的换行和空格。
2. 给父元素设置 `font-size: 0`。
3. 更现代的方案是直接改用 `flex` 布局。

---

## 七、为什么要理解显示模式

很多初学者遇到的问题，本质都不是“CSS 没生效”，而是**元素默认显示模式和预期不一致**。

例如：

1. 为什么 `span` 设宽度没反应。
2. 为什么 `img` 和文字对不齐。
3. 为什么两个按钮之间有奇怪空隙。
4. 为什么某个元素明明没写宽度却占满整行。

这些问题都和显示模式直接相关。

## 八、元素显示模式转换

有时元素本身语义正确，但默认显示模式不适合当前布局，这时可以通过 `display` 转换。

### 7.1 常见转换

```css
.link-block {
  display: block;
}

.title-inline {
  display: inline;
}

.tag {
  display: inline-block;
}
```

| 写法                        | 作用           |
| --------------------------- | -------------- |
| **`display: block`**        | 转为块级元素   |
| **`display: inline`**       | 转为行内元素   |
| **`display: inline-block`** | 转为行内块元素 |

### 7.2 典型应用

#### 让链接可点击区域更大

```css
a.nav-item {
  display: block;
  padding: 12px 16px;
}
```

#### 让多个标签并排且宽高可控

```css
.badge {
  display: inline-block;
  padding: 4px 10px;
}
```

### 7.3 一个重要边界

`display` 改的是展示和排布方式，不会改变标签本身的语义。

---

## 九、现代布局里的补充理解

虽然 `display: block / inline / inline-block` 是基础，但真实项目中很多布局会进一步使用：

1. `display: flex`
2. `display: grid`
3. `display: none`

它们已经超出了“基础显示模式”的最小范畴，但本质上仍然是在重新定义元素的显示与排布方式。

现代布局虽然常用 `flex`、`grid`，但很多异常还是要先回到最基础的问题上排查：这个元素默认到底是块级、行内，还是行内块。

---

## 十、真实开发里的选择思路

| 需求                       | 常见选择       |
| -------------------------- | -------------- |
| **做页面结构、大块容器**   | 块级元素       |
| **包裹局部文字和行内语义** | 行内元素       |
| **既想并排，又想控制宽高** | 行内块元素     |
| **做现代一维或二维布局**   | `flex`、`grid` |

## 十一、小结

1. 块级元素适合做结构和大块布局，默认独占一行。
2. 行内元素适合承载文字语义，默认宽度由内容决定。
3. 行内块元素兼具“并排显示”和“宽高可控”的特征。
4. 很多常见样式问题，本质是没有先判断元素的默认显示模式。
5. 需要时可以通过 `display` 转换元素模式，但应先保证语义是正确的。
