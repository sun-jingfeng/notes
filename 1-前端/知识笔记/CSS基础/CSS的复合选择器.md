# CSS 复合选择器

## 一、一句话理解

复合选择器的核心不是“记住写法”，而是根据元素之间的关系、元素自身的条件、以及元素状态，精确地把样式打到正确目标上。

---

## 二、复合选择器解决什么问题

基础选择器回答的是“选谁”，复合选择器回答的是“在什么关系下选谁”。

例如：

- 只想选某个区域里的链接。
- 只想选某个容器的直接子元素。
- 只想选同时具有某个标签和类名的元素。
- 只想在鼠标移入、输入框聚焦时生效。

所以复合选择器本质上是在缩小命中范围，减少误伤。

---

## 三、常见复合选择器

### 1. 后代选择器

后代选择器中间用空格，表示“某元素内部所有层级的后代”。

```css
.nav a {
  color: #333;
}
```

这表示：选中 `.nav` 里面所有层级的 `a` 元素。

| 特点                     | 说明                                   |
| ------------------------ | -------------------------------------- |
| **范围较广**             | 直接子元素、孙元素、曾孙元素都可能命中 |
| **书写简单**             | 最常用，但也最容易选太宽               |
| **最终命中的是最后一项** | `.nav a` 真正被选中的是 `a`            |

适用场景：

- 某块区域中的统一文字颜色
- 某个模块内部的通用样式
- 层级不固定的内容区

### 2. 子代选择器

子代选择器中间用 `>`，只选直接子元素。

```css
.menu > li {
  margin-right: 16px;
}
```

| 特点                     | 说明                       |
| ------------------------ | -------------------------- |
| **范围更精确**           | 只匹配第一层子元素         |
| **更适合结构明确的组件** | 比如导航、卡片列表、表格行 |
| **对 DOM 结构更敏感**    | 一旦中间多包一层就匹配不到 |

和后代选择器的区别：

| 写法             | 作用范围                         |
| ---------------- | -------------------------------- |
| **`.menu li`**   | 选中 `.menu` 内所有层级的 `li`   |
| **`.menu > li`** | 只选中 `.menu` 的直接子元素 `li` |

### 3. 并集选择器

并集选择器用逗号连接，表示“这些选择器都应用同一套规则”。

```css
h1,
h2,
h3 {
  font-weight: 600;
}
```

| 特点                 | 说明                     |
| -------------------- | ------------------------ |
| **表示或关系**       | 任意一个选择器命中都生效 |
| **适合抽公共样式**   | 避免重复写相同规则       |
| **不改变优先级逻辑** | 每个选择器仍然独立计算   |

### 4. 交集选择器

交集选择器要求一个元素同时满足多个条件。

```css
button.primary {
  background-color: #1677ff;
  color: #fff;
}
```

这表示：既是 `button`，又有 `primary` 类的元素才会命中。

| 写法              | 含义                               |
| ----------------- | ---------------------------------- |
| **`p.mark`**      | 同时满足 `p` 标签和 `mark` 类      |
| **`input.error`** | 同时满足 `input` 标签和 `error` 类 |

注意：

- 交集选择器中通常不加空格。
- 一旦加空格，含义就变成了后代关系。

### 5. 伪类选择器

伪类选择器用于描述“当前状态”，常见于链接、表单、交互反馈。

链接常见状态：

| 伪类           | 说明           |
| -------------- | -------------- |
| **`:link`**    | 未访问的链接   |
| **`:visited`** | 已访问的链接   |
| **`:hover`**   | 鼠标悬停       |
| **`:active`**  | 鼠标按下未松开 |

表单常见状态：

| 伪类            | 说明                 |
| --------------- | -------------------- |
| **`:focus`**    | 获得焦点             |
| **`:checked`**  | 单选框、复选框被选中 |
| **`:disabled`** | 被禁用               |

示例：

```css
a:hover {
  color: #1677ff;
}

input:focus {
  border-color: #1677ff;
}
```

## 四、怎么选才更合理

| 需求                             | 推荐选择器 | 原因                       |
| -------------------------------- | ---------- | -------------------------- |
| **选中某个模块里的所有某类元素** | 后代选择器 | 结构允许更灵活             |
| **只想控制第一层结构**           | 子代选择器 | 更精确，不容易误伤深层元素 |
| **多类元素共用同一规则**         | 并集选择器 | 避免重复                   |
| **元素必须同时满足多个条件**     | 交集选择器 | 条件更严格，命中更准确     |
| **根据交互状态加样式**           | 伪类选择器 | 适合悬停、聚焦、选中等状态 |

一个常见误区是：能用后代选择器就一直用后代选择器。这样虽然省事，但一旦 DOM 层级变复杂，很容易把不该选中的元素也一起命中。

## 五、真实开发中的典型对比

### 1. 导航菜单

```html
<ul class="nav">
  <li><a href="#">首页</a></li>
  <li>
    <a href="#">产品</a>
    <ul>
      <li><a href="#">子菜单</a></li>
    </ul>
  </li>
</ul>
```

如果你写：

```css
.nav li {
  list-style: none;
}
```

这会影响所有层级的 `li`。

如果你只想控制第一层菜单项，更合适的是：

```css
.nav > li {
  display: inline-block;
}
```

### 2. 表单错误状态

```html
<input class="error" type="text" />
```

```css
input.error {
  border-color: #ff4d4f;
}
```

这里用交集选择器比单纯写 `.error` 更安全，因为它明确限定了生效对象是输入框。

## 六、常见问题

| 问题                     | 原因                                     |
| ------------------------ | ---------------------------------------- |
| **选择器写上了但没命中** | DOM 结构和想象中不一致，尤其是子代选择器 |
| **样式误伤太多元素**     | 后代选择器写得过宽                       |
| **加了空格导致结果不对** | 交集误写成后代                           |
| **伪类顺序不合理**       | 链接状态覆盖关系混乱                     |

链接伪类常按 `LVHA` 顺序书写：`link` → `visited` → `hover` → `active`，这样更不容易出现状态覆盖异常。

---

## 七、小结

| 知识点         | 结论                       |
| -------------- | -------------------------- |
| **后代选择器** | 范围广，适合模块内统一控制 |
| **子代选择器** | 更精确，适合结构明确的组件 |
| **并集选择器** | 用于提取公共样式           |
| **交集选择器** | 用于严格限制命中条件       |
| **伪类选择器** | 用于处理交互状态和控件状态 |
