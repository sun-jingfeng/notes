# 圆角、阴影、渐变色文字

## 一、一句话理解

这几个能力本质上都在做同一件事：在不改变布局结构的前提下，增强元素的视觉层次和表现力。

---

## 二、圆角 `border-radius`

`border-radius` 用于给元素设置圆角。

```css
.box {
  border-radius: 12px;
}
```

### 1. 常见写法

| 写法                                     | 含义                             |
| ---------------------------------------- | -------------------------------- |
| **`border-radius: 12px`**                | 四个角都为 12px                  |
| **`border-radius: 12px 24px`**           | 左上右下为 12px，右上左下为 24px |
| **`border-radius: 10px 20px 30px 40px`** | 分别对应左上、右上、右下、左下   |

### 2. 单独控制某个角

```css
.box {
  border-top-left-radius: 12px;
  border-top-right-radius: 12px;
  border-bottom-right-radius: 4px;
  border-bottom-left-radius: 4px;
}
```

### 3. 正方形变圆形

如果元素宽高相等，圆角设置成一半或 `50%`，就能得到圆形。

```css
.avatar {
  width: 100px;
  height: 100px;
  border-radius: 50%;
}
```

## 三、盒子阴影 `box-shadow`

`box-shadow` 用于给盒子添加阴影效果。

```css
.card {
  box-shadow: 0 8px 24px rgba(0, 0, 0, 0.12);
}
```

### 1. 语法

```css
box-shadow: h-shadow v-shadow blur spread color inset;
```

### 2. 参数说明

| 参数         | 说明               |
| ------------ | ------------------ |
| **水平偏移** | 阴影左右移动距离   |
| **垂直偏移** | 阴影上下移动距离   |
| **模糊半径** | 数值越大越模糊     |
| **扩散半径** | 控制阴影扩大或缩小 |
| **颜色**     | 阴影颜色           |
| **`inset`**  | 内阴影             |

### 3. 注意事项

| 注意点                    | 说明                 |
| ------------------------- | -------------------- |
| **默认是外阴影**          | 不需要写 `outset`    |
| **写 `inset` 才是内阴影** | 否则默认外阴影       |
| **阴影不占据布局空间**    | 不会影响其他盒子排列 |

真实项目里，阴影最容易出问题的不是不会写，而是层级过多、参数过重，导致界面发灰、发脏。

---

## 四、文字阴影 `text-shadow`

`text-shadow` 用于给文字添加阴影效果。

```css
.title {
  text-shadow: 2px 2px 4px rgba(0, 0, 0, 0.3);
}
```

### 1. 语法

```css
text-shadow: h-shadow v-shadow blur color;
```

### 2. 常见场景

- 标题强调
- 发光文字
- 浮雕或霓虹效果

---

## 五、渐变色文字

渐变色文字通常通过“背景渐变 + 文本裁剪 + 文字透明”实现。

```css
.gradient-text {
  background: linear-gradient(180deg, red, green);
  background-clip: text;
  -webkit-background-clip: text;
  color: transparent;
  -webkit-text-fill-color: transparent;
}
```

### 1. 原理说明

| 技巧                        | 作用                     |
| --------------------------- | ------------------------ |
| **背景设置渐变**            | 让文字所在区域有渐变底色 |
| **`background-clip: text`** | 把背景裁剪到文字形状上   |
| **文字设为透明**            | 让背景从文字区域透出来   |

> **注意**：`background-clip: text` 在部分浏览器上需要配合 `-webkit-` 前缀使用。

渐变字适合标题、强调词、展示型内容，不适合大段正文，否则可读性会明显下降。

---

## 六、真实开发里怎么选

| 需求                     | 更适合的能力    |
| ------------------------ | --------------- |
| **头像、卡片边缘更柔和** | `border-radius` |
| **卡片层级和悬浮感**     | `box-shadow`    |
| **文字强调或发光效果**   | `text-shadow`   |
| **视觉化标题、品牌字效** | 渐变色文字      |

一个实战原则是：先保证内容可读，再叠加视觉效果，而不是反过来。

---

## 七、小结

| 知识点       | 结论                          |
| ------------ | ----------------------------- |
| **圆角**     | 用 `border-radius` 控制       |
| **盒子阴影** | 用 `box-shadow` 控制          |
| **文字阴影** | 用 `text-shadow` 控制         |
| **渐变字**   | 常通过背景渐变 + 文本裁剪实现 |
