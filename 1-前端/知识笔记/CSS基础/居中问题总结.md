# 居中问题总结

## 水平居中

目标：行内元素、行内块元素水平居中。

方法：

> 1 text-align: center; /* 给父元素设置 */

目标：块级元素水平居中。

方法：

> 1 margin: 0 auto; /* 给当前元素设置（当前元素必须有宽度，否则占满整行） */

- 目标：浮动元素水平居中。

方法：

> 1 margin: 0 auto; /* 给标准流的父元素设置 */

目标：定位元素水平居中。

方法：

> 1 left: 50%;

> 2 margin-left: -( 自身宽度的一半 );

> 3 /* 给定位元素设置 */

## 垂直居中

目标：文字在盒子里垂直居中。

方法：

> 1 line-height: （盒子的高度） ; /* 给盒子设置 */

- 目标：行内块元素（例如图片）在块元素里垂直居中。

方法：

> 1 line-height: （盒子的高度） ; /* 给盒子设置 */

> 2 vertical-align: middle; /* 给行内块元素（例如图片）设置 */

## 目标：块元素在块元素垂直居中。

方法：测量，用内外边距设置。（如果有定位，可以用定位公式）

目标：行内块元素（例如图片）和并列的行内元素（例如文字）垂直居中。

方法：

vertical-align: middle; /* 给行内块元素添加： */
