# 浮动

## 传统网页布局的三种方式

- 网页布局的本质是用 CSS 摆放盒子。CSS 提供三种传统布局方式：

   - 文本流（普通流、标准流）

   - 浮动

   - 定位

- 标准流：

   - 块级元素会独占一行，从上向下顺序排列。常用元素：div、hr、p、h1~h6、ul、ol、dl、form、table。行内元素按顺序，从左到右顺序排列，碰到父元素边缘则自动换行。常用元素：span、a、i、em 等 以上都是标准流布局，标准流是最基本的布局方式。

## 浮动说明

- 浮动最典型的应用：可以让多个块级元素一行内排列显示。

- 网页布局第一准则：多个块级元素纵向排列找标准流，多个块级元素横向排列找浮动。

- 定义：float 属性用于创建浮动框，将其移动到一边，直到左边缘或右边缘触及包含块或另一个浮动框的边缘。

## 浮动特性（脱标、贴边、顶对齐等）

- 浮动特性总结：

   - 浮动元素脱离标准流，在页面中不占据位置。

   - 相邻的浮动元素找相邻的浮动元素，顶部对齐。

   - 浮动元素只会影响到下面的元素。

   - 浮动元素不会超出父元素，在父元素内部进行浮动。

   - 浮动元素只能压住下面的盒子（单指块元素，行内块、行内压不住），压不住盒子的内容（例如：文字、

   - 图片）。

   - 浮动的元素会具有行内块元素的特性。
