# 浮动

## 一、一句话理解

浮动的核心价值，不是现代页面里继续拿它做主力布局，而是理解它为什么能横向排版、为什么会带来塌陷和清除问题。

---

## 二、传统布局中的三种方式

在 Flex 和 Grid 普及之前，网页布局主要依赖三种方式：

| 方式       | 主要用途               |
| ---------- | ---------------------- |
| **标准流** | 默认上下或左右排列     |
| **浮动**   | 让多个块级元素横向排列 |
| **定位**   | 精准控制元素位置与层叠 |

### 1. 标准流回顾

| 元素类型     | 默认表现                       |
| ------------ | ------------------------------ |
| **块级元素** | 独占一行，自上而下排列         |
| **行内元素** | 从左到右排列，空间不足自动换行 |

标准流是最基础的布局方式，但它不擅长让多个块级元素自然横向排列，这也是浮动出现的原因之一。

---

## 三、什么是浮动

**浮动（float）** 是一种让元素脱离标准流并向左或向右排列的布局方式。

最典型的用途是：**让多个块级元素在一行内显示**。

```css
.box {
  float: left;
}
```

### 1. 常见取值

| 值          | 含义           |
| ----------- | -------------- |
| **`left`**  | 向左浮动       |
| **`right`** | 向右浮动       |
| **`none`**  | 不浮动，默认值 |

---

## 四、浮动的核心特性

### 1. 脱离标准流

浮动元素会脱离标准流，不再占据原来的文档流位置。

### 2. 可以横向排列

多个浮动元素会尽量排在同一行，如果父容器宽度不够，就会自动换到下一行。

### 3. 顶部对齐

相邻浮动元素通常会沿着当前行的顶部对齐。

### 4. 具有类似行内块的特性

浮动元素往往会表现出类似 `inline-block` 的特点：

- 可以和其他浮动元素排成一行
- 可以设置宽高
- 如果宽度未设置，尺寸可能由内容撑开

### 5. 只压盒子，不压文字环绕逻辑

浮动本来就与“文字环绕”场景关系密切，因此它对周围内容的影响和定位不同。

---

## 五、浮动的典型用途

### 1. 多列横向布局

```html
<div class="item">1</div>
<div class="item">2</div>
<div class="item">3</div>
```

```css
.item {
  float: left;
  width: 200px;
  height: 100px;
}
```

### 2. 图文环绕

```html
<img class="avatar" src="./avatar.jpg" alt="头像" />
<p>这里是一大段介绍文字，会围绕图片排列。</p>
```

```css
.avatar {
  float: left;
  margin-right: 12px;
}
```

图文环绕其实也是浮动最符合原始设计意图的场景之一。

---

## 六、浮动带来的问题

浮动虽然能做横向布局，但也会带来典型问题。

### 1. 父元素高度塌陷

因为子元素浮动后脱离文档流，父元素可能感知不到它们的高度。

### 2. 后续元素位置错乱

如果没有清除浮动，后面的元素可能受到影响。

### 3. 维护成本高

复杂页面里大量使用浮动，会让布局和清除逻辑变得繁琐。

---

## 七、清除浮动的思路

清除浮动的核心目标是：**让后续元素恢复正常布局，或者让父元素重新包裹住浮动子元素**。

最常见方式包括：

- 额外标签清除
- 伪元素清除
- 父元素触发 BFC

现代项目里最常见的是伪元素清除法：

```css
.clearfix::after {
  content: "";
  display: block;
  clear: both;
}
```

---

## 八、什么时候还会用浮动

| 场景                 | 是否还值得用浮动         |
| -------------------- | ------------------------ |
| **老项目维护**       | 值得懂，也可能必须继续用 |
| **图文环绕**         | 仍然合适                 |
| **现代通用横向布局** | 通常不推荐               |
| **复杂响应式布局**   | 更适合 `flex` / `grid`   |

---

## 九、浮动与现代布局的关系

| 场景                    | 推荐方式     |
| ----------------------- | ------------ |
| **老项目兼容布局**      | 浮动         |
| **现代横向 / 纵向布局** | Flex         |
| **二维网格布局**        | Grid         |
| **图文环绕**            | 浮动依然合适 |

总结：

- 浮动不是过时知识，仍要理解它的原理和历史价值
- 但现代业务布局中，通常优先使用 Flex / Grid

---

## 十、小结

| 知识点       | 结论                                 |
| ------------ | ------------------------------------ |
| **浮动作用** | 让元素脱离标准流并横向排列           |
| **典型用途** | 多列布局、图文环绕                   |
| **核心问题** | 父元素塌陷、后续布局受影响           |
| **现代实践** | 理解浮动原理，布局优先用 Flex / Grid |
