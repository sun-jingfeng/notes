# object-fit、pointer-events、not/where/is 伪类

## 一、一句话理解

这组知识点虽然分散，但都在解决同一类问题：内容怎么放进盒子、事件能不能点到它、选择器怎么更准确地表达“我要谁、不要谁”。

---

## 二、这几个属性和伪类分别解决什么问题

一句话概括：这组知识点都属于“**控制展示方式、事件命中和选择器表达能力**”的工具。

| 知识点                                      | 主要作用                             | 常见场景                         |
| ------------------------------------------- | ------------------------------------ | -------------------------------- |
| **object-fit**                              | 控制图片、视频在固定盒子中的填充方式 | 头像、卡片封面、视频缩略图       |
| **pointer-events**                          | 控制元素是否接收鼠标 / 指针事件      | 蒙层穿透、禁用点击、装饰层       |
| **:not()**                                  | 排除不想命中的元素                   | 防止样式污染、批量排除某类节点   |
| **:is()**                                   | 合并多组选择器的公共部分             | 精简长选择器                     |
| **:where()**                                | 和 `:is()` 类似，但优先级恒为 `0`    | 写低优先级基础样式               |
| **min-content / max-content / fit-content** | 让宽度按内容内在尺寸计算             | 自适应标签、输入框、内容包裹布局 |

---

## 三、`object-fit`

### 2.1 什么是 `object-fit`

**`object-fit`** 用来指定可替换元素的内容如何填充它自己的内容盒，最常见的对象是：

1. `img`
2. `video`
3. `canvas`
4. `iframe`（部分场景）

它解决的是：**元素本身尺寸已经固定，但内容原始比例不一定匹配盒子尺寸**。

### 2.2 常见取值

| 值             | 含义                                | 视觉结果 |
| -------------- | ----------------------------------- | -------- |
| **fill**       | 拉伸填满盒子                        | 可能变形 |
| **contain**    | 完整显示内容，保持比例              | 可能留白 |
| **cover**      | 覆盖整个盒子，保持比例              | 可能裁切 |
| **none**       | 保持原始尺寸                        | 可能溢出 |
| **scale-down** | 在 `none` 和 `contain` 中选更小效果 | 更保守   |

### 2.3 最常见的两个值

```css
.avatar {
  width: 120px;
  height: 120px;
  object-fit: cover;
}

.poster {
  width: 320px;
  height: 180px;
  object-fit: contain;
}
```

### 2.4 和 `background-size` 的区别

| 对比项       | `object-fit`              | `background-size`  |
| ------------ | ------------------------- | ------------------ |
| 作用对象     | `img`、`video` 等元素内容 | 背景图             |
| 是否保留语义 | 保留元素语义和可访问性    | 只是背景装饰       |
| 典型场景     | 内容图、商品图、头像      | 装饰背景、页面背景 |

### 2.5 注意事项

1. `object-fit` 必须和明确的宽高一起使用，效果才明显。
2. 它作用的是元素“内容如何放进盒子”，不是修改盒子本身的尺寸。
3. `img` 做内容图时，优先考虑 `object-fit`，不要为了裁图改成背景图，避免丢失语义。

一个很实用的记法是：`cover` 更像“先铺满再说”，`contain` 更像“先保证完整显示”。

## 四、`pointer-events`

### 3.1 什么是 `pointer-events`

**`pointer-events`** 用来决定一个元素是否可以成为指针事件的命中目标。

在普通 HTML 场景里，最常见的两个值是：

| 值       | 含义                           |
| -------- | ------------------------------ |
| **auto** | 正常接收事件                   |
| **none** | 不接收事件，事件会命中下层元素 |

### 3.2 典型场景

#### 场景一：装饰层不挡点击

```css
.card {
  position: relative;
}

.card-mask {
  position: absolute;
  inset: 0;
  background: linear-gradient(to top, rgb(0 0 0 / 0.5), transparent);
  pointer-events: none;
}
```

这样蒙层还能显示，但不会挡住底部按钮和链接。

#### 场景二：临时禁用交互

```css
.disabled {
  pointer-events: none;
  opacity: 0.5;
}
```

### 3.3 注意事项

1. `pointer-events: none` 只是不接收指针事件，不代表元素从布局里消失。
2. 它常用于“事件穿透”，但如果元素本身还需要键盘可访问性，就不能只靠它做“禁用态”。
3. 真正的表单禁用优先使用原生属性，如 `disabled`。

也就是说，`pointer-events` 更适合解决命中问题，而不是完整的交互禁用语义。

## 五、`:not()` 伪类

### 4.1 什么是 `:not()`

**`:not()`** 用来匹配“不符合某条件”的元素，也就是反选。

```css
button:not(.primary) {
  background: #f5f5f5;
  color: #333;
}
```

这段样式表示：匹配所有不是 `.primary` 的 `button`。

### 4.2 常见用途

#### 用途一：批量排除特殊元素

```css
.article img:not(.emoji):not(.icon) {
  max-width: 100%;
}
```

#### 用途二：避免样式污染

```css
body :not(.third-party-container) a {
  color: #1677ff;
}
```

更常见的思路是：给第三方内容容器一个“隔离 class”，再用 `:not()` 做外部样式约束。

### 4.3 优先级规则

`:not()` 自身不增加额外优先级，它的优先级取决于参数里**优先级最高的那个选择器**。

| 写法            | 优先级来源 |
| --------------- | ---------- |
| `div:not(.box)` | `.box`     |
| `a:not(#app)`   | `#app`     |

### 4.4 注意事项

1. `:not()` 适合做排除，但不要把排除条件写得过长，否则可读性会很差。
2. 如果“例外情况”比“正常情况”更多，通常应该重构选择器，而不是继续叠 `:not()`。

## 六、`:is()` 和 `:where()`

### 5.1 这两个伪类解决什么问题

它们都可以把多组选项合并到一个选择器里，减少重复。

```css
:is(h1, h2, h3) .icon {
  margin-right: 8px;
}
```

相当于：

```css
h1 .icon,
h2 .icon,
h3 .icon {
  margin-right: 8px;
}
```

### 5.2 `:is()` 和 `:where()` 的核心区别

| 伪类           | 作用       | 优先级             |
| -------------- | ---------- | ------------------ |
| **`:is()`**    | 合并选择器 | 取参数中最高优先级 |
| **`:where()`** | 合并选择器 | 恒为 `0`           |

### 5.3 什么时候用 `:is()`

当你只是想**精简选择器**，且仍然希望保留正常优先级时，用 `:is()`。

```css
.content :is(h1, h2, h3) {
  line-height: 1.3;
}
```

### 5.4 什么时候用 `:where()`

当你想写一层“**低优先级基础样式**”，方便后续覆盖时，用 `:where()`。

```css
:where(article, section, aside) a {
  text-decoration: underline;
}
```

因为优先级为 `0`，所以它非常适合写 reset、主题基础层、组件库默认样式。

这里最值得记住的不是语法，而是：`:is()` 更适合压缩选择器，`:where()` 更适合故意保持低优先级。

### 5.5 额外特性

普通选择器列表里，只要有一个选择器无法解析，整个规则可能失效；而在 `:is()` / `:where()` 中，单个无效项通常不会影响其他可解析项。

## 七、`width` 的几个内容内在尺寸值

### 6.1 `min-content`

表示元素在“**不额外溢出时可压缩到的最小宽度**”。

可以理解为：尽量收缩，必要时按最难再压缩的内容决定宽度。

### 6.2 `max-content`

表示元素内容“**完全展开、不主动换行**”时所需的最大宽度。

### 6.3 `fit-content`

表示宽度在以下范围内折中：

1. 不小于 `min-content`
2. 不大于 `max-content`
3. 同时尽量适应可用空间

### 6.4 对比示例

```css
.tag-min {
  width: min-content;
}

.tag-max {
  width: max-content;
}

.tag-fit {
  width: fit-content;
}
```

| 值              | 更像什么效果     |
| --------------- | ---------------- |
| **min-content** | 尽量挤压         |
| **max-content** | 完整展开         |
| **fit-content** | 在可用空间里折中 |

### 6.5 适用场景

1. 自适应按钮宽度。
2. 标签 / 徽标宽度跟内容走。
3. 长文本容器希望在内容宽度和父容器之间平衡。

---

## 八、真实开发里怎么快速判断

| 问题                           | 优先想到什么           |
| ------------------------------ | ---------------------- |
| **图片被拉伸变形**             | `object-fit`           |
| **装饰层挡住点击**             | `pointer-events: none` |
| **想排除某类元素**             | `:not()`               |
| **多组选项共用一套规则**       | `:is()`                |
| **想写易覆盖的基础样式**       | `:where()`             |
| **宽度希望跟内容但别无限撑开** | `fit-content`          |

---

## 九、小结

1. `object-fit` 解决的是图片和视频内容如何放进固定盒子。
2. `pointer-events` 解决的是元素能不能接收指针事件。
3. `:not()` 适合做排除匹配，常用于防止样式污染。
4. `:is()` 和 `:where()` 都能精简选择器，但 `:where()` 的优先级永远是 `0`。
5. `min-content`、`max-content`、`fit-content` 适合做内容驱动的自适应宽度布局。
