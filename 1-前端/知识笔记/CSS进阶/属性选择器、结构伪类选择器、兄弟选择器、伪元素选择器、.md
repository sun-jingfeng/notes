# 属性选择器、结构伪类选择器、兄弟选择器、伪元素选择器

## 一、这篇的主线

这几类选择器本质上都在回答一个问题：

```text
当不想只靠 class 和 id 时，CSS 还能根据什么条件选中元素
```

它们各自关注的维度不同：

1. 属性选择器：看元素属性。
2. 结构伪类：看元素位置。
3. 兄弟选择器：看同级关系。
4. 伪元素：在不增加真实标签的情况下补充展示层内容。

---

## 二、属性选择器

属性选择器可以根据元素的属性或属性值来选中元素，不一定非要依赖类名和 id。

### 2.1 基本写法

```css
input[disabled] {
  background-color: #f5f5f5;
}
```

表示选中所有带有 `disabled` 属性的 `input`。

### 2.2 常见属性选择器

| 选择器          | 含义                 |
| --------------- | -------------------- |
| `[attr]`        | 选择带有某属性的元素 |
| `[attr=value]`  | 属性值完全等于某值   |
| `[attr^=value]` | 属性值以某值开头     |
| `[attr$=value]` | 属性值以某值结尾     |
| `[attr*=value]` | 属性值包含某值       |

### 2.3 常见场景

1. 根据表单状态选中输入框。
2. 根据文件后缀或链接目标加样式。
3. 根据 `data-*` 标识做样式区分。

### 2.4 一个选择建议

当语义本来就体现在属性上时，属性选择器比额外再补一个 class 更自然。

### 2.5 属性选择器什么时候合适，什么时候别滥用

| 场景                                                  | 是否适合 |
| ----------------------------------------------------- | -------- |
| 根据 `disabled`、`checked`、`data-*` 等真实状态加样式 | 适合     |
| 根据链接前缀、文件后缀、语言标识做轻量区分            | 适合     |
| 大范围替代业务 class 命名                             | 不太适合 |
| 把复杂业务语义全塞进属性值再做样式判断                | 不太适合 |

属性选择器更适合“利用现有语义”，不适合把样式系统完全建立在属性匹配上。

## 三、结构伪类选择器

结构伪类主要根据元素在文档结构中的位置进行选择。

### 3.1 常见结构伪类

| 选择器            | 含义              |
| ----------------- | ----------------- |
| `:first-child`    | 第一个孩子        |
| `:last-child`     | 最后一个孩子      |
| `:nth-child(n)`   | 第 n 个孩子       |
| `:first-of-type`  | 某类型的第一个    |
| `:last-of-type`   | 某类型的最后一个  |
| `:nth-of-type(n)` | 某类型中的第 n 个 |

### 3.2 `n` 的常见写法

```css
li:nth-child(odd) {
  background: #f7f7f7;
}

li:nth-child(even) {
  background: #eee;
}

li:nth-child(3n) {
  color: blue;
}
```

### 3.3 `:nth-child()` 和 `:nth-of-type()` 的区别

```html
<div>
  <p>p1</p>
  <span>span1</span>
  <p>p2</p>
</div>
```

```css
p:nth-child(2) {
  color: red;
}

p:nth-of-type(2) {
  color: blue;
}
```

区别：

1. `:nth-child()` 先按所有孩子排顺序，再判断是否匹配当前元素。
2. `:nth-of-type()` 先筛出同类型元素，再在其中排序。

### 3.4 怎么选

| 选择器           | 更适合                   |
| ---------------- | ------------------------ |
| `:nth-child()`   | 结构稳定、孩子类型单一时 |
| `:nth-of-type()` | 父元素下有多种标签混排时 |

如果页面结构混合了多种标签，`nth-of-type()` 往往更稳定。

### 3.5 一个高频踩坑点

很多人看到“第 2 个 `p`”就直接写 `p:nth-child(2)`，结果发现没选中，根本原因 usually 不是 CSS 失效，而是它前面夹了别的标签。

遇到这类问题时，先问自己：

1. 我数的是“父元素的所有孩子顺序”，还是“同类型元素顺序”？
2. 当前结构后续会不会插入别的标签导致序号失效？

如果结构容易变化，`nth-of-type()` 通常更抗改动。

## 四、兄弟选择器

兄弟选择器用于选择和某个元素同级的其他元素。

### 4.1 相邻兄弟选择器 `+`

```css
h2 + p {
  color: #666;
}
```

表示选择紧跟在 `h2` 后面的那个 `p`。

### 4.2 通用兄弟选择器 `~`

```css
h2 ~ p {
  color: #999;
}
```

表示选择 `h2` 后面所有同级的 `p`。

### 4.3 两者区别

| 选择器 | 作用                     |
| ------ | ------------------------ |
| `+`    | 只选紧邻的下一个兄弟     |
| `~`    | 选后面所有满足条件的兄弟 |

### 4.4 常见场景

1. 给列表项之间添加间距。
2. 表单校验提示跟随输入框显示。
3. 文章标题后的首段样式处理。

一个很常见的技巧：

```css
.stack > * + * {
  margin-top: 12px;
}
```

它表示除了第一个孩子外，其余孩子都加上上边距。

### 4.5 真实开发里怎么快速判断

| 需求                         | 更推荐                 |
| ---------------------------- | ---------------------- |
| 只处理紧跟某元素后的一个兄弟 | `+`                    |
| 处理它后面所有满足条件的兄弟 | `~`                    |
| 给同层元素做统一间距         | `> * + *` 这类组合写法 |

兄弟选择器最适合解决“相邻关系”和“后续关系”，不适合跨层级查找。

## 五、伪元素选择器

伪元素可以理解为在元素内容前后生成的虚拟元素。

### 5.1 常见伪元素

| 选择器           | 作用             |
| ---------------- | ---------------- |
| `::before`       | 在元素内容前插入 |
| `::after`        | 在元素内容后插入 |
| `::first-letter` | 首字母           |
| `::first-line`   | 首行             |
| `::selection`    | 被选中内容       |

### 5.2 `::before` 和 `::after`

```css
.badge::before {
  content: "NEW";
  margin-right: 8px;
  color: red;
}
```

### 5.3 一个关键点

`::before` 和 `::after` 如果想显示出来，通常必须写 `content`。

```css
.box::after {
  content: "";
  display: block;
  clear: both;
}
```

### 5.4 常见用途

1. 清除浮动。
2. 加装饰线、图标、标签。
3. 做角标、分隔符、阴影层。

### 5.5 一个边界提醒

伪元素更适合装饰性内容，不适合承载真正需要被业务逻辑读取的重要文本。

### 5.6 什么时候该用伪元素，什么时候该补真实标签

| 需求                                             | 更推荐   |
| ------------------------------------------------ | -------- |
| 装饰线、角标、引号、背景层、分隔符               | 伪元素   |
| 需要被脚本读取、复制、搜索、无障碍识别的重要文本 | 真实标签 |
| 需要复杂交互、事件绑定、独立布局控制             | 真实标签 |

判断标准很简单：它如果只是“展示层补充”，优先伪元素；它如果已经带业务语义，就不要偷懒。

## 六、这些选择器怎么组合

```html
<ul class="news-list">
  <li data-hot="true">新闻一</li>
  <li>新闻二</li>
  <li>新闻三</li>
</ul>
```

```css
.news-list li[data-hot="true"]::after {
  content: " 热门";
  color: red;
}

.news-list li:nth-child(odd) {
  background: #f7f7f7;
}

.news-list li + li {
  border-top: 1px solid #eee;
}
```

这里同时用到了：

1. 属性选择器。
2. 结构伪类。
3. 兄弟选择器。
4. 伪元素。

这也是它们在真实项目里最常见的使用方式：组合起来做精细化样式控制。

### 6.1 一个组合原则

组合选择器时，尽量让每一段条件都在表达“必要约束”，不要为了图省事把选择器越写越长。

比如：

1. 先用 class 限定模块边界。
2. 再用属性或结构伪类补充状态和位置。
3. 最后再用伪元素做装饰。

这样既能控制影响范围，也更方便后续维护和排错。

---

## 七、小结

1. 属性选择器适合根据属性状态或属性值选中元素。
2. 结构伪类适合根据元素在父级中的位置进行选择，`nth-child` 和 `nth-of-type` 一定要分清。
3. `+` 和 `~` 都是兄弟选择器，只是选中范围不同。
4. 伪元素适合做展示增强，不适合承载真正有业务意义的内容。
5. 这些选择器最有价值的地方，不是单独背写法，而是学会在模块边界内把它们组合使用。
6. 伪元素常用于装饰性内容和结构辅助，不需要额外写真实 HTML。
7. 学这一篇时，重点不是把选择器孤立去背，而是理解它们分别是按“属性、位置、兄弟关系、虚拟内容”这四种维度在选元素。
