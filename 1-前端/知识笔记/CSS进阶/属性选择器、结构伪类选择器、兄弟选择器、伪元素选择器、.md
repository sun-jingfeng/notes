## 区别：

   - nth-child 对父元素里面所有孩子排序选择（序号是固定的） 先找到第n个孩子，然后看看是否和E匹配

   - nth-of-type 对父元素里面指定子元素进行排序选择。 先去匹配E ，然后再根据E 找第n个孩子

- 小结：


   - 结构伪类选择器一般用于选择父级里面的第几个孩子

   - nth-child 对父元素里面所有孩子排序选择（序号是固定的） 先找到第n个孩子，然后看看是否和E匹配

   - nth-of-type 对父元素里面指定子元素进行排序选择。 先去匹配E ，然后再根据E 找第n个孩子

   - 关于 nth-child（n） 我们要知道 n 是从 0 开始计算的，要记住常用的公式

   - 如果是无序列表，我们肯定用 nth-child 更多

   - 类选择器、属性选择器、伪类选择器，权重为 10。

## 兄弟选择器

- 选择符：+

- 用法：【选择器1】 + 【选择器2】{ // 给【选择器2】对应的元素加的样式 }

- 描述：选择某个元素后面紧跟着的那个元素（注意：最终选中的是后面的元素）

- 参考文档：相邻兄弟选择器

- 示例代码：

> 1 // 给 box 的所有直接子元素之间加 10 像素边距

> 2 .box{

> 3 >*+*{

> 4 margin-left: 10px !important // 通配符优先级太低，如果没生效就加个 !important

> 5 }

> 6 }

## 伪元素选择器

- 伪元素选择器可以帮助我们利用CSS创建新标签元素，而不需要HTML标签，从而简化HTML结构。

**==> picture [467 x 77] intentionally omitted <==**

## 注意：

- before 和 after 创建一个元素，但是属于行内元素

- 新创建的这个元素在文档树中是找不到的，所以我们称为伪元素

- 语法： element::before {}

- before 和 after 必须有 content 属性

- before 在父元素内容的前面创建元素，after 在父元素内容的后面插入元素


- 伪元素选择器和标签选择器 样，权重为 1
