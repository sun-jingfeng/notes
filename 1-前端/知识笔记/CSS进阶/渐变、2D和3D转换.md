## 旋转

语法：transform: rotate(角度); // 单位：deg

技巧

取值为正, 则顺时针旋转

取值为负, 则逆时针旋转

改变旋转中心点

语法：transform-origin: x y;

取值分类

关键词（x值：left、right、center；y值：top、bottom、 center ）

- 像素值

百分数

## 缩放

## 语法

transform: scaleX(值);

transform: scaleY(值);

transform: scale(值1, 值2);

**==> picture [467 x 34] intentionally omitted <==**

取值

## 纯数字，不能为负数

值代表缩放倍数，所以值大于1表示放大，小于1表示缩小

- 改变缩放基准点

语法：transform-origin: x y;

- 取值分类：

关键词（x值：left、right、center；y值：top、bottom、 center ）

像素值

百分数

## 倾斜

## 语法

transform: skewX(角度);

transform: skewY(角度);

transform: skew(x轴的角度, y轴的角度);

## 多重转换

语法：transform: translate() rotate() scale();

注意：旋转可以改变x、y轴的方向，所以translate() rotate() 顺序不能随意换
