# HTML 基本标签

## 一、一句话理解

HTML 基本标签的重点不是记住几个标签名，而是知道不同内容该用什么标签表达，才能让页面结构、语义和后续维护都更清晰。

---

## 二、常见基础标签概览

**HTML 基本标签** 是构建网页结构和内容的最小单位，主要用于描述标题、段落、图片、链接、容器等内容。

| 类别           | 常见标签                     |
| -------------- | ---------------------------- |
| **结构与容器** | `div`、`span`                |
| **文本内容**   | `h1` ~ `h6`、`p`、`br`       |
| **文本强调**   | `strong`、`em`、`ins`、`del` |
| **媒体**       | `img`                        |
| **链接**       | `a`                          |
| **辅助**       | 注释、字符实体               |

---

## 三、标题标签

标题标签用于表示内容层级，范围从 `h1` 到 `h6`。

```html
<h1>一级标题</h1>
<h2>二级标题</h2>
<h3>三级标题</h3>
<h4>四级标题</h4>
<h5>五级标题</h5>
<h6>六级标题</h6>
```

### 1. 特点

| 特点             | 说明                           |
| ---------------- | ------------------------------ |
| **默认加粗**     | 浏览器会默认用更醒目的样式展示 |
| **字号逐级减小** | `h1` 最大，`h6` 最小           |
| **块级元素**     | 默认独占一行                   |

> **注意**：标题标签除了样式，更重要的是表达文档结构，不能只为了“字大”滥用。

也就是说，标题标签首先是结构语义，其次才是默认样式。

---

## 四、段落与换行

### 1. 段落标签 `p`

`<p>` 用于表示一段文字内容。

```html
<p>这是一个段落。</p>
```

### 2. 换行标签 `br`

`<br>` 用于强制换行。

```html
第一行<br />
第二行
```

| 标签     | 作用                             |
| -------- | -------------------------------- |
| **`p`**  | 表示完整段落，段落之间默认有间距 |
| **`br`** | 仅换行，不表示新段落             |

真的是新的段落，用 `p`；只是同一段里强制换行，用 `br`。

---

## 五、文本格式化标签

HTML 提供了一些标签用于强调文本语义。

| 标签         | 语义       | 默认效果 |
| ------------ | ---------- | -------- |
| **`strong`** | 强调、重要 | 加粗     |
| **`em`**     | 重点强调   | 倾斜     |
| **`ins`**    | 插入内容   | 下划线   |
| **`del`**    | 删除内容   | 删除线   |

```html
<strong>重要内容</strong>
<em>强调内容</em>
<ins>新增内容</ins>
<del>已删除内容</del>
```

> **注意**：现代开发中更推荐使用有语义的 `strong` 和 `em`，而不是只追求样式效果。

如果只是想改粗细和颜色，优先交给 CSS；如果是内容本身有强调语义，再考虑这些标签。

---

## 六、`div` 和 `span`

`div` 和 `span` 本身几乎没有语义，主要作为通用容器使用。

```html
<div>这是头部区域</div>
<span>今日价格</span>
```

| 标签       | 特点                                 |
| ---------- | ------------------------------------ |
| **`div`**  | 块级元素，默认独占一行，适合大块布局 |
| **`span`** | 行内元素，适合包裹局部文本           |

它们很常用，但不是万能标签；如果有更准确的语义标签，优先用更合适的标签表达内容结构。

---

## 七、图像标签 `img`

`<img>` 用于在页面中插入图片。

```html
<img src="./images/logo.png" alt="网站 Logo" width="120" />
```

### 1. 常用属性

| 属性                   | 说明                                           |
| ---------------------- | ---------------------------------------------- |
| **`src`**              | 图片地址，必填                                 |
| **`alt`**              | 图片加载失败时的替代文本，也有利于无障碍和 SEO |
| **`title`**            | 鼠标悬停提示                                   |
| **`width` / `height`** | 设置显示尺寸                                   |

### 2. 注意事项

| 注意点               | 说明                    |
| -------------------- | ----------------------- |
| **`src` 必填**       | 否则图片无法加载        |
| **建议写 `alt`**     | 提升语义和可访问性      |
| **属性写在标签名后** | 使用 `key="value"` 格式 |

很多图片相关问题，本质不是标签不会用，而是路径写错或 `alt`、尺寸策略没有想清楚。

---

## 八、路径

在引用图片、样式、脚本时，经常会涉及路径。

### 1. 相对路径

相对于当前文件所在位置来查找目标文件。

| 写法                  | 含义                          |
| --------------------- | ----------------------------- |
| **`./img/logo.png`**  | 当前目录下的 `img/logo.png`   |
| **`../img/logo.png`** | 上一级目录下的 `img/logo.png` |
| **`img/logo.png`**    | 通常也表示当前目录下          |

### 2. 绝对路径

直接从完整位置开始写。

```text
D:\web\img\logo.png
https://example.com/logo.png
```

> **注意**：前端开发中更常用的是相对路径和网络绝对路径。

---

## 九、超链接标签 `a`

`<a>` 用于创建超链接。

```html
<a href="https://www.baidu.com" target="_blank">百度</a>
```

### 1. 常用属性

| 属性         | 说明                           |
| ------------ | ------------------------------ |
| **`href`**   | 跳转地址                       |
| **`target`** | 打开方式，如 `_self`、`_blank` |

### 2. 常见链接类型

| 类型         | 示例                                     |
| ------------ | ---------------------------------------- |
| **外部链接** | `<a href="https://example.com">官网</a>` |
| **内部链接** | `<a href="index.html">首页</a>`          |
| **空链接**   | `<a href="#">占位链接</a>`               |
| **下载链接** | `href` 指向压缩包或文件地址              |
| **锚点链接** | `<a href="#section2">跳到第二部分</a>`   |

### 3. 锚点链接

```html
<a href="#chapter2">跳到第 2 节</a>

<h2 id="chapter2">第 2 节</h2>
```

`a` 标签的本质不是“蓝色带下划线文字”，而是页面导航和跳转行为的语义载体。

---

## 十、注释

HTML 注释用于给开发者阅读，不会在页面中显示。

```html
<!-- 这是一个注释 -->
```

### 1. 作用

| 作用             | 说明               |
| ---------------- | ------------------ |
| **解释代码含义** | 便于后续维护       |
| **划分结构区域** | 在大型页面中更清晰 |

注释的价值在于帮助维护，不在于把显而易见的内容再重复一遍。

---

## 十一、特殊字符

当某些字符不能直接写进 HTML 时，可以使用字符实体。

| 字符           | 实体     |
| -------------- | -------- |
| **空格**       | `&nbsp;` |
| **小于号 `<`** | `&lt;`   |
| **大于号 `>`** | `&gt;`   |
| **与号 `&`**   | `&amp;`  |
| **版权符号**   | `&copy;` |

```html
<p>3 &lt; 5</p>
<p>Tom &amp; Jerry</p>
```

特殊字符常用于避免 HTML 解析歧义，不是冷知识。

---

## 十二、真实开发里的主线

```text
标题标签负责层级
	-> 段落和强调标签负责内容表达
	-> div / span 负责通用容器包裹
	-> img / a 负责媒体和跳转
	-> 注释与字符实体负责可维护性和语法安全
```

## 十三、小结

| 知识点         | 结论                                    |
| -------------- | --------------------------------------- |
| **标题标签**   | 表达内容层级                            |
| **段落和换行** | `p` 表示段落，`br` 表示强制换行         |
| **容器标签**   | `div` 适合块级布局，`span` 适合行内包裹 |
| **图片标签**   | `img` 通过 `src` 引入图片               |
| **超链接**     | `a` 用于页面跳转和锚点定位              |
| **特殊字符**   | 用字符实体避免歧义                      |
