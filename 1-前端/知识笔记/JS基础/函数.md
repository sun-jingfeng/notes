# 函数

## 一、一句话理解

函数的本质，是把一段可复用逻辑包装成一个可调用单元，让代码从“重复堆砌”变成“按职责组织”。

---

## 二、什么是函数

**函数（Function）** 是一段可以被重复调用的代码块，用来完成某个相对独立的功能。

**核心思想：** 把重复逻辑封装起来，通过“定义一次，调用多次”提高代码复用率和可维护性。

| 维度         | 说明                               |
| ------------ | ---------------------------------- |
| **作用**     | 封装功能、减少重复代码             |
| **输入**     | 通过参数接收外部数据               |
| **输出**     | 通过 `return` 返回处理结果         |
| **典型场景** | 格式化数据、计算结果、执行公共流程 |

---

## 三、函数的声明与调用

### 1. 声明语法

```js
function 函数名(参数1, 参数2) {
  // 函数体
}
```

```js
function sayHello() {
  console.log("你好，JavaScript")
}
```

### 2. 调用语法

```js
sayHello()
```

> **注意**：函数声明后不会自动执行，只有调用时才会执行函数体中的代码。

### 3. 命名规范

| 规范               | 说明                                  |
| ------------------ | ------------------------------------- |
| **小驼峰**         | 例如 `getUserInfo`、`formatPrice`     |
| **前缀尽量用动词** | 函数表示“做什么”，通常用动词更清晰    |
| **见名知意**       | 避免 `fn1`、`test` 这类含义模糊的名字 |

常见动词约定：`get`、`set`、`create`、`update`、`remove`、`check`、`format`。

---

## 四、函数封装的意义

把重复逻辑直接写在多个地方，会带来以下问题：

| 问题           | 说明                               |
| -------------- | ---------------------------------- |
| **重复代码多** | 同样的逻辑散落在多个位置           |
| **修改成本高** | 修改一处逻辑时，其他地方也要同步改 |
| **可读性差**   | 业务流程中掺杂大量细节实现         |

将逻辑封装成函数后，代码会更清晰：

```js
function calcRectangleArea(width, height) {
  return width * height
}

const area1 = calcRectangleArea(10, 20)
const area2 = calcRectangleArea(5, 8)

console.log(area1) // 200
console.log(area2) // 40
```

## 五、参数

### 1. 什么是参数

参数就是函数在执行时需要外部传入的数据。

```js
function introduce(name, age) {
  console.log(`我叫 ${name}，今年 ${age} 岁`)
}

introduce("孙悟空", 500)
```

### 2. 形参和实参

| 概念     | 说明                                             |
| -------- | ------------------------------------------------ |
| **形参** | 声明函数时写在小括号里的参数，例如 `name`、`age` |
| **实参** | 调用函数时实际传入的值，例如 `'孙悟空'`、`500`   |

```js
function sum(num1, num2) {
  return num1 + num2
}

const result = sum(10, 20)
```

在这个例子中：

- `num1`、`num2` 是**形参**
- `10`、`20` 是**实参**

### 3. 参数个数不一致时

```js
function sum(num1, num2) {
  return num1 + num2
}

console.log(sum(10, 20)) // 30
console.log(sum(10)) // NaN，因为 num2 是 undefined
```

> **注意**：基础开发中尽量保证形参和实参个数一致，避免出现 `undefined` 带来的隐式问题。

更进一步说，参数存在的意义，不是“把值塞进函数里”，而是让函数真正具备复用价值。

## 六、返回值

### 1. return 的作用

**`return`** 用于把函数内部的结果返回给函数外部。

```js
function getSquare(num) {
  return num * num
}

const result = getSquare(6)
console.log(result) // 36
```

### 2. return 的几个关键点

| 规则                     | 说明                            |
| ------------------------ | ------------------------------- |
| **会立即结束函数**       | `return` 后面的代码默认不再执行 |
| **没有 return 时**       | 函数默认返回 `undefined`        |
| **通常返回一个最终结果** | 便于外部继续使用                |

```js
function test() {
  console.log("开始执行")
  return "结束"
  console.log("这行不会执行") // 不会执行
}
```

---

## 七、函数体与执行过程

**函数体** 就是函数内部的大括号 `{}` 包裹起来的代码。

函数的执行流程通常如下：

定义函数 → 调用函数 → 传入参数 → 执行函数体 → 返回结果

```js
function multiply(num1, num2) {
  const result = num1 * num2
  return result
}

const total = multiply(3, 4)
console.log(total) // 12
```

---

## 八、什么时候该封成函数

| 场景                                 | 是否建议封装         |
| ------------------------------------ | -------------------- |
| **重复出现的相同逻辑**               | 建议                 |
| **一段独立计算流程**                 | 建议                 |
| **临时只执行一次、极短代码**         | 不一定               |
| **过于零碎、没有明确语义的代码片段** | 不建议为了封装而封装 |

封装不是越多越好，而是要让函数的名字和职责足够清楚。

## 九、内置函数

### 1. 什么是内置函数

**内置函数** 是 JavaScript 已经封装好的函数，开发者可以直接调用。

常见内置函数：`Number()`、`Boolean()`、`parseInt()`、`parseFloat()`。

### 2. `parseInt()` 与 `parseFloat()`

| 函数               | 作用                           | 示例                               |
| ------------------ | ------------------------------ | ---------------------------------- |
| **`parseInt()`**   | 从字符串中提取整数             | `parseInt('12px')` 得到 `12`       |
| **`parseFloat()`** | 从字符串中提取数字，可保留小数 | `parseFloat('12.5px')` 得到 `12.5` |

```js
console.log(parseInt("100px")) // 100
console.log(parseFloat("3.14rem")) // 3.14
console.log(parseInt("abc123")) // NaN
```

### 3. 注意事项

| 情况                                        | 结果           |
| ------------------------------------------- | -------------- |
| **字符串不是以数字开头**                    | 得到 `NaN`     |
| **`parseInt()` 遇到小数点**                 | 只保留整数部分 |
| **`parseFloat()` 遇到第二个小数点或非数字** | 解析停止       |

## 十、小结

| 知识点         | 结论                            |
| -------------- | ------------------------------- |
| **函数是什么** | 可重复调用的代码块              |
| **参数**       | 用来接收外部传入的数据          |
| **返回值**     | 用 `return` 把结果交给外部      |
| **封装价值**   | 减少重复代码、提升可维护性      |
| **内置函数**   | JavaScript 已提供好，可直接调用 |
