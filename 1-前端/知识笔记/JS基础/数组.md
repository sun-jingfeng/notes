# 数组

## 一、一句话理解

数组的核心价值，不只是“能装很多值”，而是非常适合表达一组有顺序、可遍历、可批量处理的数据。

---

## 二、什么是数组

**数组（Array）** 是一种按顺序存储多个值的数据结构，适合表示“同一类数据的集合”。

例如：学生名单、商品列表、成绩列表、待办事项列表等。

| 特点               | 说明                   |
| ------------------ | ---------------------- |
| **有序**           | 每个元素都有自己的位置 |
| **可通过下标访问** | 下标从 `0` 开始        |
| **长度可变**       | 可以新增、删除元素     |

---

## 三、数组的声明与取值

### 1. 声明数组

```js
const names = ["小明", "小红", "小刚"]
```

### 2. 取值

```js
console.log(names[0]) // 小明
console.log(names[1]) // 小红
```

### 3. 基本术语

| 术语            | 说明                                 |
| --------------- | ------------------------------------ |
| **元素**        | 数组中的每一个值                     |
| **索引 / 下标** | 元素所在的位置编号，从 `0` 开始      |
| **长度**        | 数组中元素的个数，通过 `length` 获取 |

```js
const arr = ["a", "b", "c"]

console.log(arr.length) // 3
```

> **注意**：数组可以存储任意类型的数据，但实际开发中通常建议同一个数组尽量存储同一类数据，便于维护。

---

## 四、数组的特点

### 1. 可通过下标动态新增元素

```js
const arr = ["a", "b"]
arr[2] = "c"

console.log(arr) // ['a', 'b', 'c']
```

### 2. `length` 可以读，也可以改

```js
const arr = ["a", "b", "c", "d"]

arr.length = 2
console.log(arr) // ['a', 'b']
```

当把 `length` 改小，数组会被截断；改大时，会出现“空位”。

```js
const arr = ["a", "b"]
arr.length = 5
console.log(arr) // ['a', 'b', empty × 3]
```

## 五、遍历数组

### 1. `for` 循环遍历

```js
const arr = ["小明", "小红", "小刚"]

for (let index = 0; index < arr.length; index++) {
  console.log(arr[index])
}
```

### 2. `for...of` 遍历值

```js
for (const item of arr) {
  console.log(item)
}
```

### 3. `forEach()` 遍历

```js
arr.forEach(function (item, index) {
  console.log(index, item)
})
```

| 方式            | 特点                     |
| --------------- | ------------------------ |
| **`for`**       | 最基础，控制力最强       |
| **`for...of`**  | 语义清晰，适合只拿值     |
| **`forEach()`** | 写法简洁，适合执行副作用 |

## 六、数组和对象的关系

数组本质上也是对象的一种特殊形式。

```js
const arr = ["a", "b", "c"]
console.log(typeof arr) // object
```

### 1. 为什么数组也是对象

因为数组底层也是键值结构，只不过它的 key 通常是连续的数字索引。

### 2. 能不能用 `for...in` 遍历数组

可以，但一般**不推荐**。

```js
const arr = ["a", "b", "c"]

for (const key in arr) {
  console.log(key, arr[key])
}
```

`for...in` 更适合遍历对象属性名，而不是常规数组元素。

## 七、常用数组方法

### 1. 增加元素

| 方法            | 作用           |
| --------------- | -------------- |
| **`push()`**    | 在尾部追加元素 |
| **`unshift()`** | 在头部插入元素 |

```js
const arr = ["b", "c"]
arr.push("d")
arr.unshift("a")
console.log(arr) // ['a', 'b', 'c', 'd']
```

### 2. 删除元素

| 方法          | 作用             |
| ------------- | ---------------- |
| **`pop()`**   | 删除最后一个元素 |
| **`shift()`** | 删除第一个元素   |

```js
const arr = ["a", "b", "c"]
arr.pop()
arr.shift()
console.log(arr) // ['b']
```

### 3. 反转数组

```js
const arr = [1, 2, 3]
arr.reverse()
console.log(arr) // [3, 2, 1]
```

### 4. `splice()`

`splice()` 是一个非常重要的方法，可以实现删除、插入、替换。

```js
const arr = ["a", "b", "c", "d"]

// 从下标 1 开始删除 2 个元素
arr.splice(1, 2)
console.log(arr) // ['a', 'd']
```

```js
const arr = ["a", "d"]

// 从下标 1 开始删除 0 个元素，并插入 'b'、'c'
arr.splice(1, 0, "b", "c")
console.log(arr) // ['a', 'b', 'c', 'd']
```

| 参数            | 说明           |
| --------------- | -------------- |
| **第 1 个参数** | 起始下标       |
| **第 2 个参数** | 删除个数       |
| **后续参数**    | 要插入的新元素 |

## 八、常见方法按“是否改原数组”来理解

这是实际开发里非常重要的一条线索。

| 类型               | 代表方法                                               | 特点                 |
| ------------------ | ------------------------------------------------------ | -------------------- |
| **会改原数组**     | `push`、`pop`、`shift`、`unshift`、`splice`、`reverse` | 适合直接修改当前结果 |
| **通常返回新结果** | `map`、`filter`、`concat`、`slice`                     | 更适合做数据加工     |

如果你在框架状态管理里处理数组，这个区别尤其重要，因为是否原地修改会直接影响状态更新方式。

### 1. `map()`

```js
const scores = [60, 70, 80]

const newScores = scores.map(function (item) {
  return item + 5
})

console.log(newScores) // [65, 75, 85]
console.log(scores) // [60, 70, 80]
```

### 2. `filter()`

```js
const scores = [60, 70, 80, 90]

const passed = scores.filter(function (item) {
  return item >= 80
})

console.log(passed) // [80, 90]
```

## 九、常见注意事项

| 问题                                 | 说明                                  |
| ------------------------------------ | ------------------------------------- |
| **数组下标从 0 开始**                | 不要误以为第一个元素下标是 1          |
| **直接修改 `length` 会影响数组内容** | 改小会截断，改大会产生空位            |
| **`typeof []` 是 `object`**          | 数组是特殊对象                        |
| **`for...in` 不适合常规数组遍历**    | 更推荐 `for`、`for...of`、`forEach()` |

还有一个高频意识：遍历数组时，要分清自己是“只想看一遍”，还是“想产出一个新数组结果”。
