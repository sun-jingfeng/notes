# 正则表达式

## 创建正则表达式：

Let reg = /abc/

   - Let reg = new RegExp(/abc/)

- 测试正则：

reg.test(字符串)：布尔值

- reg.exec(字符串)：null，数组

## 元字符

- 元字符：元字符是一些具有特殊含义的字符（正则内置的符号），完整的正则表达式出了一些简单字符还应该 有特殊字符（元字符）

- MDN：https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Guide/Regular_Expressions

- 正则测试工具 ： http://tool.oschina.net/regex

- 正则表达式在线测试 ： https://c.runoob.com

- jQuery：正则表达式部分

- 为了方便记忆和学习，我们对众多的元字符进行了分类：

   - 量词

   - 字符

   - 字符集合

   - 位置

   - 转义符

   - 修饰符

## 位置边界

- ^ 在开始位置匹配符合规则的字符串，$ 在结尾位置匹配符合规则的字符串

- 注意：如果^和$同时使用为精确匹配

## 字符集合

## [] 匹配字符集合：匹配其中之一

总结：

- 使用连字符 - 表示一个范围，如 [a-zA-Z]、[0-9]

- 使用 ^ 匹配反向字符集，如 [^a-z] 匹配除了小写字母以外的字符（在中括号内部开头写一个即可对当前中 括号内部所有字符取反）

## 预定义类

- 预定义类: 预先写好的类

总结：

- \d：匹配阿拉伯数字 0 ~ 9，\D取反

- \w：匹配英文大小写字母、数字、下划线，\W取反

- \s：匹配空白字符，如空格、换行符等，\S取反

- .：匹配除换行符之外的任何单个字符（在[]中只匹配"."字符）

- (Java|HTML|CSS) 匹配Java或HTML或CSS，|是或的意思，例如(.|\n)、(\w|\W)表示匹配单个字符

## 量词

## 总结：

- + 表示重复至少 1 次

- ? 表示重复 0 次或1次

- 表示重复 0 次或多次

- {m, n} 表示重复 m 到 n 次（{m, }表示重复m到无穷次）

## 修饰符

- 修饰符约束正则执行的某些细节行为，如是否区分大小写、是否支持多行匹配等。

## 总结：

- 修饰符附加在正则表达式之后

- i 是单词 ignore 的缩写，正则匹配时字母不区分大小写

- g 是单词 global 的缩写，匹配所有满足正则表达式的结果

- m 是单词 multiline 的缩写，正则支持多行匹配，多行针对的是 \r 或 \n 等换行符
