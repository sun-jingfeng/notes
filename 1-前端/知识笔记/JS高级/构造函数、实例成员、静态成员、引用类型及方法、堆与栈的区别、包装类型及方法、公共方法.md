# 构造函数、实例成员、静态成员、引用类型、堆与栈、包装类型、公共方法

## 构造函数

- 说明：专门用于创建对象的函数；用 new 调用的函数即为构造函数。

1 <script> 2 // 定义函数 3 function foo() { 4 console.log(' 通过 new 也能调用函数 ...'); 5 } 6 // 调用函数 7 new foo(); 8 </script>

## 总结：

- 使用 new 关键字调用函数的行为被称为实例化

- 实例化构造函数时没有参数时可以省略 ()

- 构造函数内部的 return 返回的值无效，因为构造函数的返回值默认为新创建的对象

- 实践中为了从视觉上区分构造函数和普通函数，习惯将构造函数的首字母大写

## 实例成员

说明：通过构造函数创建的对象称为实例对象，实例对象中的属性和方法称为实例成员。

1 <script> 2 // 构造函数 3 function Person() { 4 // 构造函数内部的 this 就是实例对象 5 6 // 实例对象中动态添加属性 ' ' 7 this.name = 小明 ; 8 // 实例对象动态添加方法（这种添加方法的方式不好，浪费空间， 9 // 更好的做法是在构造函数的原型上加方法，让所有实例公用一个函数） 10 this.sayHi = function () { 11 console.log(' 大家好 ~'); 12 } 13 } 14 15 // 实例化， p1 是实例对象 16 // p1 实际就是 构造函数内部的 this

> 17 let p1 = new Person();

18

> 19 console.log(p1);

> 20 console.log(p1.name); // 访问实例属性

> 21 p1.sayHi(); // 调用实例方法

> 22 </script>

## 总结：

- 构造函数内部 this 实际上就是实例对象，为其动态添加的属性和方法即为实例成员

- 为构造函数传入参数，动态创建结构相同但值不同的对象

- 实例对象的 constructor 属性指向了构造函数（实际上constructor 在实例的原型中）

- instanceof 用于检测实例对象对应的构造函数（底层向上兼容，例如数组的构造函数是Array也是Object，

- 例如 [] instanceof Array 和 [] instanceof Object 结果都是true）

- 构造函数创建的实例对象彼此独立互不影响

## 静态成员

- 说明：在 JavaScript 中底层函数本质上也是对象类型，因此允许直接为函数动态添加属性或方法，构造函数的 属性和方法被称为静态成员。

> 1 <script>

> 2 // 构造函数

> 3 function Person(name, age) {

> 4 // 省略实例成员

> 5 } 6

> 7 // 静态属性

> 8 Person.eyes = 2;

> 9 Person.arms = 2;

> 10 // 静态方法

> 11 Person.walk = function () {

> 12 console.log('^_^ 人都会走路 ...');

> 13 // this 指向 Person

> 14 console.log(this.eyes);

> 15 }

> 16 </script>

## 总结：

- 静态成员指的是通过构造函数+点的方式添加到构造函数本身的属性和方法

- 实例成员指的是直接写在构造方法里由this+点开头的属性和方法

- 静态成员只能通过构造函数名点的方式调用，实例成员只能通过实例化的对象点的方式调用

- 一般公共特征的属性或方法静态成员设置为静态成员

- 静态成员方法中的 this 指向构造函数本身

## 一切皆对象

- 在 JavaScript 中最主要的数据类型有 6 种，分别是字符串、数字、布尔、undefined、函数、对象，常见的对

- 象类型数据包括数组和普通对象。其中字符串、数字、布尔、undefined也被称为简单类型或基础类型，函数、 对象也被称为引用类型。

- 在 JavaScript 内置了一些构造函数，绝大部的数据处理都是基于这些构造函数实现的，JavaScript 基础阶段学

- 习的 Date 就是内置的构造函数。

> 1 <script>

> 2 // 实例化

> 3 let date = new Date(); 4

> 5 // date 即为实例对象

> 6 console.log(date);

> 7 </script>

甚至字符串、数值、布尔、数组、普通对象也都有专门的构造函数，用于创建对应类型的数据。

## 堆与栈的区别

- 堆和栈是内存中的数据存储空间

- 简单类型的数据保存在内存的栈空间中

- 引用类型的数据保存在内存的堆空间中，栈内存中存取的是引用类型的地址

- 实例方法 endsWith 检测是否以某字符结尾

- 实例方法 replace 用于替换字符串，支持正则匹配

- 实例方法 trim 用于去除字符串开头和结尾处的空格

- 注：String 也可以当做普通函数使用，这时它的作用是强制转换成字符串数据类型。

> 5 let num = 12.345;

## 总结：

- valueOf 方法获取原始值，数据内部运算的基础，很少主动调用该方法
