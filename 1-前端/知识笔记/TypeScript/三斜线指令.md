# 三斜线指令

语法

```ts
/// <reference path="./file-name.d.ts" />
```

引入某个文件的声明

- /// <reference types="vite/client" />

引入某个第三方包的声明

/// <reference lib="DOM" />

引入某个内置库的声明

说明

需放到页面顶部，才能生效

示例

【模块】拓展【模块】

声明文件入口

> 1 /// <reference path="./mitt.d.ts" /> 2

> 3 module 'mitt' {

> 4 const a = 123

> 5 }

拓展声明文件

> 1 module 'mitt' {

> 2 const b = 'abc'

> 3 }

## 使用

- 1 import mitt from "mitt" 2

- 3 mitt.a // 123

- 4 mitt.b // "abc"

   - 【模块】拓展【导出为模块的命名空间】

      - 声明文件入口

> 1 /// <reference path="./mitt.d.ts" /> 2

> 3 namespace mitt {

> 4 const a = 123

> 5 } 6

> 7 export = mitt // 注意语法： export = xxx

## 拓展声明文件

> 1 import mitt = require('./index') // 注意语法： import xxx = require('xxx') 2

> 3 module './index' {

> 4 const b = 'abc'

> 5 }
