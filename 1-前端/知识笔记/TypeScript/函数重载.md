# 函数重载

## 声明语法

以 function 关键字声明

不使用函数重载

> 1 function toArray(value: string | number): string[] | number[] {

> 2 if(typeof value === 'string'){

> 3 return value.split('')

> 4 }else{

> 5 return value.toString().split('').map((item: string) => +item)

> 6 }

> 7 } 8

> 9 let arr1 = toArray(123) // string[] | number[]

> 10 let arr2 = toArray('abc') // string[] | number[]

使用函数重载

> 1 function toArray(value: string): string[]

> 2 function toArray(value: number): number[]

> 3 function toArray(value: any) { // 实现签名必须与重载签名兼容，建议参数类型写 any ，返回值类 型不写

> 4 if(typeof value === 'string'){

> 5 return value.split('')

> 6 }else{

> 7 return value.toString().split('').map(Number)

> 8 }

> 9 } 10

> 11 let arr1 = toArray(123) // number[]

> 12 let arr2 = toArray('abc') // string[]

## 使用调用签名

> 1 type Fn = {

> 2 (name: string): void

> 3 (age: number): void

> 4 }

5 6 const fn: Fn = () => {} 7 8 fn("abc") // 允许 9 10 fn(123) // 允许 11 12 fn(true) // 报错：没有与此调用匹配的重载。

## 声明为对象的属性

> 1 type Obj = {

> 2 fn(name: string): void

> 3 fn(age: number): void

> 4 } 5

> 6 const obj: Obj = {

> 7 fn() {},

> 8 } 9

> 10 obj.fn("abc") // 允许 11

> 12 obj.fn(123) // 允许 13

> 14 obj.fn(true) // 报错：没有与此调用匹配的重载。

## 使用交叉类型

> 1 type Fn = ((p: number) => number) &

> 2 ((p: string) => string) &

> 3 ((p: boolean) => boolean) 4

> 5 let fn!: Fn 6

> 7 fn(123) // (p: number) => number

> 8 fn("abc") // (p: string) => string

> 9 fn(true) // (p: boolean) => boolean
