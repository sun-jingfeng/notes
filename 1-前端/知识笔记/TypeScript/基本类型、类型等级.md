## any

## 说明

不进行类型检测，尽量少使用

可执行任何操作

> 1 let something: any

> 2 something = []

> 3 something()

> 4 something.xxx

> 5 // 可以做任何事情 ……

## 特点

- 联合任何类型都是any

- 交叉任何类型都是any

- keyof取值为string | number | symbol

> 1 type T1 = any | { name: string } // type T1 = any 2

> 3 type T2 = any & { name: string } // type T2 = any 4

> 5 type T3 = keyof any // type T = string | number | symbol

## 特点

- 联合任何类型都是unknown

- 交叉任何类型都是被交叉的类型
