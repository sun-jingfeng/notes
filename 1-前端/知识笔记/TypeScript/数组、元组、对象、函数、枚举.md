# 数组、元组、对象、函数、枚举

## 一、这篇的作用

这一篇属于 TypeScript 的基础结构类型总览，核心目标是把最常见的几类类型组织起来理解：

1. 数组和元组。
2. 对象类型。
3. 函数类型。
4. 枚举。

这些内容看起来分散，但本质上都在回答同一个问题：

**如何用 TypeScript 描述不同形状的数据和调用方式。**

---

## 二、数组

数组用于描述“同一类元素组成的列表”。

### 2.1 常见写法

```ts
const arr1: number[] = [1, 2, 3]
const arr2: string[] = ["a", "b", "c"]
const arr3: (number | string)[] = [1, "a", 2, "b"]
const arr4: Array<number> = [1, 2, 3]
```

`number[]` 和 `Array<number>` 都是合法写法。

### 2.2 读取数组元素类型

```ts
type List = ["a", "b", "c"]

type T1 = List[0]
type T2 = List[number]
type T3 = List["length"]
```

这说明：

1. 可以通过索引拿到某一项类型。
2. `T[number]` 可以拿到所有元素的联合类型。
3. 元组的 `length` 往往还是字面量数字。

---

## 三、元组

元组本质上也是数组，但它强调：

1. 长度通常固定。
2. 每个位置的类型可以不同。

### 3.1 基本写法

```ts
const user: [string, number, boolean] = ["Sun", 20, true]
const user2: [name: string, age: number, male: boolean] = ["Sun", 20, true]
```

带标签的元组可读性更好，尤其在返回值或复杂参数中。

### 3.2 元组和普通数组的区别

| 对比项   | 数组       | 元组         |
| -------- | ---------- | ------------ |
| 元素类型 | 通常相同   | 可不同       |
| 长度     | 通常不固定 | 通常固定     |
| 场景     | 列表数据   | 固定结构数据 |

### 3.3 常见场景

1. React Hook 返回值。
2. 某些函数的固定返回结构。
3. 需要“按位置表达语义”的少量数据。

```ts
function useLoading(): [boolean, () => void] {
  return [true, () => {}]
}
```

### 3.4 元组配合泛型与映射类型

当你希望“按位置保留每个元素自己的类型”时，元组和泛型经常一起出现。

```ts
type WrapTuple<T extends readonly unknown[]> = {
  [K in keyof T]: { data: T[K] }
}

type Result = WrapTuple<[number, boolean, string]>
```

### 3.5 `as const` 的意义

```ts
const list = [123, true, "abc"] as const
```

在现代 TypeScript 里，`as const` 往往是保留字面量和元组信息的重要手段。

## 四、对象类型

对象类型用来约束对象的结构。

### 4.1 常规属性

```ts
type User = {
  name: string
  age: number
}

const user: User = {
  name: "Sun",
  age: 20,
}
```

### 4.2 可选属性

```ts
type User = {
  name: string
  age: number
  motorbike?: string
}
```

`?` 表示这个属性可以不存在。

### 4.3 只读属性

```ts
type User = {
  readonly id: number
  name: string
}
```

### 4.4 索引签名

```ts
type User = {
  name: string
  age: number
  [key: string]: string | number
}
```

注意：索引签名的值类型必须能覆盖已声明属性的类型。

### 4.5 映射类型

```ts
type Keys = "name" | "age"

type User = {
  [K in Keys]: string
}
```

映射类型常用于批量生成新类型，是很多工具类型的基础。

### 4.6 键名重映射

```ts
type PrefixKeys<T extends object> = {
  [K in keyof T as `key_${K & string}`]: T[K]
}

type Obj = {
  a: string
  b: number
  c: boolean
}

type T1 = PrefixKeys<Obj>
```

### 4.7 通过索引获取值的类型

```ts
type Person = {
  name: string
  address: {
    num: number
  }
}

type PersonName = Person["name"]
type PersonAddressNum = Person["address"]["num"]
```

### 4.8 取对象的键联合和值联合

```ts
type Person = {
  name: string
  address: {
    num: number
  }
}

type PropUnion = keyof Person
type ValueUnion = Person[keyof Person]
```

## 五、函数类型

TypeScript 不仅能描述“值是什么”，也能描述“函数怎么调用”。

### 5.1 直接标注

```ts
function add(a: number, b: number): number {
  return a + b
}
```

### 5.2 函数类型表达式

```ts
type AddFn = (a: number, b: number) => number

const add: AddFn = (a, b) => a + b
```

### 5.3 可选参数与默认参数

```ts
function greet(name: string, age?: number) {
  console.log(name, age)
}

function fetchData(url: string, method: string = "GET") {
  console.log(url, method)
}
```

### 5.4 剩余参数

```ts
function sum(a: number, ...args: number[]) {
  return args.reduce((total, current) => total + current, a)
}
```

### 5.5 为 `this` 标注类型

```ts
const person = {
  name: "Sun",
  age: 20,
}

function getName(this: typeof person, key: keyof typeof person) {
  return this[key]
}

getName.call(person, "name")
```

### 5.6 调用签名与构造签名

调用签名表示“这是一个可调用的值”：

```ts
type Counter = {
  (num: number): number
  count: number
}

const counter: Counter = num => num + 1
counter.count = 100
```

构造签名表示“这是一个可 `new` 的值”：

```ts
type SomeObject = {
  name: string
}

type SomeConstructor = {
  new (s: string): SomeObject
}

function createInstance(ctor: SomeConstructor) {
  return new ctor("hello")
}
```

### 5.7 一个容易混淆的点

对象里的函数属性写法和方法写法在类型兼容上可能表现不同：

```ts
type Obj1 = {
  fn: () => number
}

type Obj2 = {
  fn(): number
}
```

它们看起来接近，但在某些严格配置和参数变型场景下会有差异。

## 六、枚举 `enum`

枚举适合表示一组相关的常量。

### 6.1 数字枚举

```ts
enum Direction {
  Up,
  Down,
  Left,
  Right,
}
```

默认从 `0` 开始递增。

### 6.2 字符串枚举

```ts
enum Status {
  Idle = "idle",
  Loading = "loading",
  Success = "success",
}
```

字符串枚举在调试和接口传值里更直观。

### 6.3 数字枚举的自动推导

```ts
enum UserRole {
  USER = 10,
  ADMIN,
  SUPER_ADMIN,
}
```

此时：

1. `USER` 是 `10`。
2. `ADMIN` 会自动变成 `11`。
3. `SUPER_ADMIN` 会自动变成 `12`。

### 6.4 反向映射

数字枚举可以通过值反查键：

```ts
enum Level {
  Low,
  High,
}

Level[0]
```

但字符串枚举不支持这种反向映射。

### 6.5 常量枚举 `const enum`

```ts
const enum UserRole {
  USER,
  ADMIN,
}

UserRole.USER
```

`const enum` 通常不会生成同名运行时代码，因此更轻量，但也少了反向映射等运行时特性。

### 6.6 `enum` 的优缺点

| 优点             | 缺点                         |
| ---------------- | ---------------------------- |
| 语义清晰         | 会生成额外运行时代码         |
| 适合固定常量集合 | 某些场景下不如联合字面量轻量 |

### 6.7 实际建议

很多现代前端项目里，简单场景更常用联合字面量替代 `enum`：

```ts
type Status = "idle" | "loading" | "success"
```

这样更轻量，也更贴近类型系统本身。

---

## 七、小结

1. 数组适合描述同类型列表，元组适合描述固定结构数据。
2. 对象类型要重点掌握常规属性、可选属性、只读属性、索引签名和映射类型。
3. 可以通过索引访问、`keyof` 和映射类型继续从对象类型中提取信息。
4. 函数类型不仅能约束参数和返回值，也能描述调用签名、构造签名和 `this`。
5. 枚举适合表达固定常量集合，但联合字面量在现代前端里也非常常见。
6. 学这篇时，重点不是记语法碎片，而是理解“结构约束”和“类型复用”。
