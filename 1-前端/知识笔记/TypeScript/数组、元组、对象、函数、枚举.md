数组

## 语法

> 1 const arr1: number[] = [1, 2, 3]

> 2 const arr2: string[] = ['a', 'b', 'c']

> 3 const arr3: (number | string)[] = [1, 2, 3, 'a', 'b', 'c'] // "|" 是联合类型语法，表 示这几种类型都可以
