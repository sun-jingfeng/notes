# 条件类型、分发

## 条件类型

类似 JS 中的三元表达式

> 1 type ResStatus<T><T>T>> = T extends 200 | 201 | 204 | 206 ?

> 2 type Status1 = ResStatus<200>; // type Status1 = "success"

> 3 type Status2 = ResStatus<300>; // type Status2 = "fail"

type ResStatus<T><T>T>> = T extends 200 | 201 | 204 | 206 ? "success" : "fail";

## 与泛型组合使用

- 1 type Conditional<T, U> = T extends U ? true : false; 2 type R1 = Conditional<"abc", string>; // type R1 = true 3 type R2 = Conditional<"abc", number>; // type R2 = false

## 根据泛型的类型判断函数返回值类型

> 1 type FormatReturnValue<T> = T extends string

> 2 ? string

> 3 : T extends number

> 4 ? number

> 5 : never;

> 6 function sum<T>(a: T, b: T): FormatReturnValue<T> {

> 7 return a + (b as any); // 泛型之间不能做运算

> 8 } 9

> 10 let r1 = sum(1, 2); // let r1: number

> 11 let r2 = sum("a", "b"); // let r2: string

> 12 let r3 = sum(undefined, undefined); // let r3: never

判断两个类型完全相等

> 1 type NoDistrubte<T> = T & Object

> 2 type IsEqual<T, U, Success, Fail> = NoDistrubte<T> extends U

> 3 ? NoDistrubte<U> extends T

> 4 ? Success

> 5 : Fail

> 6 : Fail

7 8 type T1 = IsEqual<1 | 2, 2 | 1, true, false> // type T1 = true 9 type T2 = IsEqual<any, unknown, true, false> // type T2 = true

## 分发

- 条件

   - 泛型传入类型并且用extends比较

   - 传入的是联合类型

   - 比较时用裸类型（T是裸类型，T[]、[T]等是非裸类型）

## 示例

> 1 type SelectType<T> = T extends number ? true : false 2

> 3 type T1 = SelectType<number | string> // type T1 = boolean （先判断 number 是不是 number ，得 true 。再判断 string 是不是 number ，得 false 。联合起来是 boolean ）

- 4 type T2 = number | string extends number ? true : false // type T2 = false

## 分发机制导致的子类型判断错误

## 演示

- 1 type T1 = 1 | 2 | 3 extends 1 | 2 ? true : false // type T1 = false 2 3 type UnionAssets<T, U> = T extends U ? true : false 4 type T2 = UnionAssets<1 | 2 | 3, 1 | 2> // type T2 = boolean ，错误

## 如何避免

## 非裸类型

> 1 type UnionAssets<T, U> = T[] extends U[] ? true : false

> 2 type T2 = UnionAssets<1 | 2 | 3, 1 | 2> // type T2 = false ，正确

## 声明禁止分发类型

1

type NoDistrubte<T> = T & Object // 或 T & {}

> 2 type UnionAssets<T, U> = NoDistrubte<T> extends U ? true : false

> 3 type T2 = UnionAssets<1 | 2 | 3, 1 | 2> // type T2 = false ，正确

## 自带分发的类型

any（任何时候都分发）

> 1 type T = any extends number ? true : false // type T = boolean

## never（通过泛型传递的时候会分发）

> 1 type T1 = never extends never ? true : false // type T1 = true

2

> 3 type IsNever<T> = T extends never ? true : false

- 4 type T2 = IsNever<never> // type T2 = never
