## 与泛型结合使用

对泛型的类型有要求

> 1 type SaySomething<T> = `hi, ${T}` // 报错：不能将类型 "T" 分配给类型 "string | number | bigint | boolean | null | undefined" 。

## 限定泛型的类型

> 1 // 方式 1

> 2 type SaySomething<T extends string | number | boolean> = `hi, ${T}`

3

> 4 type T1 = SaySomething<"Sun"> // type T1 = "hi, Sun" 5

> 6 type T2 = SaySomething<123> // type T2 = "hi, 123" 7

> 8 type T3 = SaySomething<true> // type T3 = "hi, true" 9

> 10 // 方式 2

> 11 type SaySomething<T> = `hi, ${T & string}` 12

> 13 type T1 = SaySomething<"Sun"> // type T1 = "hi, Sun" 14

> 15 type T2 = SaySomething<123> // type T2 = never

## 字符串相关的内置工具类型

Uppercase，全部字母转大写

> 1 type T = Uppercase<"sun"> // type T = "SUN"

Lowercase，全部字母转小写

> 1 type T = Lowercase<"SUN"> // type T = "sun"

Capitalize，首字母转大写

> 1 type T = Capitalize<"sun"> // type T = "Sun"

Uncapitalize，首字母转小写

> 1 type T = Uncapitalize<"SUN"> // type T = "sUN"
