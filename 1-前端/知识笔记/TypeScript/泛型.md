## 泛型约束

约束泛型必须是某些类型

- 1 const handle = <T extends number | string>(value: T): T => value;

- 2 handle(1);

- 3 handle("a");

- 4 handle(true); // 报错：类型 "boolean" 的参数不能赋给类型 "string | number" 的参数。

约束泛型必须有某些属性

> 1 function getLength<T extends { length: number }>(value: T): number {

> 2 return value.length;

> 3 }

> 4 getLength([]);

> 5 getLength("a");

> 6 getLength(() => {}); // 函数的 length 是形参个数

> 7 getLength(1); // 报错：类型 "number" 的参数不能赋给类型 "{ length: number; }" 的参数。

用一个泛型约束另一个泛型

> 1 function getValue<T extends object, U extends keyof T>(obj: T, key: U) {

> 2 return obj[key];

> 3 } 4

> 5 getValue({ a: 1, b: 2, c: 3 }, "b"); 6

> 7 // 当然也可以这么写

> 8 function getValue<T extends object>(obj: T, key: keyof T) {

> 9 return obj[key];

> 10 }
