# 类型别名、接口

接口和类型别名的区别

type

   - 常用于描述函数、联合类型、工具类型、映射类型、条件类型

   - 无法拓展类型，只能通过交集生成合并后的新类型

   - 不可以重名

- interface

   - 常用于描述对象、类

   - 可以通过重名、扩展（extends）的方式拓展类型

   - 可以重名，可以被扩展（extends）、继承（extends）、实现（implements）

## 类型别名

基本用法

> 1 type Direction = 'top' | 'right' | 'bottom' | 'left'

> 2 let direction: Direction = 'top'
