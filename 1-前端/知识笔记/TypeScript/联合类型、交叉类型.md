# 联合类型、交叉类型

## 联合类型

类型符合联合中的一种，可理解为「或」、并集。

- 1 let strOrNum: string | number 2 strOrNum = 'abc' 3 strOrNum = 123

确定类型前，只能使用联合类型共有的方法。确定类型后，可以使用对应的方法。

> 1 let strOrNum: string | number 2

> 3 strOrNum = Math.random() > 0.5 ? 'abc' : 123

> 4 strOrNum.toString() // toString 为数字和字符串共有的方法 5

> 6 strOrNum = 'abc'

> 7 strOrNum.charAt(0) 8

> 9 strOrNum = 123

> 10 strOrNum.toFixed(0)

## 函数类型之间交叉

交叉后为重载函数

> 1 type Fn = ((p: number) => number) &

> 2 ((p: string) => string) &

> 3 ((p: boolean) => boolean) 4

> 5 let fn!: Fn 6

> 7 fn(123) // (p: number) => number

> 8 fn("abc") // (p: string) => string

> 9 fn(true) // (p: boolean) => boolean
