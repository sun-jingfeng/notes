# 装饰器

## 说明

## 本质是一个函数

- 只能用来标注或修改类及其成员

- 需要在tsconfig.json中设置compilerOptions.experimentalDecorators为true才能使用


- 是一项实验性特性，在未来的版本中可能会发生改变

装饰类的方法

基本用法

代码

- 1 function Enum(target: any, key: string, descriptor: PropertyDescriptor) {}

- 2

- 3 class Animal {

- 4 @Enum 5 eat() {} 6 }

说明

target：类的原型

- key：被装饰的函数的名字，此示例中为eat

- descriptor.writable：被装饰的函数是否可写，默认值为true

- descriptor.value：被装饰的函数原来的值

- descriptor.enumerable：被装饰的函数是否可枚举，默认值为false

- descriptor.configurable：被装饰的函数是否可被删除，默认值为true

修改方法为可枚举

代码

> 1 function Enum(target: any, key: string, descriptor: PropertyDescriptor) {

> 2 descriptor.enumerable = true

> 3 } 4

> 5 class Animal {

> 6 @Enum

> 7 eat() {}

> 8 }
