# 赋值兼容性

对象

- 说明

   - 可以理解成"你要的我都有就行"、"属性多的可以赋值给属性少的"、"子类可以赋值给父类" 赋值后无法访问多余的属性

## 示例

> 1 let obj1 = {

> 2 a: 123,

> 3 b: 123,

> 4 }

> 5 let obj2 = {

> 6 a: 123,

> 7 b: 123,

> 8 c: 123,

> 9 } 10

> 11 obj1 = obj2 // 允许，但无法访问 obj2 多余的属性

> 12 obj1.c // 报错：类型 "{ a: number; b: number; }" 上不存在属性 "c" 。 13

> 14 obj2 = obj1 // 报错：类型 "{ a: string; b: string; }" 中缺少属性 "c" ，但类型 "{ a: string; b: string; c: string; }" 中需要该属性。

## 函数

- 参数角度

   - 说明

      - 可以理解成"参数少的可以赋值给参数多的"、"参数可以传的多但用的少"

      - 赋值后仍需要传满参数

示例

1

let fn1 = (p1: number, p2: number) => 123

> 2 let fn2 = (p1: number) => 123 3

> 4 fn1 = fn2 // 允许，但仍需要传满参数

> 5 fn1(123) // 报错：应有 2 个参数，但获得 1 个。 6

> 7 fn2 = fn1 // 报错：不能将类型 "(p1: number, p2: number) => number" 分配给类型 "(p1: number) => number" 。

返回值角度

说明

- 参考联合类型

- 赋值后返回值仍是完整的联合类型

示例

> 1 let fn1: () => number | string

> 2 let fn2: () => number 3

> 4 fn1 = fn2 // 允许

> 5 fn1().toUpperCase() // 报错：类型 "string | number" 上不存在属性 "toUpperCase" 。 6

> 7 fn2 = fn1 // 报错：不能将类型 "() => string | number" 分配给类型 "() => number" 。

## 私有属性

说明

无法兼容

示例

> 1 class A {

> 2 private key1 = 123

> 3 }

> 4 class B {

> 5 private key1 = 123

> 6 } 7

> 8 const obj: A = new B() // 报错：不能将类型 "B" 分配给类型 "A" 。类型具有私有属性 "key1" 的单独声 明。

## 普通属性

## 说明

## 相同即可兼容

## 示例

> 1 type T1 = number

> 2 type T2 = number 3

- 4 const data1: T1 = 123

- 5

- 6 const data2: T2 = data1 // 允许

## 区别方法

- 1 class AddType<S> { 2 private _type!: S 3 } 4 type NewType<T, S extends string> = T & AddType<S> // AddType<S> 的写法不固定，也可以 换成 [S] ，只要 T1 、 T2 别变成 never 就行

- 5 type T1 = NewType<number, "T1">

- 6 type T2 = NewType<number, "T2">

7

- 8 const data1: T1 = 123 as T1

9

> 10 const data2: T2 = data1 // 报错：不能将类型 "T1" 分配给类型 "T2" 。
