# 逆变、协变

## 逆变

## 说明

   - 声明时，参数可以传父类

   - 调用时，依旧受原始类型的限制

- 理解：声明的时候，参数我可以少属性。调用的时候，你传多了我可以不用。

示例

> 1 class Parent {

> 2 house() {}

> 3 }

> 4 class Son extends Parent {

> 5 car() {}

> 6 }

> 7 class GrandSon extends Son {

> 8 sleep() {}

> 9 } 10

> 11 type Fn = (p1: Son) => void 12

> 13 const fn: Fn = (p1: Parent) => {} // 参数类型不是 Son ，而是父类 Parent ，允许 14

> 15 // 调用时，依旧受 Son 类型的限制

> 16 fn(new Parent()) // 报错：类型 "Parent" 的参数不能赋给类型 "Son" 的参数。

> 17 fn(new Son()) // 传 Son 本身，允许

> 18 fn(new GrandSon()) // 传 Son 的子类，允许

协变

说明

- 声明时，返回值可以返子类

调用时，依旧返回原始类型

理解：声明的时候，返回值我可以多属性。调用的时候，你得多了你可以不用。

示例

> 1 class Parent {

> 2 house() {}

> 3 }

> 4 class Son extends Parent {

> 5 car() {}

> 6 }

> 7 class GrandSon extends Son {

> 8 sleep() {}

> 9 } 10

> 11 type Fn = () => Son 12

> 13 const fn: Fn = () => {

> 14 return new GrandSon() // 返回值类型不是 Son ，而是子类 GrandSon ，允许

> 15 } 16

> 17 // 调用时，返回值依旧是 Son

> 18 fn() // const fn: () => Son

## 启用逆变示例

- 说明：类型要求是子，声明时父可以，孙不可以

## 代码

> 1 class Parent {

> 2 house() {}

> 3 }

> 4 class Son extends Parent {

> 5 car() {}

> 6 }

> 7 class GrandSon extends Son {

> 8 sleep() {}

> 9 }

10

> 11 type Obj = {

> 12 fn: (p: Son) => void // 注意这里的语法

> 13 } 14

> 15 const obj1: Obj = {

> 16 fn(p: Parent) {}, // 允许

> 17 }

> 18 const obj2: Obj = {

> 19 fn(p: Son) {}, // 允许

> 20 }

> 21 const obj3: Obj = {

> 22 fn(p: GrandSon) {}, // 报错：不能将类型 "(p: GrandSon) => void" 分配给类型 "(p: Son) => void" 。参数 "p" 和 "p" 的类型不兼容。

> 23 } 24

> 25 obj1.fn() // 参数要求 Son 类型

> 26 obj2.fn() // 参数要求 Son 类型

> 27 obj3.fn() // 参数要求 Son 类型
