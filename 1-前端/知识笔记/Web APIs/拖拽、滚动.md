# 拖拽、滚动

## 步骤

   - 在可被拖动的元素上，设置属性draggable为true（这个true是字符串，不是布尔值）

   - 获取可被拖动的元素，监听事件dragstart：保存被拖动的元素以备后续操作使用

   - 获取目标容器元素，监听事件dragover、dragenter：两个事件都阻止默认行为（此操作会让目标元素成

   - 为"可释放目标"：可以监听到drop事件，且改变此元素的放置反馈）

      - 提示：如果要在拖动的过程中执行业务逻辑，可以在事件dragover的监听函数中写，它比dragenter触 发频率更高。

   - 对目标容器元素监听事件drop：执行拖动结束时的操作

- 拖动事件参考文档：HTML 拖放 API、拖拽操作
