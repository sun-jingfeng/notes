# uni-app 快速入门

## 一、一句话理解

uni-app 的核心价值不是“写一套代码就再也不用适配”，而是尽量把多端开发中的重复劳动压缩到一套更统一的工程体系里。

---

## 二、什么是 uni-app

**uni-app** 是一个基于 Vue 生态的多端开发框架，目标是让开发者通过一套代码，编译输出到多个平台，例如 H5、App、微信小程序等。

---

## 三、uni-app 解决了什么问题

多端开发最常见的问题是：

1. 同一业务要重复开发多份。
2. 多端交付节奏不一致。
3. 维护成本高。

uni-app 的思路就是把这些重复劳动尽量统一起来。

它解决的重点是复用效率，不是所有平台完全零差异。

---

## 四、uni-app 的主要优势

| 优势               | 说明                           |
| ------------------ | ------------------------------ |
| **多端复用**       | 一套代码可面向多个平台         |
| **Vue 语法友好**   | 对熟悉 Vue 的前端更容易上手    |
| **生态相对成熟**   | 有组件、插件、工程化支持       |
| **适合业务型项目** | 尤其适合表单、列表、内容类应用 |

### 1. 但不要神化

多端框架通常解决的是“复用效率”，不是“所有平台完全零差异”。不同平台仍然可能存在能力差异和细节适配工作。

---

## 五、uni-app 和微信小程序的关系

uni-app 并不是微信小程序本身，而是可以把代码编译输出为微信小程序的一种开发方案。

### 1. 对前端的直接好处

如果你已经熟悉 Vue，那么切到 uni-app 往往比直接从零学习另一套多端语法更顺。

### 2. 但仍要理解平台差异

即使编译目标是微信小程序，你仍然要知道：

1. 微信宿主环境限制。
2. 小程序登录、支付、授权等平台能力。
3. 不同端的 API 和样式差异。

也就是说，用 uni-app 开发小程序，并不等于可以不懂小程序平台本身。

---

## 六、快速开始一个 uni-app 项目

### 1. 基本流程

```text
安装开发工具 → 创建 uni-app 项目 → 配置项目 → 运行到目标平台 → 开始开发
```

### 2. 常见步骤

1. 安装 HBuilderX 或其他支持 uni-app 的开发环境。
2. 创建 uni-app 项目模板。
3. 配置 `manifest.json`。
4. 设置微信小程序的 AppID。
5. 运行到微信小程序环境验证。

---

## 七、项目目录怎么理解

一个典型 uni-app 项目通常会看到这些目录或文件：

| 路径            | 作用                 |
| --------------- | -------------------- |
| `pages/`        | 业务页面目录         |
| `static/`       | 静态资源             |
| `main.js`       | 应用入口             |
| `App.vue`       | 应用级配置和全局样式 |
| `manifest.json` | 应用打包与平台配置   |
| `pages.json`    | 页面路由与导航配置   |
| `uni.scss`      | 全局样式变量         |

### 1. 一个简单理解

如果你学过 Vue 项目，可以把它理解成“一个带多端编译能力的 Vue 工程”。

---

## 八、开发时最常接触的几个文件

### 1. `App.vue`

负责应用级别的入口配置、全局样式和生命周期。

### 2. `pages.json`

负责页面路由、导航条、tabBar 等页面级配置。

### 3. `manifest.json`

负责应用名称、版本号、AppID、平台构建相关信息。

### 4. 页面 `.vue`

每个页面通常以 Vue 单文件组件形式组织。

这些文件的重点不是死记名字，而是知道：路由去哪配、平台参数去哪配、全局入口去哪配。

---

## 九、写微信小程序时为什么会选 uni-app

### 1. 常见原因

1. 团队本身熟悉 Vue。
2. 后续可能要扩展到 H5 或 App。
3. 希望减少多端维护成本。

### 2. 什么时候不一定最优

1. 项目只服务微信小程序且深度依赖平台特性。
2. 团队本身对原生小程序生态更熟。
3. 多端复用收益并不明显。

### 3. 一个更直观的选择表

| 场景                                       | 更适合的方案         |
| ------------------------------------------ | -------------------- |
| **后续要扩展 H5 / App / 小程序多端**       | uni-app              |
| **团队熟悉 Vue，想快速统一开发方式**       | uni-app              |
| **只做微信小程序，且依赖很多原生平台细节** | 原生小程序可能更稳   |
| **复用收益很低，只是一个小型单端项目**     | 不一定非要上 uni-app |

---

## 十、一个入门练习思路

可以先做一个非常小的练习项目，比如“拍照预览”或“待办列表”。

### 1. 练习目标

1. 跑通页面。
2. 配通路由。
3. 理解页面配置。
4. 体验一套代码编译到微信小程序。

### 2. 这样做的好处

先把工程跑通，再去追求复杂业务，比一开始就做重项目更稳。

---

## 十一、总结

1. uni-app 是基于 Vue 生态的多端开发方案。
2. 它的核心价值是多端复用和统一开发体验。
3. 项目中最重要的几个配置文件是 `App.vue`、`pages.json`、`manifest.json`。
4. 即使用 uni-app 开发微信小程序，也仍然要理解微信平台本身的规则和限制。
5. 学这篇的重点，是建立“多端框架如何组织项目”的整体认知。
