## I. Introducing and Installing IDEA

### 1. What Is IDEA?

**IntelliJ IDEA** is a **Java integrated development environment** (IDE) developed by JetBrains, widely regarded as the best Java IDE.

| Name       | Full name                                                     |
| -------- | ------------------------------------------------------ |
| **IDEA** | **I**ntelli**J** **IDEA**                              |
| **IDE**  | **I**ntegrated **D**evelopment **E**nvironment |

### 2. Why Choose IDEA?

| Advantage          | Description          |
| ----------- | ----------- |
| **Intelligent code completion**  | Context-aware suggestions   |
| **Powerful refactoring** | Rename, extract methods, and more with one action |
| **Code analysis**    | Real-time error and warning checks   |
| **Rich plugin ecosystem**   | Support for many frameworks and tools   |
| **Excellent debugger**  | Visual debugging       |
| **Git integration**  | Built-in version control      |

### 3. IDEA Editions

Starting with **2025.3**, IntelliJ IDEA uses a unified distribution instead of separate Community and Ultimate installers; free features and Ultimate subscription features are available in the same application.

| Access option             | Description                | Cost           |
| ------------------ | ----------------- | ------------ |
| **Ultimate subscription**      | Unlocks additional framework and enterprise development features | Paid, with a trial available |
| **Free features**           | Includes core Java development features | **Free**       |

**For beginners**: The unified distribution's free features are sufficient for learning Java fundamentals. Older tutorials may still refer to the Community/Ultimate names. See the [JetBrains unified distribution FAQ](https://lp.jetbrains.com/intellij-idea-unified-faq/).

### 4. Download IDEA

**Official download**: <https://www.jetbrains.com/idea/download/>

**Recommended approach**: Manage JetBrains products with **Toolbox App**

    Benefits of Toolbox App:
    ├─ Manage all JetBrains IDEs in one place
    ├─ Automatic updates
    ├─ Manage multiple versions
    └─ Quickly open projects

### 5. Install IDEA (Windows Example)

    1. Download the installer (.exe)
    2. Double-click to run it
    3. Choose an installation path (preferably without Chinese characters or spaces)
       Recommended: D:\JetBrains\IntelliJ IDEA
    4. Select installation options:
       ☑ Create Desktop Shortcut
       ☑ Add "Open Folder as Project" (context menu)
       ☑ .java (associate .java files)
       ☑ Add launchers dir to the PATH (environment variable)
    5. Click Install to complete installation
    6. Start IDEA

### 6. Install IDEA (macOS)

    1. Download the .dmg file
    2. Double-click to open it
    3. Drag IntelliJ IDEA into the Applications folder
    4. Open IDEA from Launchpad

### 7. First-Launch Setup

    1. Accept the user agreement
    2. Choose a UI theme (Darcula for dark / Light for light)
    3. Choose whether to send usage statistics
    4. Proceed to the welcome screen

### 8. Configure the JDK

    Option 1: Configure it when creating a project
    1. New Project → JDK dropdown
    2. Select "Add JDK..."
    3. Select the JDK installation directory

    Option 2: Global configuration
    1. File → Project Structure (Ctrl + Alt + Shift + S)
    2. Platform Settings → SDKs
    3. Click "+" → Add JDK
    4. Select the JDK installation directory

    Option 3: Download a JDK (IDEA 2020.3+)
    1. New Project → JDK dropdown
    2. Select "Download JDK..."
    3. Choose a version and vendor (Eclipse Temurin is recommended)
    4. Click Download

## II. Your First Code in IDEA

### 1. Create a New Project

    Steps:
    1. Open IDEA and click "New Project"
    2. Select "New Project" on the left
    3. Enter the project details:
       - Name: HelloWorld (project name)
       - Location: D:\JavaProjects (project location)
       - Language: Java
       - Build system: IntelliJ (choose this as a beginner)
       - JDK: select the installed JDK 17
    4. Click "Create" to create the project

### 2. IDEA Project Structure

    HelloWorld/                    # Project root
    ├─ .idea/                      # IDEA configuration files (leave these alone)
    ├─ src/                        # Source directory (where you write code)
    │   └─ Main.java               # Class generated by default
    ├─ HelloWorld.iml              # Project configuration file
    └─ External Libraries/         # External libraries (JDK, etc.)

### 3. Create a Java Class

    Steps:
    1. Right-click the src directory
    2. Choose New → Java Class
    3. Enter the class name: HelloWorld
    4. Press Enter to confirm

### 4. Write HelloWorld

```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

### 5. Run the Program

**Option 1: Click the Run button**

    1. Click the green triangle ▶ to the left of the code
    2. Select "Run 'HelloWorld.main()'"

**Option 2: Run from the context menu**

    1. Right-click in the code editor
    2. Select "Run 'HelloWorld.main()'"

**Option 3: Keyboard shortcut**

| System      | Shortcut                                             |
| ------- | ----------------------------------------------- |
| Windows | `Ctrl + Shift + F10` (first run) / `Shift + F10` (subsequent runs) |
| macOS   | `Ctrl + Shift + R` (first run) / `Ctrl + R` (subsequent runs)      |

### 6. View the Output

    After running, the Run window appears at the bottom and displays:

    Hello, World!

    Process finished with exit code 0

## VI. Code Generation (Alt + Insert)

Inside a class, press `Alt + Insert` (Windows) or `Cmd + N` (macOS):

| Option                          | Description                      |
| --------------------------- | ----------------------- |
| **Constructor**             | Generate a constructor                  |
| **Getter and Setter**       | Generate getter/setter methods     |
| **Getter**                  | Generate getters only              |
| **Setter**                  | Generate setters only              |
| **equals() and hashCode()** | Generate equals and hashCode methods |
| **toString()**              | Generate a toString method          |
| **Override Methods**        | Override superclass methods                  |
| **Implement Methods**       | Implement interface methods                  |
| **Delegate Methods**        | Delegate methods                    |
| **Test Method**             | Generate a test method                  |

**Example**: Generate a JavaBean

```java
public class User {
    private String name;
    private int age;

    // Press Alt + Insert → Constructor → select fields → OK
    public User(String name, int age) {
        this.name = name;
        this.age = age;
    }

    // Press Alt + Insert → Getter and Setter → select fields → OK
    public String getName() { return name; }
    public void setName(String name) { this.name = name; }
    public int getAge() { return age; }
    public void setAge(int age) { this.age = age; }

    // Press Alt + Insert → toString() → OK
    @Override
    public String toString() {
        return "User{name='" + name + "', age=" + age + "}";
    }
}
```

## VII. Quick Fixes (Alt + Enter)

When code contains an error or warning, press `Alt + Enter` for quick fixes:

| Situation    | Fix option                                                 |
| ----- | ---------------------------------------------------- |
| Missing import  | Import class                                         |
| Undeclared variable | Create local variable                                |
| Unimplemented method | Implement methods                                    |
| Type mismatch | Cast to ...                                          |
| Redundant code  | Simplify                                             |
| Missing method  | Create method                                        |
| Missing class   | Create class                                         |
| Unhandled exception | Add exception to signature / Surround with try-catch |
| Code that can be optimized | Replace with ...                                     |
| Unclosed resource | Surround with try-with-resources                     |

**Example**:

```java
// ArrayList is highlighted in red (not imported)
ArrayList<String> list = new ArrayList<>();

// Place the caret on ArrayList and press Alt + Enter
// Select "Import class" to import it automatically
import java.util.ArrayList;
```

## VIII. Debugging

    Line breakpoint: click to the left of a line number to show a red dot 🔴
    Conditional breakpoint: right-click the red dot → set Condition (e.g. i > 5)
    Logging breakpoint: right-click the red dot → clear Suspend, select Log, and configure the output
    Exception breakpoint: View Breakpoints → "+" → Java Exception Breakpoints

    Settings → Editor → General → Auto Import
    ├─ ☑ Add unambiguous imports on the fly
    └─ ☑ Optimize imports on the fly

    ├─ ☑ Show line numbers
