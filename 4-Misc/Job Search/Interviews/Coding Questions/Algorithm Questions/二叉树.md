# 二叉树

## 一、题型认知

二叉树题最核心的能力是：**把每个节点当成一棵更小的子树来思考。**

| 题型            | 核心问题                           |
| --------------- | ---------------------------------- |
| **遍历类**      | 当前节点什么时候处理               |
| **高度/路径类** | 当前节点的答案依赖左右子树什么信息 |
| **构造类**      | 根节点是谁，左右子树如何递归切分   |
| **层序类**      | 更适合 BFS 或“按深度收集结果”      |

下面代码默认使用同一个节点定义：

```typescript
class TreeNode {
  val: number
  left: TreeNode | null
  right: TreeNode | null

  constructor(val?: number, left?: TreeNode | null, right?: TreeNode | null) {
    this.val = val ?? 0
    this.left = left ?? null
    this.right = right ?? null
  }
}
```

常见递归框架：

```typescript
function dfs(root: TreeNode | null): number {
  if (root === null) {
    return 0
  }

  const left = dfs(root.left)
  const right = dfs(root.right)

  // 根据左右子树结果，计算当前节点答案
  return Math.max(left, right) + 1
}
```

## 二、二叉树的中序遍历

**链接**：[94. 二叉树的中序遍历](https://leetcode.cn/problems/binary-tree-inorder-traversal/)

**难度：** Easy

### 1. 核心思路

中序遍历顺序是：**左子树 → 当前节点 → 右子树**。只要严格按这个顺序写递归即可。

### 2. 复杂度

| 维度           | 复杂度             |
| -------------- | ------------------ |
| **时间复杂度** | `O(n)`             |
| **空间复杂度** | `O(h)`，递归栈高度 |

### 3. 参考实现

```typescript
function inorderTraversal(root: TreeNode | null): number[] {
  const result: number[] = []

  function dfs(node: TreeNode | null): void {
    if (node === null) {
      return
    }

    dfs(node.left)
    result.push(node.val)
    dfs(node.right)
  }

  dfs(root)
  return result
}
```

## 三、二叉树的最大深度

**链接**：[104. 二叉树的最大深度](https://leetcode.cn/problems/maximum-depth-of-binary-tree/)

**难度：** Easy

### 1. 核心思路

以当前节点为根的树的最大深度，等于左右子树最大深度中的较大值再加一。

$$
depth(root) = \max(depth(root.left), depth(root.right)) + 1
$$

### 2. 参考实现

```typescript
function maxDepth(root: TreeNode | null): number {
  if (root === null) {
    return 0
  }

  return Math.max(maxDepth(root.left), maxDepth(root.right)) + 1
}
```

## 四、翻转二叉树

**链接**：[226. 翻转二叉树](https://leetcode.cn/problems/invert-binary-tree/)

**难度：** Easy

### 1. 核心思路

每个节点要做的事都一样：交换左右孩子，然后递归处理左右子树。

### 2. 参考实现

```typescript
function invertTree(root: TreeNode | null): TreeNode | null {
  if (root === null) {
    return null
  }

  ;[root.left, root.right] = [root.right, root.left]
  invertTree(root.left)
  invertTree(root.right)

  return root
}
```

## 五、对称二叉树

**链接**：[101. 对称二叉树](https://leetcode.cn/problems/symmetric-tree/)

**难度：** Easy

### 1. 核心思路

判断一棵树是否对称，本质是判断左子树和右子树是否互为镜像：

- 两个节点值相等。
- 左节点的左子树对应右节点的右子树。
- 左节点的右子树对应右节点的左子树。

### 2. 参考实现

```typescript
function isSymmetric(root: TreeNode | null): boolean {
  return root === null ? true : isMirror(root.left, root.right)
}

function isMirror(left: TreeNode | null, right: TreeNode | null): boolean {
  if (left === null && right === null) {
    return true
  }
  if (left === null || right === null) {
    return false
  }

  return (
    left.val === right.val &&
    isMirror(left.left, right.right) &&
    isMirror(left.right, right.left)
  )
}
```

## 六、二叉树的直径

**链接**：[543. 二叉树的直径](https://leetcode.cn/problems/diameter-of-binary-tree/)

**难度：** Easy

### 1. 核心思路

树的直径可能经过某个节点，此时路径长度就是：

$$
leftDepth + rightDepth
$$

因此递归每个节点时：

- 返回以该节点为根的最大深度。
- 顺便用 `leftDepth + rightDepth` 更新全局最大直径。

### 2. 复杂度

| 维度           | 复杂度 |
| -------------- | ------ |
| **时间复杂度** | `O(n)` |
| **空间复杂度** | `O(h)` |

### 3. 参考实现

```typescript
function diameterOfBinaryTree(root: TreeNode | null): number {
  let diameter = 0

  function dfs(node: TreeNode | null): number {
    if (node === null) {
      return 0
    }

    const leftDepth = dfs(node.left)
    const rightDepth = dfs(node.right)
    diameter = Math.max(diameter, leftDepth + rightDepth)

    return Math.max(leftDepth, rightDepth) + 1
  }

  dfs(root)
  return diameter
}
```

## 七、将有序数组转换为二叉搜索树

**链接**：[108. 将有序数组转换为二叉搜索树](https://leetcode.cn/problems/convert-sorted-array-to-binary-search-tree/)

**难度：** Easy

### 1. 核心思路

要构造高度平衡 BST，根节点最好选中间元素：

- 中间元素左边天然小于它，可递归构造左子树。
- 中间元素右边天然大于它，可递归构造右子树。

### 2. 参考实现

```typescript
function sortedArrayToBST(nums: number[]): TreeNode | null {
  function build(left: number, right: number): TreeNode | null {
    if (left > right) {
      return null
    }

    const mid = left + ((right - left) >> 1)

    return new TreeNode(nums[mid], build(left, mid - 1), build(mid + 1, right))
  }

  return build(0, nums.length - 1)
}
```

### 3. 易错点

| 易错点                  | 说明                                               |
| ----------------------- | -------------------------------------------------- |
| **直接用 `slice` 递归** | 能做，但会额外创建数组，空间更大                   |
| **中点选择不统一**      | 偶数长度时选左中位或右中位都可以，只要递归规则一致 |

## 八、二叉树的层序遍历

**链接**：[102. 二叉树的层序遍历](https://leetcode.cn/problems/binary-tree-level-order-traversal/)

**难度：** Medium

### 1. 核心思路

层序遍历最直观的做法是 BFS，但用 DFS 记录层数也能完成：

- `depth` 表示当前节点所在层。
- 遍历到节点时，把它放进 `result[depth]`。

这种写法很适合顺便扩展出“锯齿层序遍历”等变种。

### 2. 参考实现

```typescript
function levelOrder(root: TreeNode | null): number[][] {
  const result: number[][] = []

  function dfs(node: TreeNode | null, depth: number): void {
    if (node === null) {
      return
    }

    if (!result[depth]) {
      result[depth] = []
    }

    result[depth].push(node.val)
    dfs(node.left, depth + 1)
    dfs(node.right, depth + 1)
  }

  dfs(root, 0)
  return result
}
```
