# 多维动态规划

## 一、题型认知

**多维动态规划** 常见于网格、区间、字符串匹配等题型。和一维 DP 的区别在于：状态需要用二维及以上坐标来描述。

网格类题通常都有一个非常稳定的套路：

| 步骤         | 说明                                    |
| ------------ | --------------------------------------- |
| **状态定义** | `dp[i][j]` 表示走到坐标 `(i, j)` 的答案 |
| **来源方向** | 通常从上方或左方转移而来                |
| **初始化**   | 第一行、第一列往往要单独处理            |

---

## 二、不同路径

**链接**：[62. 不同路径](https://leetcode.cn/problems/unique-paths/)

**难度：** Medium

### 1. 题目描述

机器人位于 `m x n` 网格左上角，每次只能向右或向下移动一步，问到达右下角共有多少条不同路径。

### 2. 核心思路

定义 `dp[i][j]` 为走到 `(i, j)` 的路径数。

因为只能从上边或左边过来，所以：

$$
dp[i][j] = dp[i - 1][j] + dp[i][j - 1]
$$

第一行和第一列只有一种走法，因此都初始化为 `1`。

### 3. 复杂度

| 维度           | 复杂度  |
| -------------- | ------- |
| **时间复杂度** | `O(mn)` |
| **空间复杂度** | `O(mn)` |

### 4. 参考实现

```typescript
function uniquePaths(m: number, n: number): number {
  const dp = Array.from({ length: m }, () => new Array(n).fill(1))

  for (let i = 1; i < m; i++) {
    for (let j = 1; j < n; j++) {
      dp[i][j] = dp[i - 1][j] + dp[i][j - 1]
    }
  }

  return dp[m - 1][n - 1]
}
```

### 5. 易错点

| 易错点                      | 说明                         |
| --------------------------- | ---------------------------- |
| **把递归直接拿来用**        | 会有大量重复子问题，容易超时 |
| **忘记初始化第一行/第一列** | 它们是整个状态转移的基础     |

## 三、最小路径和

**链接**：[64. 最小路径和](https://leetcode.cn/problems/minimum-path-sum/)

**难度：** Medium

### 1. 题目描述

给定一个非负整数网格，从左上角走到右下角，每次只能向右或向下，求路径和最小值。

### 2. 核心思路

同样定义 `dp[i][j]` 为走到 `(i, j)` 的最小路径和。

与“不同路径”的区别在于，这里不是路径数相加，而是选更小的那条路：

$$
dp[i][j] = grid[i][j] + \min(dp[i - 1][j], dp[i][j - 1])
$$

### 3. 复杂度

| 维度           | 复杂度  |
| -------------- | ------- |
| **时间复杂度** | `O(mn)` |
| **空间复杂度** | `O(mn)` |

### 4. 参考实现

```typescript
function minPathSum(grid: number[][]): number {
  const row = grid.length
  const col = grid[0].length
  const dp = Array.from({ length: row }, () => new Array<number>(col).fill(0))

  for (let i = 0; i < row; i++) {
    for (let j = 0; j < col; j++) {
      if (i === 0 && j === 0) {
        dp[i][j] = grid[i][j]
      } else if (i === 0) {
        dp[i][j] = dp[i][j - 1] + grid[i][j]
      } else if (j === 0) {
        dp[i][j] = dp[i - 1][j] + grid[i][j]
      } else {
        dp[i][j] = Math.min(dp[i - 1][j], dp[i][j - 1]) + grid[i][j]
      }
    }
  }

  return dp[row - 1][col - 1]
}
```

### 5. 面试表达点

- 网格题优先想“当前位置能从哪里来”。
- 一旦状态和转移写对，代码实现通常就是套模板。
