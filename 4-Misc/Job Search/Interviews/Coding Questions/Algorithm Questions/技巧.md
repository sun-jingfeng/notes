# 技巧

## 一、题型认知

这个文件记录的是面试里常见的 **“小技巧型高频题”**。它们不一定属于复杂专题，但往往考查你能否快速识别隐藏规律。

| 技巧类型     | 代表思路               |
| ------------ | ---------------------- |
| **位运算**   | 用异或消掉成对元素     |
| **投票法**   | 用“抵消”思想找多数元素 |
| **数学规律** | 观察不变量或配对关系   |

面试表达时，重点不是把代码背出来，而是说清楚 **为什么这个规律成立**。

## 二、只出现一次的数字

**链接**：[136. 只出现一次的数字](https://leetcode.cn/problems/single-number/)

**难度：** Easy

### 1. 题目描述

给定一个非空整数数组，除了某个元素只出现一次外，其余元素都出现两次，找出只出现一次的那个元素。

### 2. 核心思路

这题的关键是异或的两个性质：

| 性质            | 说明                 |
| --------------- | -------------------- |
| **`a ^ a = 0`** | 相同的数异或会抵消   |
| **`a ^ 0 = a`** | 最后剩下的就是目标值 |

因此把所有元素从头到尾异或一遍，成对元素会全部抵消，最终只剩那个只出现一次的数。

### 3. 复杂度

| 维度           | 复杂度 |
| -------------- | ------ |
| **时间复杂度** | `O(n)` |
| **空间复杂度** | `O(1)` |

### 4. 参考实现

```typescript
function singleNumber(nums: number[]): number {
  let answer = 0

  for (const num of nums) {
    answer ^= num
  }

  return answer
}
```

### 5. 面试表达点

- 这题不是哈希计数题，重点在于看到“其余元素都出现两次”。
- 一旦题目要求 `O(1)` 额外空间，就应该优先想到位运算。

## 三、多数元素

**链接**：[169. 多数元素](https://leetcode.cn/problems/majority-element/)

**难度：** Easy

### 1. 题目描述

给定一个大小为 `n` 的数组，找到其中出现次数大于 `⌊n / 2⌋` 的元素。

### 2. 核心思路

最适合面试表达的是 **Boyer-Moore 投票算法**。

它的直觉是：

- 如果当前数和候选人相同，票数加一。
- 如果不同，票数减一，表示两个不同元素相互抵消。
- 因为多数元素的数量严格大于一半，所以最后一定能“活到最后”。

### 3. 复杂度

| 维度           | 复杂度 |
| -------------- | ------ |
| **时间复杂度** | `O(n)` |
| **空间复杂度** | `O(1)` |

### 4. 参考实现

```typescript
function majorityElement(nums: number[]): number {
  let candidate = 0
  let count = 0

  for (const num of nums) {
    if (count === 0) {
      candidate = num
    }

    count += num === candidate ? 1 : -1
  }

  return candidate
}
```

### 5. 易错点

| 易错点                 | 说明                                               |
| ---------------------- | -------------------------------------------------- |
| **只会哈希做法**       | 哈希能做，但投票法更符合这题的面试价值             |
| **没说清楚为什么成立** | 关键就在于“多数元素数量超过一半”，抵消后仍然会剩下 |
| **误以为必须二次验证** | 这道题已明确保证多数元素一定存在，因此可直接返回   |
