# 排序

## 一、题型认知

**排序** 是面试基础题，重点不只是会写代码，更要能说清楚各算法的时间复杂度、空间复杂度以及稳定性。

| 算法         | 平均时间复杂度 | 空间复杂度 | 特点                     |
| ------------ | -------------- | ---------- | ------------------------ |
| **冒泡排序** | `O(n^2)`       | `O(1)`     | 思路直观，适合讲交换过程 |
| **快速排序** | `O(n log n)`   | `O(log n)` | 高频，体现分治思想       |

面试里如果被要求“手写一个排序”，快速排序和归并排序优先级通常更高；冒泡排序更适合用来说明基础排序思想。

---

## 二、冒泡排序

### 1. 一句话理解

**冒泡排序** 通过反复比较相邻元素，把当前轮次中的最大值逐步交换到数组末尾。

### 2. 核心思路

- 第 1 轮把最大的元素放到最后。
- 第 2 轮把剩余元素里最大的放到倒数第二位。
- 每完成一轮，末尾就多一个已排序元素。

### 3. 复杂度

| 维度           | 复杂度   |
| -------------- | -------- |
| **时间复杂度** | `O(n^2)` |
| **空间复杂度** | `O(1)`   |

### 4. 参考实现

```typescript
function bubbleSort(nums: number[]): number[] {
  for (let i = 0; i < nums.length - 1; i++) {
    let swapped = false

    for (let j = 0; j < nums.length - 1 - i; j++) {
      if (nums[j] > nums[j + 1]) {
        ;[nums[j], nums[j + 1]] = [nums[j + 1], nums[j]]
        swapped = true
      }
    }

    if (!swapped) {
      break
    }
  }

  return nums
}
```

### 5. 面试表达点

- 如果一轮下来没有发生交换，说明数组已经有序，可以提前结束。
- 这是一个 **稳定排序**，因为相等元素不会被强制交换相对顺序。

## 三、快速排序

### 1. 一句话理解

**快速排序** 通过选定一个基准值，把数组划分成“左边都不大于它、右边都不小于它”的两部分，再递归处理左右子区间。

### 2. 核心思路

快速排序的核心是 **分区（partition）**：

- 选一个基准值 `pivot`。
- 用双指针从两端向中间靠拢。
- 找到左边不该在左边的值、右边不该在右边的值，然后交换。
- 最后把 `pivot` 放到正确位置。

当分区完成后，`pivot` 左边都不大于它，右边都不小于它，问题就被拆成两个更小的同类问题。

### 3. 复杂度

| 维度               | 复杂度             |
| ------------------ | ------------------ |
| **平均时间复杂度** | `O(n log n)`       |
| **最坏时间复杂度** | `O(n^2)`           |
| **空间复杂度**     | `O(log n)`，递归栈 |

### 4. 参考实现

```typescript
function quickSort(
  nums: number[],
  left = 0,
  right = nums.length - 1,
): number[] {
  if (left >= right) {
    return nums
  }

  const pivotIndex = partition(nums, left, right)
  quickSort(nums, left, pivotIndex - 1)
  quickSort(nums, pivotIndex + 1, right)

  return nums
}

function partition(nums: number[], left: number, right: number): number {
  const pivot = nums[left]
  let i = left
  let j = right

  while (i < j) {
    while (i < j && nums[j] >= pivot) {
      j--
    }
    while (i < j && nums[i] <= pivot) {
      i++
    }

    if (i < j) {
      ;[nums[i], nums[j]] = [nums[j], nums[i]]
    }
  }

  ;[nums[left], nums[i]] = [nums[i], nums[left]]
  return i
}
```

### 5. 易错点

| 易错点                 | 说明                                             |
| ---------------------- | ------------------------------------------------ |
| **边界条件没写好**     | `left >= right` 时必须终止递归                   |
| **指针移动顺序混乱**   | 这类写法里通常先移动右指针，再移动左指针，更稳定 |
| **忘记把基准值放回去** | 分区结束后要交换 `nums[left]` 和 `nums[i]`       |
