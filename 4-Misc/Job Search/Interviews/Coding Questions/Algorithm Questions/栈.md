# 栈

## 一、题型认知

**栈** 的特点是 **后进先出（LIFO）**，特别适合处理“最近一个尚未匹配的元素”。

| 常见场景       | 为什么适合用栈                            |
| -------------- | ----------------------------------------- |
| **括号匹配**   | 右括号要匹配最近的左括号                  |
| **单调栈**     | 维护一组单调元素，方便找“下一个更大/更小” |
| **表达式处理** | 需要回看最近状态                          |

## 二、有效的括号

**链接**：[20. 有效的括号](https://leetcode.cn/problems/valid-parentheses/)

**难度：** Easy

### 1. 题目描述

给定只包含 `(`、`)`、`{`、`}`、`[`、`]` 的字符串 `s`，判断它是否是有效括号串。

### 2. 核心思路

遇到左括号就入栈，遇到右括号就检查它能否和栈顶左括号配对：

- 能配对，说明最近一个未匹配左括号被成功闭合，弹栈。
- 不能配对，说明顺序或类型不正确，直接返回 `false`。

最后如果栈为空，说明所有括号都匹配成功。

### 3. 复杂度

| 维度           | 复杂度 |
| -------------- | ------ |
| **时间复杂度** | `O(n)` |
| **空间复杂度** | `O(n)` |

### 4. 参考实现

```typescript
function isValid(s: string): boolean {
  const pairMap = new Map<string, string>([
    [")", "("],
    ["]", "["],
    ["}", "{"],
  ])
  const stack: string[] = []

  for (const char of s) {
    if (!pairMap.has(char)) {
      stack.push(char)
      continue
    }

    if (stack.pop() !== pairMap.get(char)) {
      return false
    }
  }

  return stack.length === 0
}
```

### 5. 易错点

| 易错点                     | 说明                       |
| -------------------------- | -------------------------- |
| **只判断数量，不判断顺序** | `([)]` 数量对，但顺序错    |
| **栈空时直接 `pop`**       | 要考虑右括号提前出现的情况 |
| **最后忘记检查栈是否为空** | 左括号没匹配完同样不合法   |

## 三、每日温度

**链接**：[739. 每日温度](https://leetcode.cn/problems/daily-temperatures/)

**难度：** Medium

### 1. 题目描述

给定数组 `temperatures`，返回每一天距离下一个更高温度还需要等待多少天；如果之后不会升高，则记为 `0`。

### 2. 核心思路

这题是典型的 **单调栈**。

栈里存放“还没有找到下一个更高温度”的下标，并保持这些下标对应的温度 **从栈底到栈顶递减**：

- 如果当前温度比栈顶下标对应的温度高，说明当前天就是栈顶那一天的答案。
- 持续弹栈，直到栈为空或者栈顶温度不小于当前温度。
- 然后把当前下标入栈，等待未来来解决。

### 3. 复杂度

| 维度           | 复杂度 |
| -------------- | ------ |
| **时间复杂度** | `O(n)` |
| **空间复杂度** | `O(n)` |

### 4. 参考实现

```typescript
function dailyTemperatures(temperatures: number[]): number[] {
  const answer = new Array(temperatures.length).fill(0)
  const stack: number[] = []

  for (let i = 0; i < temperatures.length; i++) {
    while (
      stack.length &&
      temperatures[i] > temperatures[stack[stack.length - 1]]
    ) {
      const prevIndex = stack.pop() as number
      answer[prevIndex] = i - prevIndex
    }

    stack.push(i)
  }

  return answer
}
```

### 5. 面试表达点

- 栈里存的是 **下标**，不是温度值，因为最后要计算“等几天”。
- 每个下标最多进栈一次、出栈一次，所以整体复杂度仍然是 `O(n)`。
