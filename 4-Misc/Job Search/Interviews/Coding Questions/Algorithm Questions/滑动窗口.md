# 滑动窗口

## 一、题型认知

**滑动窗口** 适合处理“连续区间”问题。它的核心不是暴力枚举每个区间，而是维护一个动态窗口 `[left, right]`。

| 识别信号                             | 说明                     |
| ------------------------------------ | ------------------------ |
| **连续子串 / 子数组**                | 窗口天然对应连续区间     |
| **求最长 / 最短 / 个数**             | 很多题都能用窗口维护约束 |
| **随着右指针推进，左指针按条件收缩** | 典型窗口模式             |

当前题的窗口约束是：**窗口内不能出现重复字符**。

---

## 二、无重复字符的最长子串

**链接**：[3. 无重复字符的最长子串](https://leetcode.cn/problems/longest-substring-without-repeating-characters/)

**难度：** Medium

### 1. 题目描述

给定字符串 `s`，找出其中不含重复字符的最长子串长度。

### 2. 核心思路

让右指针不断向右扩张，把字符加入窗口；一旦发现重复字符，就持续移动左指针，直到窗口重新满足“无重复”的条件。

整个过程中：

- `Set` 用来判断当前字符是否已经在窗口里。
- `left` 负责收缩窗口。
- `right` 负责扩大窗口。
- 每次窗口合法时，用 `right - left + 1` 更新答案。

### 3. 复杂度

| 维度           | 复杂度                   |
| -------------- | ------------------------ |
| **时间复杂度** | `O(n)`                   |
| **空间复杂度** | `O(k)`，`k` 为字符集大小 |

### 4. 参考实现

```typescript
function lengthOfLongestSubstring(s: string): number {
  const window = new Set<string>()
  let answer = 0
  let left = 0

  for (let right = 0; right < s.length; right++) {
    while (window.has(s[right])) {
      window.delete(s[left])
      left++
    }

    window.add(s[right])
    answer = Math.max(answer, right - left + 1)
  }

  return answer
}
```

### 5. 易错点

| 易错点                             | 说明                                          |
| ---------------------------------- | --------------------------------------------- |
| **重复字符出现后只移动一次左指针** | 可能窗口里仍然有重复，必须用 `while` 持续收缩 |
| **把子串和子序列混淆**             | 子串必须连续，所以适合窗口                    |
| **答案更新时机不对**               | 要在窗口合法之后再更新最大值                  |
