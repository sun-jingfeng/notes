# 矩阵

## 一、题型认知

矩阵题常见两类思路：

| 类型           | 核心关注点                   |
| -------------- | ---------------------------- |
| **状态标记类** | 行列是否要处理、访问是否重复 |
| **边界模拟类** | 上下左右边界如何收缩         |

面试里矩阵题最容易丢分的地方，不是想不到思路，而是 **边界条件和遍历顺序写乱**。

## 二、矩阵置零

**链接**：[73. 矩阵置零](https://leetcode.cn/problems/set-matrix-zeroes/)

**难度：** Medium

### 1. 题目描述

给定矩阵，如果某元素为 `0`，则将它所在行和列全部置为 `0`，要求原地修改。

### 2. 核心思路

如果边遍历边置零，会污染后续判断，所以必须分两步：

- 第一轮先记录哪些行、哪些列需要清零。
- 第二轮根据记录统一改值。

这是典型的“**先标记，再处理**”的矩阵题。

### 3. 复杂度

| 维度           | 复杂度     |
| -------------- | ---------- |
| **时间复杂度** | `O(mn)`    |
| **空间复杂度** | `O(m + n)` |

### 4. 参考实现

```typescript
function setZeroes(matrix: number[][]): void {
  const rowCount = matrix.length
  const colCount = matrix[0].length
  const zeroRows = new Array(rowCount).fill(false)
  const zeroCols = new Array(colCount).fill(false)

  for (let i = 0; i < rowCount; i++) {
    for (let j = 0; j < colCount; j++) {
      if (matrix[i][j] === 0) {
        zeroRows[i] = true
        zeroCols[j] = true
      }
    }
  }

  for (let i = 0; i < rowCount; i++) {
    for (let j = 0; j < colCount; j++) {
      if (zeroRows[i] || zeroCols[j]) {
        matrix[i][j] = 0
      }
    }
  }
}
```

### 5. 易错点

| 易错点               | 说明                           |
| -------------------- | ------------------------------ |
| **一边扫描一边改值** | 会把后续本来不该置零的位置误伤 |
| **忘了列也要记录**   | 只记行不记列，答案不完整       |

## 三、螺旋矩阵

**链接**：[54. 螺旋矩阵](https://leetcode.cn/problems/spiral-matrix/)

**难度：** Medium

### 1. 题目描述

给定一个矩阵，按螺旋顺序返回其中所有元素。

### 2. 核心思路

用四个边界来描述当前还没遍历的矩形区域：

- `top`：上边界
- `bottom`：下边界
- `left`：左边界
- `right`：右边界

每轮按“上、右、下、左”四个方向依次遍历，然后收缩边界。边界交错时要及时停止，避免重复访问。

### 3. 复杂度

| 维度           | 复杂度               |
| -------------- | -------------------- |
| **时间复杂度** | `O(mn)`              |
| **空间复杂度** | `O(1)`，不算结果数组 |

### 4. 参考实现

```typescript
function spiralOrder(matrix: number[][]): number[] {
  if (matrix.length === 0 || matrix[0].length === 0) {
    return []
  }

  const answer: number[] = []
  let top = 0
  let bottom = matrix.length - 1
  let left = 0
  let right = matrix[0].length - 1

  while (top <= bottom && left <= right) {
    for (let col = left; col <= right; col++) {
      answer.push(matrix[top][col])
    }
    top++

    for (let row = top; row <= bottom; row++) {
      answer.push(matrix[row][right])
    }
    right--

    if (top <= bottom) {
      for (let col = right; col >= left; col--) {
        answer.push(matrix[bottom][col])
      }
      bottom--
    }

    if (left <= right) {
      for (let row = bottom; row >= top; row--) {
        answer.push(matrix[row][left])
      }
      left++
    }
  }

  return answer
}
```

### 5. 易错点

| 易错点                 | 说明                     |
| ---------------------- | ------------------------ |
| **边界收缩后忘记判断** | 单行或单列时容易重复遍历 |
| **遍历顺序写乱**       | 建议始终固定为“上右下左” |
