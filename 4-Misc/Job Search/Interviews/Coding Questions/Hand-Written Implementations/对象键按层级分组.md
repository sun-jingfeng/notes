# 对象键按层级分组

## 一、题目

给定一个层级嵌套的对象，实现 `getKeysByLevel(obj)`，将对象中所有的键按照所在深度分组，返回一个二维数组。

- 第一层的所有键放在第一个子数组
- 第二层的所有键放在第二个子数组
- 以此类推，深度相同的键放在同一个子数组中
- 同一子数组内，键的顺序与对象中的定义顺序一致
- 值为非对象（数字、字符串等）的属性，只记录其键名，不继续向下遍历

```js
const obj = {
    a: {
        b: {
            c: 1
        },
        d: 2
    },
    e: 3
};

getKeysByLevel(obj);
// 输出：[['a', 'e'], ['b', 'd'], ['c']]
```

---

## 二、解法

### 1. DFS（递归）

向下递归时将当前深度作为参数传递，按深度索引存入结果数组。

```js
function getKeysByLevel(obj) {
    const result = [];

    function traverse(o, depth) {
        if (!o || typeof o !== 'object') return;
        if (!result[depth]) result[depth] = [];

        for (const key of Object.keys(o)) {
            result[depth].push(key);
            traverse(o[key], depth + 1);  // 递归处理子对象，深度 +1
        }
    }

    traverse(obj, 0);
    return result;
}
```

### 2. BFS（队列，推荐）

用队列逐层遍历，天然按层分组，无需手动传递深度。

```js
function getKeysByLevel(obj) {
    const result = [];
    let queue = [obj];   // 当前层的所有节点

    while (queue.length) {
        const nextQueue = [];  // 下一层的所有节点
        const levelKeys = [];  // 当前层的所有键

        for (const node of queue) {
            for (const key of Object.keys(node)) {
                levelKeys.push(key);
                if (node[key] && typeof node[key] === 'object') {
                    nextQueue.push(node[key]);  // 子对象入队，留待下一层处理
                }
            }
        }

        result.push(levelKeys);
        queue = nextQueue;
    }

    return result;
}
```

| 解法 | 思路 | 适合场景 |
| ---- | ---- | -------- |
| **DFS** | 递归深入，用 `depth` 参数定位当前层 | 树较深、层数多 |
| **BFS** | 队列逐层推进，天然按层分组 | 逻辑更直观，代码更清晰 |

---

## 三、面试表达点

- DFS 方案的关键是把 `depth` 作为递归参数传递，而不是用全局变量记录。
- BFS 方案每轮 `while` 循环对应一层，`queue` 存当前层节点，`nextQueue` 收集下一层，循环结束时切换。
- 面试官追问「如果值也可能是数组怎么办」：`Array.isArray(node[key])` 同样作为 object 处理，直接入队即可，`Object.keys` 会返回数组的数字索引作为键。
