# JavaScript 闭包

**一句话回答：** 闭包是“函数 + 它定义时所在的词法作用域”，内部函数在外部执行时仍能访问外层变量。

***

## 一、闭包是什么

闭包本质上不是某种特殊语法，而是 **作用域链被保留下来** 的结果。只要函数在定义作用域之外继续被引用，并且访问了外层变量，就形成了闭包。

```js
function createCounter() {
  let count = 0
  return function () {
    count += 1
    return count
  }
}
```

上面返回的内部函数每次执行都能继续访问 `count`，因为该变量并没有随着外层函数执行结束而立即释放。

***

## 二、常见应用场景

| 场景 | 说明 |
| --- | --- |
| **数据封装** | 模拟私有变量，对外只暴露方法，不直接暴露状态 |
| **函数工厂 / 柯里化** | 预先保存一部分参数，返回新函数 |
| **防抖 / 节流** | 通过闭包保存 `timer` 或上次触发时间 |
| **事件处理** | 让事件回调记住当前上下文与状态 |
| **模块模式** | 用 IIFE 或工厂函数隔离内部实现 |

***

## 三、为什么闭包会带来内存问题

闭包本身不是内存泄漏，但它会 **延长外层变量的生命周期**。如果闭包长期存在，又引用了大对象、DOM 节点或定时器上下文，就可能导致额外内存占用。

| 风险点 | 典型场景 | 优化方式 |
| --- | --- | --- |
| **大对象被长期引用** | 回调里抓住超大数组、缓存对象 | 只保留必要字段，不闭包整个对象 |
| **事件监听未清理** | 页面卸载后监听仍存在 | `removeEventListener` |
| **定时器未释放** | `setInterval` 一直存活 | `clearInterval` / 置空引用 |
| **循环变量使用不当** | `var` + 异步回调共用同一变量 | 使用 `let` 或额外包一层作用域 |

***

## 四、面试答题要点

1. **定义：** 闭包是函数与其词法作用域的组合。
2. **形成条件：** 内部函数被外部持有，并访问外层变量。
3. **价值：** 封装状态、实现高阶函数、支持回调和模块化。
4. **风险：** 会让外层变量活得更久，要注意监听器、定时器和大对象引用。

***

## 五、面试答题模板

可以直接答：**闭包就是函数在外部执行时，仍然能访问它定义时所在作用域里的变量。它的价值是封装私有状态、实现函数工厂和防抖节流，但因为会延长变量生命周期，所以要注意不要把大对象、DOM 或定时器上下文长期挂在闭包里。**
