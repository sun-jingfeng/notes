# 常见的 Vite 配置

**一句话回答：** 面试里讲 Vite 配置，不要背所有字段，重点说开发代理、路径别名、环境变量、构建优化和插件体系这几类高频能力。

***

## 一、最常用的配置项

| 配置项 | 作用 | 常见场景 |
| --- | --- | --- |
| **`server.proxy`** | 开发代理 | 解决本地调试跨域 |
| **`resolve.alias`** | 路径别名 | 简化 import 路径 |
| **`define`** | 注入全局常量 | 注入版本号、构建时间 |
| **`css.preprocessorOptions`** | 预处理器配置 | 全局注入变量、mixin |
| **`build`** | 构建行为控制 | 压缩、分包、产物目录 |
| **`plugins`** | 插件扩展 | Vue/React、自动导入、压缩分析 |

***

## 二、面试里最值得展开的几个点

### 1. 开发代理

开发阶段通常会通过 `server.proxy` 把前端请求转发到后端，解决本地跨域问题。它只影响开发环境，不等于生产环境 CORS 已经解决。

### 2. 环境变量

- Vite 使用 `.env`、`.env.production` 等文件。
- 只有 `VITE_` 前缀的变量才会暴露到客户端。
- 通过 `import.meta.env` 读取。

### 3. 构建优化

| 目标 | 常见做法 |
| --- | --- |
| **减小体积** | 代码分割、Tree Shaking、压缩、按需加载 |
| **优化缓存** | 文件名带 hash、静态资源分目录 |
| **分析产物** | `rollup-plugin-visualizer` |
| **兼容旧浏览器** | `@vitejs/plugin-legacy` |

***

## 三、一个简化的回答思路

如果面试官问“常见 Vite 配置有哪些”，可以按下面顺序答：

1. **开发体验类：** 代理和路径别名。
2. **环境区分类：** `mode`、`.env`、`import.meta.env`。
3. **构建优化类：** 分包、压缩、产物分析。
4. **插件扩展类：** 框架插件、自动导入、legacy 兼容。

***

## 四、面试答题模板

可以直接答：**Vite 常见配置我一般按四类记：一类是开发体验，比如代理和路径别名；二类是环境变量和模式区分；三类是构建优化，比如分包、压缩、产物分析；四类是插件体系，比如框架插件、自动导入和 legacy 兼容。真正项目里用得最多的还是代理、别名、环境变量和构建配置。**
