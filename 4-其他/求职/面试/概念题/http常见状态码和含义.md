# HTTP 常见状态码和含义

**一句话回答：** HTTP 状态码是服务端对请求处理结果的标准化反馈，面试里不只要记数字，还要能说出使用场景。

***

## 一、按类别理解状态码

| 类别 | 含义 | 典型状态码 |
| --- | --- | --- |
| **1xx** | 请求已收到，继续处理 | `100 Continue` |
| **2xx** | 请求成功 | `200`、`201`、`204`、`206` |
| **3xx** | 需要进一步动作，多为重定向或缓存协商 | `301`、`302`、`304` |
| **4xx** | 客户端请求有问题 | `400`、`401`、`403`、`404`、`409`、`429` |
| **5xx** | 服务端处理失败 | `500`、`502`、`503`、`504` |

***

## 二、面试高频状态码

| 状态码 | 含义 | 常见场景 |
| --- | --- | --- |
| **200 OK** | 请求成功 | 查询成功、接口正常返回 |
| **201 Created** | 资源创建成功 | 新增订单、创建用户 |
| **204 No Content** | 成功但无响应体 | 删除成功、不返回列表 |
| **206 Partial Content** | 返回部分内容 | 大文件断点续传、Range 请求 |
| **301 Moved Permanently** | 永久重定向 | 域名迁移、HTTP 跳 HTTPS |
| **302 Found** | 临时重定向 | 临时跳转、登录态跳转 |
| **304 Not Modified** | 资源未修改 | 协商缓存命中 |
| **400 Bad Request** | 请求格式错误 | 参数缺失、JSON 非法 |
| **401 Unauthorized** | 未认证 | Token 缺失、登录过期 |
| **403 Forbidden** | 已认证但无权限 | 角色不足、资源拒绝访问 |
| **404 Not Found** | 资源不存在 | 路由错误、接口地址错误 |
| **409 Conflict** | 资源冲突 | 版本冲突、重复提交 |
| **429 Too Many Requests** | 请求过多 | 限流、风控拦截 |
| **500 Internal Server Error** | 服务端内部异常 | 空指针、未捕获异常 |
| **502 Bad Gateway** | 上游返回异常 | 网关、Nginx、反向代理问题 |
| **503 Service Unavailable** | 当前不可用 | 维护、降级、过载 |
| **504 Gateway Timeout** | 上游超时 | 网关等待服务超时 |

***

## 三、面试回答的加分点

1. **401 和 403 不要混。** `401` 是“没通过认证”，`403` 是“通过认证但不给你权限”。
2. **304 不是成功返回资源，而是告诉浏览器直接用本地缓存。**
3. **206 常用于断点续传和视频分片加载。**
4. **502 / 504 多出现在网关或代理链路，不一定是应用本身直接抛错。**

***

## 四、面试答题模板

可以直接答：**HTTP 状态码要按类记。2xx 表示成功，3xx 常见于重定向和缓存，4xx 是客户端问题，5xx 是服务端问题。高频里最容易混的是 401 和 403，前者是没认证，后者是没权限；304 是协商缓存命中，206 则常见于断点续传。**
