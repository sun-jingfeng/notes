# 柯里化、防抖、节流

## 一、核心认知

这三道题都属于高频前端手写题，但考查点不同：

| 题目       | 本质                                   |
| ---------- | -------------------------------------- |
| **柯里化** | 把“接收多个参数”的函数改造成可分步传参 |
| **防抖**   | 高频触发时只保留最后一次               |
| **节流**   | 高频触发时按固定频率执行               |

---

## 二、柯里化

### 1. 核心思路

柯里化的关键是：

- 不断收集参数。
- 当参数数量达到原函数形参个数时，真正执行原函数。
- 否则返回一个新函数继续收参。

### 2. 参考实现

```typescript
function curry<T extends (...args: any[]) => any>(fn: T) {
  function curried(this: unknown, ...args: unknown[]): unknown {
    if (args.length >= fn.length) {
      return fn.apply(this, args as Parameters<T>)
    }

    return function (this: unknown, ...rest: unknown[]) {
      return curried.apply(this, [...args, ...rest])
    }
  }

  return curried
}

const getSum = (a: number, b: number, c: number) => a + b + c
const curriedGetSum = curry(getSum)

console.log(curriedGetSum(1, 2, 3))
console.log(curriedGetSum(1)(2)(3))
console.log(curriedGetSum(1, 2)(3))
console.log(curriedGetSum(1)(2, 3))
```

### 3. 易错点

- 用一个共享数组收参数，容易导致多次调用之间互相污染。
- 忘记保留 `this`，在对象方法场景下会出问题。

## 三、防抖

### 1. 一句话定义

**防抖** 是指事件连续触发时，只在“停止触发一段时间后”执行最后一次。

### 2. 适用场景

- 输入框搜索建议
- 窗口尺寸变化后的重排计算
- 表单频繁校验

### 3. 参考实现

```typescript
function debounce<T extends (...args: any[]) => void>(fn: T, delay = 300) {
  let timer: ReturnType<typeof setTimeout> | null = null

  return function (this: ThisParameterType<T>, ...args: Parameters<T>) {
    if (timer !== null) {
      clearTimeout(timer)
    }

    timer = setTimeout(() => {
      fn.apply(this, args)
    }, delay)
  }
}
```

### 4. 面试表达点

- 防抖关注的是“最后一次”。
- 每次触发都重置计时器，是它和节流最本质的区别。

---

## 四、节流

### 1. 一句话定义

**节流** 是指在一段时间内无论事件触发多少次，都只按固定频率执行。

### 2. 适用场景

- 页面滚动监听
- 拖拽过程中的位置更新
- 高频鼠标移动事件

### 3. 参考实现

```typescript
function throttle<T extends (...args: any[]) => void>(fn: T, delay = 300) {
  let lastTime = 0
  let timer: ReturnType<typeof setTimeout> | null = null

  return function (this: ThisParameterType<T>, ...args: Parameters<T>) {
    const now = Date.now()
    const remaining = delay - (now - lastTime)

    if (remaining <= 0) {
      if (timer !== null) {
        clearTimeout(timer)
        timer = null
      }

      lastTime = now
      fn.apply(this, args)
      return
    }

    if (timer === null) {
      timer = setTimeout(() => {
        lastTime = Date.now()
        timer = null
        fn.apply(this, args)
      }, remaining)
    }
  }
}
```

### 4. 面试表达点

- 节流关注的是“执行频率”。
- 上面这版同时兼顾了首触发和尾触发，实用性比最简版更强。
