# 深拷贝

## 一、核心认知

**深拷贝** 的目标是：复制后的新对象和原对象彼此独立，修改一方不会影响另一方。

| 方式                               | 问题                                                       |
| ---------------------------------- | ---------------------------------------------------------- |
| **浅拷贝**                         | 只复制第一层，嵌套对象仍然共享引用                         |
| **`JSON.parse(JSON.stringify())`** | 会丢失 `Date`、`RegExp`、`undefined`、函数、循环引用等信息 |
| **手写深拷贝**                     | 可以按需求逐步补齐边界能力                                 |

---

## 二、简单版

### 1. 适用场景

简单版适合面试里先快速表达递归思路，但要明确说明它有边界：

- 不能处理循环引用
- 不能正确处理 `Date`、`RegExp`
- 不保留原型信息

### 2. 参考实现

```typescript
function deepClone<T>(value: T): T {
  if (typeof value !== "object" || value === null) {
    return value
  }

  const clone = (Array.isArray(value) ? [] : {}) as T

  for (const key in value) {
    if (Object.hasOwn(value, key)) {
      clone[key] = deepClone(value[key])
    }
  }

  return clone
}
```

## 三、进阶版

### 1. 补齐的问题

进阶版通常至少要补这几项：

- 循环引用
- `Date`
- `RegExp`
- `Map`
- `Set`
- Symbol 键
- 原型链保留

### 2. 参考实现

```typescript
function isObjectLike(value: unknown): value is object {
  return typeof value === "object" && value !== null
}

function deepCloneAdvanced<T>(
  value: T,
  cache = new WeakMap<object, unknown>(),
): T {
  if (!isObjectLike(value)) {
    return value
  }

  if (value instanceof Date) {
    return new Date(value.getTime()) as T
  }

  if (value instanceof RegExp) {
    return new RegExp(value.source, value.flags) as T
  }

  if (cache.has(value)) {
    return cache.get(value) as T
  }

  if (value instanceof Map) {
    const clonedMap = new Map()
    cache.set(value, clonedMap)

    value.forEach((mapValue, mapKey) => {
      clonedMap.set(
        deepCloneAdvanced(mapKey, cache),
        deepCloneAdvanced(mapValue, cache),
      )
    })

    return clonedMap as T
  }

  if (value instanceof Set) {
    const clonedSet = new Set()
    cache.set(value, clonedSet)

    value.forEach(item => {
      clonedSet.add(deepCloneAdvanced(item, cache))
    })

    return clonedSet as T
  }

  const clone = (
    Array.isArray(value) ? [] : Object.create(Object.getPrototypeOf(value))
  ) as Record<PropertyKey, unknown>

  cache.set(value, clone)

  for (const key of Reflect.ownKeys(value)) {
    clone[key] = deepCloneAdvanced(
      (value as Record<PropertyKey, unknown>)[key],
      cache,
    )
  }

  return clone as T
}
```

### 3. 面试表达点

- `WeakMap` 是为了解决循环引用。
- `Reflect.ownKeys` 可以拿到字符串键和 Symbol 键。
- 如果面试官继续追问，可以补充：函数通常直接复用引用，不做“克隆函数体”。
