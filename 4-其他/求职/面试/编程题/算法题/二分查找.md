# 二分查找

## 一、题型认知

**二分查找** 适用于“**有序数组中找目标值或边界**”这类问题，本质是在每一步都砍掉一半搜索空间。

| 识别信号           | 说明                                   |
| ------------------ | -------------------------------------- |
| **数组有序**       | 升序或降序都可以，只是比较方向不同     |
| **查找位置/边界**  | 找值、找插入点、找第一个满足条件的位置 |
| **可排除一半区间** | 根据中点和目标值的关系缩小范围         |

**闭区间写法模板：**

```typescript
function binarySearch(nums: number[], target: number): number {
  let left = 0
  let right = nums.length - 1

  while (left <= right) {
    const mid = left + ((right - left) >> 1)

    if (nums[mid] === target) {
      return mid
    }
    if (nums[mid] < target) {
      left = mid + 1
    } else {
      right = mid - 1
    }
  }

  return -1
}
```

## 二、搜索插入位置

**链接**：[35. 搜索插入位置](https://leetcode.cn/problems/search-insert-position/)

**难度：** Easy

### 1. 题目描述

给定一个排序数组和一个目标值，在数组中找到目标值，并返回其索引。如果目标值不存在于数组中，返回它按顺序应该插入的位置。

### 2. 核心思路

这个题不是单纯“找到就返回，找不到就返回 -1”，而是要找出 **第一个大于等于 `target` 的位置**。

做法是：

- 如果 `nums[mid] >= target`，答案一定在 `mid` 或其左边，先记录 `mid`。
- 如果 `nums[mid] < target`，说明答案只能在右边。
- 最后如果始终没找到更合适的位置，说明 `target` 比所有元素都大，插入点就是数组末尾。

### 3. 复杂度

| 维度           | 复杂度     |
| -------------- | ---------- |
| **时间复杂度** | `O(log n)` |
| **空间复杂度** | `O(1)`     |

### 4. 参考实现

```typescript
function searchInsert(nums: number[], target: number): number {
  let left = 0
  let right = nums.length - 1
  let answer = nums.length

  while (left <= right) {
    const mid = left + ((right - left) >> 1)

    if (nums[mid] >= target) {
      answer = mid
      right = mid - 1
    } else {
      left = mid + 1
    }
  }

  return answer
}
```

### 5. 易错点

| 易错点               | 说明                                                                      |
| -------------------- | ------------------------------------------------------------------------- |
| **区间更新错误**     | 闭区间写法里，左边界要用 `left = mid + 1`，右边界要用 `right = mid - 1`   |
| **没记录候选答案**   | 遇到 `nums[mid] >= target` 时，需要先保存 `mid`，否则最终可能丢失插入位置 |
| **把题目当普通查找** | 这题找的是“插入点”，不是单纯判断是否存在                                  |
