# 动态规划

## 一、题型认知

**动态规划（DP）** 的核心是：把原问题拆成若干个重叠子问题，并把子问题答案保存下来，避免重复计算。

写 DP 时优先想清楚 3 件事：

| 步骤         | 说明                           |
| ------------ | ------------------------------ |
| **状态定义** | `dp[i]` 或 `dp[i][j]` 表示什么 |
| **状态转移** | 当前答案如何由更小子问题推出来 |
| **初始条件** | 最小规模问题的答案是什么       |

## 二、爬楼梯

**链接**：[70. 爬楼梯](https://leetcode.cn/problems/climbing-stairs/)

**难度：** Easy

### 1. 题目描述

每次可以爬 `1` 或 `2` 个台阶，求到达第 `n` 阶有多少种不同方法。

### 2. 核心思路

到达第 `n` 阶的最后一步只有两种情况：

- 从 `n - 1` 阶走 `1` 步上来。
- 从 `n - 2` 阶走 `2` 步上来。

所以状态转移为：

$$
dp[n] = dp[n - 1] + dp[n - 2]
$$

这和斐波那契数列本质相同。

### 3. 复杂度

| 写法        | 时间复杂度 | 空间复杂度 |
| ----------- | ---------- | ---------- |
| **纯递归**  | `O(2^n)`   | `O(n)`     |
| **迭代 DP** | `O(n)`     | `O(1)`     |

### 4. 参考实现

```typescript
function climbStairs(n: number): number {
  if (n <= 1) {
    return 1
  }

  let prev2 = 1
  let prev1 = 1

  for (let i = 2; i <= n; i++) {
    const current = prev1 + prev2
    prev2 = prev1
    prev1 = current
  }

  return prev1
}
```

### 5. 面试表达点

- 如果只是为了说明问题，可以先讲递归，再说明为什么要优化成 DP。
- 这题空间可以进一步压缩，因为每次只依赖前两个状态。

## 三、杨辉三角

**链接**：[118. 杨辉三角](https://leetcode.cn/problems/pascals-triangle/)

**难度：** Easy

### 1. 题目描述

给定整数 `numRows`，返回杨辉三角的前 `numRows` 行。

### 2. 核心思路

杨辉三角每一行都可以由上一行推出：

- 每行首尾都是 `1`。
- 中间元素等于上一行左上和右上的两个数之和。

虽然这题不一定会被单独叫做“动态规划”，但它很适合作为 **状态由上一层推导当前层** 的入门题。

### 3. 复杂度

| 维度           | 复杂度         |
| -------------- | -------------- |
| **时间复杂度** | `O(numRows^2)` |
| **空间复杂度** | `O(numRows^2)` |

### 4. 参考实现

```typescript
function generate(numRows: number): number[][] {
  const answer: number[][] = []

  for (let i = 0; i < numRows; i++) {
    const row = new Array(i + 1).fill(1)

    for (let j = 1; j < i; j++) {
      row[j] = answer[i - 1][j - 1] + answer[i - 1][j]
    }

    answer.push(row)
  }

  return answer
}
```

### 5. 易错点

| 易错点               | 说明                           |
| -------------------- | ------------------------------ |
| **循环边界写错**     | 中间位置从 `1` 遍历到 `i - 1`  |
| **没区分首尾和中间** | 首尾固定为 `1`，不需要重复计算 |
