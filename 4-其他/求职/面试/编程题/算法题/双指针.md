# 双指针

## 一、题型认知

**双指针** 是用两个位置变量协同推进，在线性时间内解决数组或字符串问题的常见技巧。

| 常见类型     | 使用方式                           |
| ------------ | ---------------------------------- |
| **快慢指针** | 一个负责扫描，一个负责维护有效区间 |
| **左右指针** | 从两端向中间收缩，常见于有序数组   |
| **读写指针** | 一个读原数据，一个写结果位置       |

当前这题本质是 **快慢指针 + 原地覆盖/交换**。

## 二、移动零

**链接**：[283. 移动零](https://leetcode.cn/problems/move-zeroes/)

**难度：** Easy

### 1. 题目描述

给定一个数组 `nums`，将所有 `0` 移动到数组末尾，同时保持非零元素的相对顺序。要求原地操作。

### 2. 核心思路

让 `fast` 负责从左到右扫描数组，让 `slow` 指向下一个应该放非零元素的位置：

- 当 `nums[fast] !== 0` 时，说明遇到了一个有效元素。
- 把它交换到 `slow` 所在位置。
- 然后 `slow` 向后移动一位，表示前面的区间已经整理好。

这样可以保证：

- `slow` 左边始终都是处理好的非零元素。
- `fast` 负责不断把后面的非零元素搬到前面。

### 3. 复杂度

| 维度           | 复杂度 |
| -------------- | ------ |
| **时间复杂度** | `O(n)` |
| **空间复杂度** | `O(1)` |

### 4. 参考实现

```typescript
function moveZeroes(nums: number[]): void {
  let slow = 0

  for (let fast = 0; fast < nums.length; fast++) {
    if (nums[fast] !== 0) {
      ;[nums[slow], nums[fast]] = [nums[fast], nums[slow]]
      slow++
    }
  }
}
```

### 5. 易错点

| 易错点                             | 说明                                                  |
| ---------------------------------- | ----------------------------------------------------- |
| **误以为必须新开数组**             | 题目要求原地操作，双指针正好满足                      |
| **交换条件写成 `if (nums[fast])`** | 面试里最好显式写成 `nums[fast] !== 0`，表达更清晰     |
| **担心顺序被破坏**                 | `slow` 总是按扫描顺序接收非零元素，因此相对顺序不会变 |
