# 哈希

## 一、题型认知

**哈希表** 适合解决“**查找、去重、计数、用空间换时间**”的问题。

| 识别信号                       | 说明                     |
| ------------------------------ | ------------------------ |
| **需要快速判断某值是否出现过** | `Map` / `Set` 常见       |
| **查找配对值**                 | 例如 `target - nums[i]`  |
| **统计出现次数**               | 词频、字符计数、多数元素 |

面试里常见一句话：**看到“查找某个值是否已经出现过”，优先想到哈希表。**

## 二、两数之和

**链接**：[1. 两数之和](https://leetcode.cn/problems/two-sum/)

**难度：** Easy

### 1. 题目描述

给定整数数组 `nums` 和目标值 `target`，找出和为 `target` 的两个元素下标。

### 2. 核心思路

遍历到当前位置 `i` 时，如果已经知道前面某个数 `x` 的下标，那么只要当前值满足：

$$
x + nums[i] = target
$$

就可以直接得到答案。

因此遍历过程中：

- 先计算还差多少：`need = target - nums[i]`
- 去哈希表里查 `need` 是否已经出现
- 如果出现过，直接返回对应下标
- 如果没出现，就把当前值和下标存起来，供后面使用

### 3. 复杂度

| 维度           | 复杂度 |
| -------------- | ------ |
| **时间复杂度** | `O(n)` |
| **空间复杂度** | `O(n)` |

### 4. 参考实现

```typescript
function twoSum(nums: number[], target: number): [number, number] {
  const indexMap = new Map<number, number>()

  for (let i = 0; i < nums.length; i++) {
    const need = target - nums[i]

    if (indexMap.has(need)) {
      return [indexMap.get(need) as number, i]
    }

    indexMap.set(nums[i], i)
  }

  return [-1, -1]
}
```

### 5. 易错点

| 易错点               | 说明                                                 |
| -------------------- | ---------------------------------------------------- |
| **先存当前值再查找** | 这样在 `target = 2 * nums[i]` 时，可能错误匹配到自己 |
| **没想清楚返回什么** | 题目要的是下标，不是元素值                           |
| **忽略重复元素**     | 哈希表天然支持，只要顺序写对即可                     |
