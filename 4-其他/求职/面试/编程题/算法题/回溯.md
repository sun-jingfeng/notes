# 回溯

## 一、题型认知

**回溯** 本质上是“在决策树上做 DFS”。它特别适合求：

- 全部排列
- 全部组合
- 全部子集
- 满足条件的路径

回溯的标准模板：

```typescript
function backtrack(路径, 选择列表) {
  if (满足结束条件) {
    收集答案
    return
  }

  for (const 选择 of 选择列表) {
    做选择
    backtrack(新路径, 新选择列表)
    撤销选择
  }
}
```

| 关键动作     | 说明                     |
| ------------ | ------------------------ |
| **做选择**   | 把当前元素放进路径       |
| **递归深入** | 继续处理下一层           |
| **撤销选择** | 回到上一层，尝试其他分支 |

## 二、全排列

**链接**：[46. 全排列](https://leetcode.cn/problems/permutations/)

**难度：** Medium

### 1. 核心思路

全排列要求每个位置都从“还没用过的数字”里选一个，因此需要一个 `used` 数组标记哪些元素已经加入当前路径。

### 2. 复杂度

| 维度           | 复杂度               |
| -------------- | -------------------- |
| **时间复杂度** | `O(n * n!)`          |
| **空间复杂度** | `O(n)`，不算结果数组 |

### 3. 参考实现

```typescript
function permute(nums: number[]): number[][] {
  const result: number[][] = []
  const path: number[] = []
  const used = new Array(nums.length).fill(false)

  function backtrack(): void {
    if (path.length === nums.length) {
      result.push(path.slice())
      return
    }

    for (let i = 0; i < nums.length; i++) {
      if (used[i]) {
        continue
      }

      used[i] = true
      path.push(nums[i])
      backtrack()
      path.pop()
      used[i] = false
    }
  }

  backtrack()
  return result
}
```

## 三、子集

**链接**：[78. 子集](https://leetcode.cn/problems/subsets/)

**难度：** Medium

### 1. 核心思路

子集问题和全排列不同，不要求顺序。遍历到某个位置时，只有两种选择：

- 选它
- 不选它

因此可以通过“从当前位置开始往后选”来避免重复。

### 2. 参考实现

```typescript
function subsets(nums: number[]): number[][] {
  const result: number[][] = []
  const path: number[] = []

  function backtrack(start: number): void {
    result.push(path.slice())

    for (let i = start; i < nums.length; i++) {
      path.push(nums[i])
      backtrack(i + 1)
      path.pop()
    }
  }

  backtrack(0)
  return result
}
```

### 3. 面试表达点

- 子集题通常在每一层都可以收集答案。
- `start` 参数的作用是避免回头选已经处理过的位置，防止重复。

## 四、电话号码的字母组合

**链接**：[17. 电话号码的字母组合](https://leetcode.cn/problems/letter-combinations-of-a-phone-number/)

**难度：** Medium

### 1. 核心思路

每一位数字都对应一组选项，因此整道题就是一个多叉树搜索：

- 第 1 层选择第 1 个数字对应的字母。
- 第 2 层选择第 2 个数字对应的字母。
- 当路径长度等于数字串长度时，得到一个完整答案。

### 2. 参考实现

```typescript
const phoneMap: Record<string, string> = {
  "2": "abc",
  "3": "def",
  "4": "ghi",
  "5": "jkl",
  "6": "mno",
  "7": "pqrs",
  "8": "tuv",
  "9": "wxyz",
}

function letterCombinations(digits: string): string[] {
  if (digits.length === 0) {
    return []
  }

  const result: string[] = []
  const path: string[] = []

  function backtrack(index: number): void {
    if (index === digits.length) {
      result.push(path.join(""))
      return
    }

    for (const char of phoneMap[digits[index]]) {
      path.push(char)
      backtrack(index + 1)
      path.pop()
    }
  }

  backtrack(0)
  return result
}
```

### 3. 易错点

| 易错点                         | 说明                             |
| ------------------------------ | -------------------------------- |
| **空字符串不特殊处理**         | 应直接返回空数组                 |
| **用 `includes` 判断是否已用** | 这题不是排列，不需要去重使用标记 |

## 五、组合总和

**链接**：[39. 组合总和](https://leetcode.cn/problems/combination-sum/)

**难度：** Medium

### 1. 核心思路

这题既要找组合，又允许同一个数字重复使用，因此递归时：

- 下层仍然可以从当前下标 `i` 开始，而不是 `i + 1`。
- 只要当前和超过 `target`，就可以立即剪枝。

### 2. 复杂度

回溯题的精确复杂度通常和答案规模相关，面试里说明“指数级搜索，依赖剪枝效果”即可。

### 3. 参考实现

```typescript
function combinationSum(candidates: number[], target: number): number[][] {
  const result: number[][] = []
  const path: number[] = []

  function backtrack(start: number, sum: number): void {
    if (sum === target) {
      result.push(path.slice())
      return
    }

    for (let i = start; i < candidates.length; i++) {
      const current = candidates[i]

      if (sum + current > target) {
        continue
      }

      path.push(current)
      backtrack(i, sum + current)
      path.pop()
    }
  }

  backtrack(0, 0)
  return result
}
```

### 4. 面试表达点

- “组合”意味着顺序不重要，所以要用 `start` 控制搜索范围。
- “可以重复使用”意味着下层递归仍从当前下标开始。
