# 子串

## 一、题型认知

当前文件名叫“子串”，但这道题本质上是 **连续子数组 + 前缀和 + 哈希表**。

**前缀和** 的核心作用是把“区间和”转成两个前缀值之差：

$$
sum(i, j) = prefix[j] - prefix[i - 1]
$$

如果在遍历到当前位置时，之前存在某个前缀和 `prefix - k`，就说明从那个位置之后到当前位置这一段的和正好等于 `k`。

| 识别信号                         | 说明                   |
| -------------------------------- | ---------------------- |
| **连续子数组求和**               | 不是任意元素组合       |
| **要求个数，不是只判断是否存在** | 更适合配合哈希表做计数 |
| **数组可能含负数**               | 不能直接用滑动窗口     |

## 二、和为 K 的子数组

**链接**：[560. 和为 K 的子数组](https://leetcode.cn/problems/subarray-sum-equals-k/)

**难度：** Medium

### 1. 题目描述

给定整数数组 `nums` 和整数 `k`，返回和为 `k` 的连续子数组个数。

### 2. 核心思路

设当前前缀和为 `prefix`。如果之前某个位置的前缀和是 `prefix - k`，那么从那个位置之后到当前位置这一段的和就是 `k`。

所以遍历时：

- 用 `prefix` 维护从开头到当前位置的累加和。
- 用哈希表记录“某个前缀和出现过多少次”。
- 每到一个新位置，就查看 `prefix - k` 出现过几次，这些都能组成合法子数组。

这个做法把暴力枚举两层循环优化成了一次遍历。

### 3. 复杂度

| 维度           | 复杂度 |
| -------------- | ------ |
| **时间复杂度** | `O(n)` |
| **空间复杂度** | `O(n)` |

### 4. 参考实现

```typescript
function subarraySum(nums: number[], k: number): number {
  const prefixCount = new Map<number, number>()
  prefixCount.set(0, 1)

  let prefix = 0
  let answer = 0

  for (const num of nums) {
    prefix += num

    answer += prefixCount.get(prefix - k) ?? 0
    prefixCount.set(prefix, (prefixCount.get(prefix) ?? 0) + 1)
  }

  return answer
}
```

### 5. 易错点

| 易错点                           | 说明                                         |
| -------------------------------- | -------------------------------------------- |
| **忘记初始化 `0 -> 1`**          | 表示“从下标 `0` 开始的子数组”也可能是答案    |
| **把这题误判成滑动窗口**         | 有负数时，窗口扩大后和不单调，滑动窗口不成立 |
| **只记录是否出现过，不记录次数** | 题目要求的是“个数”，不是“是否存在”           |
