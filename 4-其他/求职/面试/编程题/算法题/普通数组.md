# 普通数组

## 一、题型认知

“普通数组”里的题通常没有特别强的标签，但往往能落到 **状态转移、前缀和、贪心、双指针** 这些常见模型上。

这道题最经典的做法是 **Kadane 算法**，本质属于一维动态规划。

| 关键问题                                   | 结论                                        |
| ------------------------------------------ | ------------------------------------------- |
| **当前连续子数组要不要继续接上前面的和？** | 如果前面的和是负数，就应该直接放弃          |
| **状态怎么定义？**                         | `dp[i]` 表示以 `i` 结尾的最大子数组和       |
| **状态转移是什么？**                       | `dp[i] = max(nums[i], dp[i - 1] + nums[i])` |

## 二、最大子数组和

**链接**：[53. 最大子数组和](https://leetcode.cn/problems/maximum-subarray/)

**难度：** Medium

### 1. 题目描述

给定一个整数数组 `nums`，找出和最大的连续子数组，返回其最大和。

### 2. 核心思路

遍历到 `nums[i]` 时，只需要考虑一件事：

- 是把它接在前一个连续子数组后面更优；
- 还是从它自己重新开始更优。

因此可以定义：

$$
dp[i] = \max(nums[i], dp[i - 1] + nums[i])
$$

为了节省空间，没有必要真的开数组，只要用一个变量保存“以上一个位置结尾的最优值”即可。

### 3. 复杂度

| 维度           | 复杂度 |
| -------------- | ------ |
| **时间复杂度** | `O(n)` |
| **空间复杂度** | `O(1)` |

### 4. 参考实现

```typescript
function maxSubArray(nums: number[]): number {
  let best = -Infinity
  let current = 0

  for (const num of nums) {
    current = Math.max(num, current + num)
    best = Math.max(best, current)
  }

  return best
}
```

### 5. 易错点

| 易错点                   | 说明                                                     |
| ------------------------ | -------------------------------------------------------- |
| **初始化为 `0`**         | 数组可能全是负数，答案不一定大于等于 `0`                 |
| **把题目看成任意子序列** | 题目要求的是“连续子数组”                                 |
| **状态没想清楚**         | `current` 表示“必须以当前位置结尾”的最优值，不是全局最优 |
