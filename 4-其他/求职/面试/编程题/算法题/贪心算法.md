# 贪心算法

## 一、题型认知

**贪心算法** 的核心是：每一步都做当前看起来最优的选择，并依赖题目的性质保证局部最优能推出全局最优。

| 识别信号                   | 说明                             |
| -------------------------- | -------------------------------- |
| **只关心当前最优状态**     | 比如当前最小值、当前最大收益     |
| **不需要回头修改历史决策** | 当前决策一旦做出，不会影响正确性 |
| **可以维护某个最优不变量** | 如最小买入价、最大剩余容量       |

这道题的关键不变量是：**遍历到当天时，始终知道历史最低买入价。**

---

## 二、买卖股票的最佳时机

**链接**：[121. 买卖股票的最佳时机](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock/)

**难度：** Easy

### 1. 题目描述

给定数组 `prices`，其中 `prices[i]` 表示第 `i` 天的股票价格。只允许完成一次买入和一次卖出，求最大利润。

### 2. 核心思路

遍历到第 `i` 天时，只需要知道两件事：

- 之前见过的最低价格是多少。
- 如果今天卖出，利润是多少。

因此可以边遍历边维护：

- `minPrice`：截至当前为止的最低买入价。
- `maxProfit`：截至当前为止能得到的最大利润。

这就是典型的贪心：**每一天都用“更低的买入价”和“更高的利润”刷新答案。**

### 3. 复杂度

| 维度           | 复杂度 |
| -------------- | ------ |
| **时间复杂度** | `O(n)` |
| **空间复杂度** | `O(1)` |

### 4. 参考实现

```typescript
function maxProfit(prices: number[]): number {
  let minPrice = Infinity
  let maxProfit = 0

  for (const price of prices) {
    minPrice = Math.min(minPrice, price)
    maxProfit = Math.max(maxProfit, price - minPrice)
  }

  return maxProfit
}
```

### 5. 易错点

| 易错点                 | 说明                                   |
| ---------------------- | -------------------------------------- |
| **允许先卖后买**       | 题目要求买入必须发生在卖出之前         |
| **最大利润初始化错误** | 如果一直亏损，答案应该是 `0`，不是负数 |
| **把题目做成双层循环** | 暴力是 `O(n^2)`，没有必要              |
