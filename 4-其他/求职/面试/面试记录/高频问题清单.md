## 二、按主题归类的问题清单

## 二、基础背景与求职动机

### 1. 自我介绍与个人标签

- 请先做一下自我介绍。
- 请脱离简历讲讲你自己。
- 你先简单介绍一下。
- 请做一个不超过四五分钟的自我介绍。

### 2. 工作经历与角色定位

- 你现在做了 4 年是吗，主要技术栈是什么？
- 你之前主要是前端多一点是吧？
- 你现在更把自己定义成什么类型的开发？
- 你是前端出身，后来又做 AI 和全栈，是这样吗？

### 3. 离职原因与找工作诉求

- 现在是不是已经离职了？离职原因是什么？
- 为什么没有留在原公司内部其他业务线？
- 接下来想找什么样的机会？
- 你现在看机会一般会从哪些方向去看？

### 4. 职业规划与竞争力

- 你对自己未来的发展有什么规划？
- 你觉得自己最突出的亮点是什么？
- 换到别的业务线或 To B 系统，你的优势是什么？
- 你现在的经验和我们岗位的匹配度，你自己怎么看？

### 5. 稳定性与个人情况

- 为什么本科时间比较长？
- 为什么 31 岁只有 4 年工作经验？
- 现在是在北京还是老家？地点是否有问题？
- 英语怎么样，能否适配海外团队？

***

## 三、项目与全栈交付

### 1. 最近项目总述

- 把最近做的主要项目简单讲一讲。
- 挑一个最能代表你的项目，结合实际展开讲讲你做了什么。
- 最近的项目是什么，是不是从 0 到 1？
- 项目到底解决什么问题？

### 2. 个人职责与团队分工

- 你在项目里担任什么角色？
- 前后端参与比例是多少？
- 团队配置怎样？
- 你这边也参与具体开发吗？比例大概多少？

### 3. 带人、分工与推进

- 你这个小组长带多少人，主要负责什么？
- 做需求分析、技术选型和工作安排时是怎么考虑的？
- 新项目到你这里后，你怎么分人、怎么拆任务？
- 绩效是不是你来打？

### 4. 技术选型与架构理由

- 从 0 到 1 的技术选型、架构搭建是怎么做的？
- 为什么用了父子项目 / iframe，而不是微前端框架？
- 为什么智能体选 Python，不选 Spring AI 或 Node.js？
- 为什么后端要从单体演进到微服务？

### 5. 全栈能力边界

- 你后端做了多长时间？
- Java 开发这部分你也做过吗？
- Java、Spring、MySQL、Redis、Python 这些能力是什么时候开始真正实践的？
- 服务器部署是不是也由你负责？

***

## 四、AI 提效、工具链与工程实践

### 1. AI 提效方法论

- 平时怎么用 AI 做开发提效？
- AI 在前端、后端分别怎么帮助你？
- 大概多少代码由 AI 生成？为什么还有一部分必须自己写？
- 如果一行代码都不写，能否靠 AI 把项目端到端做完？

### 2. AI 工具与模型选择

- 平时主要用哪些 AI 编程工具？
- Cursor、Claude Code、Copilot、OpenCode 有什么区别？
- 你现在主要用什么模型？
- 最近有没有观察过这些工具上下文读取方式的变化？

### 3. Rules / Skills / MCP / Prompt 沉淀

- Rules 和 Skills 分别放什么？
- 这些规则是怎么限制 AI 的？为什么有的放 Rules，有的放 Skills？
- Skills 通常在什么时候用？你写了多少类？
- MCP 你怎么理解，实际接过哪些？
- Skills 和 MCP 有什么区别？

### 4. AI 约束、幻觉与质量控制

- 上下文很多、AI 回答不稳定或者出现幻觉时怎么处理？
- 多人协作、大项目里 AI 容易跑偏，你怎么控住？
- AI 生成代码后你怎么 review、怎么验收？
- 如果 AI 帮你写完一段代码，你下一步怎么验证它是真的对的？

### 5. AI 在完整研发链路里的角色

- 如果把需求分析、PRD、UI、技术方案、排期、联调、自测都尽量交给 AI，你怎么看？
- 测试阶段 AI 会怎么参与排查问题？
- 如果让 AI 参与部署到发布的链路，怎么保证准确性与安全性？
- AI 会怎么改变前端、后端、测试、产品这些角色？

## 五、Agent 与大模型应用

### 1. 智能体项目介绍

- 智能体这块是什么时候开始做的？上线了吗？
- 你们这个智能体主要包含哪几部分？
- 主要完成什么业务功能？输入输出是什么？
- 最后是以什么方式交付到系统里的？

### 2. LangChain / LangGraph / RAG

- 基于 LangChain 做的能力具体怎么接的？
- 是不是用 LangGraph 之类的工作流来组织的？里面核心有几个节点？
- 有没有 RAG 或知识库设计？
- 对 AI 知识库和 RAG 的理解是什么？

### 3. Prompt、消息协议与风控

- 强约束提示词应该放在 message 的哪个角色位置？
- tool message 在 message 数组里有什么顺序要求？
- 哪些问题该交给模型，哪些该交给传统逻辑？
- 输入风控、输出风控、流式撤回怎么设计？

### 4. 长上下文与对话管理

- 长对话场景下怎么做上下文管理？
- 压缩时机和压缩力度怎么控制？
- 只按阈值压缩，怎么避免上下文被切断后不连贯？
- 项目里有没有建立准确率指标？

### 5. Agent 工程化能力

- 你在 Agent 里面怎么设计 system prompt？
- 如果新建一个垂类 Agent 或 Sub-Agent，你会怎么设计说明文件和能力边界？
- 团队里有哪些 AI 工程实践和 rules / skills 沉淀？
- 如果让 AI 对产品文档评分、判断需求值不值得做，提示词结构怎么设计？

## 七、后端高频追问

### 1. Spring 与 Java 基础

- Spring Boot 这套框架你理解到什么程度？
- IOC、DI、AOP 的核心作用是什么？
- Spring Bean 的生命周期是怎么样的？
- Controller 是单例时会不会有并发数据污染问题？

### 2. 数据库、缓存与中间件

- MySQL 索引优化有哪些应用场景和思路？
- 数据库事务隔离级别你知道吗？
- 深分页为什么会慢，怎么优化？
- Redis 雪崩、击穿、穿透怎么理解？
- MyBatis 一级缓存和二级缓存有什么区别？

### 3. 微服务与分布式

- 微服务是从 0 开始搭建的，还是从已有项目演进出来的？
- 服务拆成了哪些部分？分别做什么？
- 服务间调用、隔离和系统可用性怎么保证？
- 分布式事务在什么场景下才有必要？Seata 怎么做统一回滚？

### 4. 并发、线程池与问题排查

- 多线程用过吗？
- 线程池核心参数怎么理解？
- 线程池大小为什么这么设？
- 线上内存泄漏、服务异常、磁盘 IO 压力怎么排查？

### 5. 消息队列与异步场景

- MQ 用过吗，在哪个项目、什么场景？
- MQ 的具体实现逻辑是什么？
- 异步任务为什么要用消息队列而不是同步调用？

- 流式输出过程中命中敏感内容，怎么做撤回和兜底？
- 如果 AI 生成代码量是人写的 3 到 5 倍，怎么保证长期质量？
- 如果 AI 参与部署发布链路，权限边界、审批、审计、回滚怎么设计？
- 如果让你设计一个承载海量数据的表格系统，你会怎么做虚拟化、滚动体验和编辑态管理？
